## 0. 摘要

### 0.1 本模块交付什么

1. **层分析** `find_layers` / `findLayers`：沿任意方向做一维间隙单链聚类。`auto`/`normal` 的方向由 F0-A 的 `surface_normal` 给出（真空间隙优先，U1）。
   周期方向上，slab 轴用 F0-D `find_vacuum_gap` 的间隙中点切开，与显示用同一个切口（U1 第 1、2 点）。
   结果给出每个原子的层号（0 = 最底层，同时给出从顶层数的层号）、每层高度、原子、组成、起伏，以及"临界容差"警告。
   可以把原子面按**化学计量单元**合并成行（TiO2(110) 的 O–Ti2O2–O 三层组、CeO2(111) 的 O–Ce–O）。
2. **化学键图** `bond_graph` / `bondGraph`（全仓库唯一的成键判据，M4、M5 复用）和配位数；可选 smart 规则：两个金属原子都与非金属成键时，不计这对金属–金属键。
3. **吸附物识别** `find_adsorbates`（v2 规则）以及 **Mark as adsorbate / Unmark**。吸附物来源依次为：`adsorbate_id` > tags（含 Open Catalyst 约定）> 几何猜测 > 无。
   手动标记是所有猜测失败时的通用补救。
4. **暴露原子** `surface_atoms`：竖直探针下落判据的闭式解，探针半径取统一原子半径 R 的倍数（默认 0.70 R），因此与晶格常数无关。
5. **几何选择**：按层（底部 N 层、顶部 N 层、中间 N 层、指定层）、按高度、按分数坐标（可跨 1→0）、按球形区域（最小像）、选吸附物、选暴露原子；网页端 `app.select` 增加 `intersect` 模式。
6. **Atom Selection 查询工具**：仿 MS 的 Edit › Atom Selection，做成非模态浮动卡片。查询是一份带版本号的 JSON，Python、JS、REST 用同一套语义，层和成键参数写在查询里。
7. **约束**：在 F0-D `core/constraints` 之上做薄封装（`fix`/`free`/`fix_layers`/`fix_height`）。
   界面包括：Surface ▸ Layers 的固定控件、选区卡片 Fix ▾、右键菜单、Structure ▸ Constraints 分区、悬停卡片的约束行、固定原子光环与显示开关。
8. **接口**：JS 公共 API、Python API、REST `POST /api/v1/analysis/layers`、客户端 `Client.layers()`；CLI 有只读的 `facet layers`，以及修改结构的 `facet edit fix` / `edit free`。

## 1. 用户故事与 Materials Studio 对照

### 1.1 用户故事

- **S1 固定底层（最常用）。** 用 M2 切出 Pt(111) p(3×3) 4 层（pbc T T T，U2），打开 Surface ▸ Layers，看到 4 行（`1` 顶层 … `4` 底层，每行 Pt 9，Δ 2.26 Å）。
  在固定控件里选 `Fix [bottom ▾] [2] layers` → Apply：18 个原子变为 F F F，视图里出现蓝色固定光环，Structure ▸ Constraints 显示 "18 of 36 atoms fixed"。
  用 M5 放两个 CO 后，"Adsorbates"一行显示 "C 2 · O 2 (from adsorbate ids)"，层号不变。导出 POSCAR（F0-D）带 Selective dynamics。
- **S2 打开 VASP CONTCAR。** 文件 pbc T T T，带 Selective dynamics，底层在分数 z = 0，有几个原子被 VASP 包到 0.999。
  视图按 U1 的切口把 slab 连续画出，层分析用同一个切口，仍是 4 层 Pt，不再提示 straddle。原有的 SD 标志显示在层行和光环上。
  吸附物由几何猜测找到，开关旁标 "guessed"。悬停卡片显示存储坐标（F0-A）以及 `layer 4/4 · fixed`。
- **S3 TiO2(110) 氧空位。** 点层表第 1 行（桥氧）选中整行，Ctrl/⌘ 点掉不删的原子，按 Delete；或者在 Atom Selection 里写 `Element is O` 且 `Layer from top = 1`。
  之后 **Select surface atoms** 能看到空位下露出来的 Ti。把 `Group` 切到 `Stoichiometric units`，层表变成 3 行 O–Ti2O2–O，`Fix [bottom] [1] unit` 固定最下面一个三层组。
- **S4 对称 slab 固定中间层。** SrTiO3 7 层：`Fix [middle ▾] [3] layers`，两个表面同时弛豫；或者点第 3 行，Shift 点第 4、5 行，再用选区卡片的 **Fix**。
- **S5 部分约束。** Ru(0001)：先 `Fix bottom 2 layers`，再选第 3 行 → 选区卡片 **Fix ▾ → Fix z only**（标志 T T F；a、b ⊥ z 才这样命名）。
- **S6 二维材料加原子。** MoS2 单层显示 3 层（S、Mo、S）；放一个 Pt 吸附原子后显示 "Adsorbates · Pt 1 (guessed)"。
  要在 S 层上放一个 S 吸附原子：同元素猜不出来，选中它 → 选区卡片 More → **Mark as adsorbate**。右键吸附原子 → **Select atoms within…**，打开 Atom Selection 并预填 "Distance ≤ 3.0 Å of atom #48"。
- **S7 台阶面与邻晶面。** Pt(211) 沿法向每 0.80 Å 一排，一行一排；**Select surface atoms** 得到台阶边、台面、台阶底三排。
  Pt(554) 在 0.3 Å 下只有 1 层，层表给出起伏提示；用 **Fix by height** `Fix atoms deeper than [4.0] Å below the top` 固定下部。
- **S8 大体系。** Pt(111) p(6×6) 6 层（216 原子）和 1 万原子的 slab：层列表、悬停高亮、按层固定都没有可感知的延迟（§7.5）。
- **S9 脚本与命令行。** `facet layers slab.vasp` 打印层表；`facet edit fix slab.vasp --bottom 2 -o POSCAR` 写出带 SD 的文件；
  Python `s.fix_layers(bottom=2)`；JS `facet.edit.fixLayers({ bottom: 2 })`。
- **S10 Open Catalyst 数据。** 打开 OC20 的 extxyz（tags 0 = 次表层、1 = 表面、2 = 吸附物）：吸附物来源显示 "from tags (Open Catalyst: 2 = adsorbate)"，次表层不会被当成吸附物。
- **S11 两面吸附。** Pt(111) 5 层上下各放一个 CO（消除偶极的常见做法）：两个 CO 都被认出，`Fix [middle] [3] layers` 固定中间三层。

## 3. 算法

记号：晶胞行矢量 `a_0, a_1, a_2`（= a, b, c），`cart = frac @ cell`（C1）；`n̂` 为单位法向；`P` 为周期（Å）；长度一律 Å。
常量放在 `SURFACE_DEFAULTS`（C10；F0-D 的 `core/defaults`，Python 同时支持 `d.key` 与 `d["key"]`，JS 用 camelCase）。M3 的键：

| Python 键 | JS 键 | 值 | 用途 |
|---|---|---|---|
| `layer_tolerance` | `layerTolerance` | 0.3 | 默认层容差（M2 共用） |
| `layer_tolerance_max` | `layerToleranceMax` | 5.0 | API 上限（界面上限 2.0） |
| `layer_borderline` | `layerBorderline` | 0.15 | 临界提示的余量 |
| `layer_rumple_min` | `layerRumpleMin` | 0.6 | 起伏警告的下限：层厚 > max(2·tol, 0.6) |
| `period_max_index` | `periodMaxIndex` | 12 | 判定周期时尝试的最大整数 |
| `period_min` | `periodMin` | 0.5 | 周期下限（实际用 `max(period_min, 2·tol)`） |
| `surface_probe` | `surfaceProbe` | 0.70 | 探针半径 / R |
| `surface_borderline` | `surfaceBorderline` | 0.10 | 暴露度与 κ 相差小于它的原子标为"临界" |
| `bond_scale` / `bond_min` / `bond_max` | `bondScale` / `bondMin` / `bondMax` | 1.15 / 0.4 / 5.0 | 化学键图（§3.7），M4 共用 |
| `select_radius_max` | `selectRadiusMax` | 50.0 | 球形选择半径上限 |
| `analysis_lazy_atoms` | `analysisLazyAtoms` | 20000 | 超过它时，界面只在用户触发时才做几何猜测与暴露原子计算 |

另外引用 F0-D 的 `vacuum_gap_min`（5.0 Å，U1 的真空阈值）与 `position_tolerance`（1e-5 Å，C10）。

### 3.1 方向解析 `resolve_direction(structure, direction) -> (label, n̂, axis, source)`

| 输入 | n̂ 与 axis | 需要晶胞 | label / source |
|---|---|---|---|
| `None` / `"auto"` | `g = surface_normal(s, require_gap=True)`（F0-A §3.13.2）。非空：`n̂ = g.normal`，`axis = g.axis`；为空时，有晶胞取 c 面法向（axis 2），无晶胞取 ẑ（axis None） | 否 | `"abc"[axis]` 或 `"z"`；`source = g.source`（`vacuum`/`pbc`/……）或 `default` |
| `"normal"` | 同上，但 `g` 为空时报错 `direction 'normal' needs a vacuum gap or a non-periodic axis; use 'c'` | 是 | 同上 |
| `"a"`/`"b"`/`"c"`（轴 k） | `unit(a_{k+1} × a_{k+2})`，取 `n̂·a_k > 0`；axis = k | 是 | 同输入；`source = axis` |
| `"x"`/`"y"`/`"z"` | 笛卡尔单位矢量 | 否 | 同输入 |
| `[x, y, z]` | `unit(v)` | 否 | `"vector"` |
| `{"hkl": [h, k, l]}` | `unit(h a* + k b* + l c*)`，`a*` 为 `inv(cell)ᵀ` 的行 | 是 | `"hkl"` |
| `{"hkil": [h, k, i, l]}` | 校验 `i = −(h + k)` 后按 `(h, k, l)` | 是 | `"hkl"` |
| `{"uvw": [u, v, w]}`（可选） | `unit(u a + v b + w c)` | 是 | `"uvw"` |
| `{"kind": …, "value": …}` | 界面存的规范形式（§4），与上面各行一一对应 | — | — |

- 对 x/y/z、矢量与 hkl：若 `n̂` 与某个 `plane_normal(cell, k)` 平行（`|cos| > 1 − 1e-9`），令 `axis = k`。例如标准取向 slab 上 `"z"` 与 `"c"` 完全等价。
- F0-A 若不提供 `require_gap` 参数，则等价写法是 `surface_normal(s)` 且 `source ∈ {'vacuum', 'pbc'}`（F0-A 若保留 `'info'` 规则，也算在内）。
  M3 自己**不**判断"是不是 slab"，也不直接读 `info.surface.normal/axis`（EM6）。
- 左手晶胞时叉积方向相反，靠"使 `n̂·a_k > 0`"统一。

### 3.2 周期判定 `period_along(cell, pbc, n̂) -> (P | None, kind)`

与 v1 相同：

```
if cell is None or not any(pbc): return None, "invariant"
p = [a_k·n̂ for periodic k];   nz = [|x| for x in p if |x| > 1e-9 · max_k |a_k|]
if not nz: return None, "invariant"          # n̂ 垂直于所有周期矢量：包裹不改变高度
p0 = min(nz)
for m in 1 .. period_max_index:
    P = p0 / m
    if P < max(period_min, 2·tol): break
    if all(|x/P − round(x/P)| < 1e-6 · max(1, |x/P|) for x in nz): return P, "periodic"
return None, "irrational"
```

第一次成功的 m 给出最大的 P，也就是晶面族的面间距（fcc 常规胞沿 (111) 得 2.263 Å）。`P < 2·tol` 时周期聚类没有意义，按无理方向处理。

### 3.3 高度与切口（U1）

高度一律用 Float64 存储坐标（P5）：`h_i = (x_i·n0 + y_i·n1) + z_i·n2`，运算顺序固定，两种语言逐位相同（v1 原型已验证）。

| kind | 切口与展开 | `offset_i`（整数，`u_i = h_i − offset_i·P`） | `vacuum` |
|---|---|---|---|
| `invariant` | 不切；`u = h` | 0 | `null`（结构可能是 pbc T T F 的二维材料） |
| `periodic`，方向是 slab 轴 | `slab = surface_normal(s, require_gap=True)` 非空且 `slab.axis == axis`：`gap = find_vacuum_gap(s, axis, min_width=0)`（F0-D，**全部原子**参与）；`f' = unwrap_along_gap(f_axis, gap)`（F0-D：`f − floor(f − cut)`，cut 为间隙中点映射到 (−0.5, 0.5]） | `offset_i = f_i − f'_i`（精确整数） | `gap.width` |
| `periodic`，其他 | 环上规则（只看参与聚类的原子 C）：`w = h − P·floor(h/P)`（`w ≥ P(1 − 1e-12)` 时取 0），排序后求环上间隙；最大间隙 ≤ tol 时整个周期是一层（`spansPeriod`）；否则切在**最宽的间隙**，宽度相差 ≤ 1e-5 Å 时优先跨晶胞边界的那个（1→0），再取起点最小者；`mid` 为切口间隙的中点，所有原子 `u_i = w_i − P·[w_i > mid]` | `round((h_i − u_i)/P)` | `null` |
| `wrapped`（无理方向） | 各周期轴的分数坐标：有间隙的轴用 `unwrap_along_gap`，其余轴用 F0-D `wrap_fractional`（[0, 1)）；按这些坐标求 h，不切 | 0 | `null`；附提示 |

要点：

- **与显示同一个切口。** 间隙宽度 ≥ `vacuum_gap_min` 时，F0-A 的显示（§3.8.2）调用同一个 `unwrap_along_gap(f, find_vacuum_gap(s, k))`，所以层分析、悬停高亮与画面一致。
  间隙小于 5 Å、但 `surface_normal` 仍判定这根轴为表面轴时（例如 M2 的 slab 上立着高分子），M3 也切在最宽的间隙上，而显示不切；层的划分仍然正确（F0-D 审查 F10）。
- **排除吸附物或只聚类 `indices`** 只会让间隙变大，切口仍落在参与聚类的原子之间的间隙里；被排除的原子按同一切口展开，所以顶面上的吸附物高度在顶面之上。
- **分子离哪一面近就归哪一面。** 分子在真空中部时，按最宽间隙它可能归到下一个周期像的底面一侧（原型：15 Å 真空、CO 在 7 Å），显示也这样画。吸附物识别有"自由分子"规则（§3.8），所以按层固定不受影响。
- 体相（没有间隙）沿 c 时，fcc 的两个面间隙相等，并列时优先晶胞边界，层高就等于存储坐标（原型：0.00、1.96）。
- `straddles` 为真表示参与聚类的原子有两种以上的 `offset`（slab 跨晶胞边界存放）。它只作信息，界面不提示（K15）。
- 轴情形下，展开后的笛卡尔位置 `r_i − offset_i · a_axis` 沿 n̂ 的高度正好是 `u_i`；M5 与 §3.9 都用它。

### 3.4 聚类：线性单链

- 周期情形只需把 order 旋转到切口之后开头，不必再排序。复杂度：一次稳定排序 O(N log N)，其余 O(N)。

### 3.6 化学计量单元分组（`group = "units"`）


### 3.7 化学键图 `bond_graph(structure, *, metal_pairs="all", indices=None) -> BondGraph`

全仓库唯一的成键判据（K7）；M3 在第 1 波交付，M4（片段、基底掩码）、M5（smart 配位数）直接调用。

- **判据**：`bond_min < d < min(bond_max, bond_scale·(r_i + r_j))`，取 0.4 / 5.0 / 1.15；Cordero 共价半径，两种语言用 F0-D 统一的表（未知元素 0.5 Å）；
  所有元素对都参与，不读任何显示设置（`smart`、`pairOverrides`、`tolerance`、`maxLength`）。
- **距离**：`d = sqrt(dx*dx + dy*dy + dz*dz)`，固定这个运算顺序（不用 `Math.hypot` 或 `np.linalg.norm`，r5：32% 的随机矢量末位不同）。
- **周期像**：每条边带整数像偏移 `o`，表示 `r_j + o @ cell` 与 `r_i` 成键；非周期轴的偏移恒为 0；同一对原子的不同像是不同的边（小晶胞里桥氧的两个 Ti 可能是同一个原子的两个像，v1 原型踩过）。
  双向存储，反向偏移取负。
- **输出（CSR）**：Python `BondGraph(indptr (N+1,), neighbors (M,), offsets (M, 3) int, distances (M,))`；JS `{ indptr: Int32Array, neighbors: Int32Array, offsets: Int32Array(3M), distances: Float64Array }`。
  每个原子的边按 (j, o) 字典序排列，两种语言逐条相同。
- **smart 规则**（`metal_pairs="smart"`，M5 §3.2 的定义）：先在完整的图上求每个原子是否至少与一个非金属（`ANIONS` 中且不在 `METALS` 中，集合与 `core/elements.js:160-166` 相同）成键；
  然后删去两端都是"与非金属成键的金属"的金属–金属边。效果：氧化物、硫化物、卤化物里不计阳离子–阳离子接触；
  金属表面上，只有直接连着吸附物的金属原子之间才不计。已知局限：吸附物达到 1 ML 时，顶层金属之间的键也不计（§8）。
- `indices` 给出时，只保留两端都在集合内的边（M4 的子图用法）。
- `coordination_numbers(structure, *, metal_pairs="smart", graph=None) -> (N,) int` 是每个原子的边数（按像计数）。
- **实现要求**（E8）：分数坐标周期格子（格宽 ≥ 最大截断），CSR 数组，不复制周期像，一次计算多处复用；JS 预分配 `Int32Array`/`Float64Array`，不用字符串键的 Map。
  预算见 §7.5。Python 可以在现有 `neighbor_arrays`（`analysis/neighbors.py:81`）上实现，传 `min_distance=0.4` 后再按 `bond_max` 过滤；它的比较是严格的 `<`，与本判据一致。
- 缓存：JS 按 `structureDigest(s)`（只看符号、坐标、晶胞、pbc、帧）加 `metal_pairs` 缓存在 `WeakMap` 里；Python 不缓存。

### 3.8 吸附物识别 `find_adsorbates(structure, *, direction=None, tolerance=None, details=False)`

```
1. props.adsorbate_id 存在且有 > 0 的值 → 这些原子，source = "adsorbate_id"
2. props.tags 存在：
   a. 值域 ⊆ {0, 1, 2}，含 2，且含 0 或 1，并且 tags == 2 的原子在化学键图里不构成面内无限延伸的连通块
      → tags == 2 的原子，source = "tags-oc20"（Open Catalyst 约定：0 次表层、1 表面、2 吸附物）
      （ASE 的两层 slab 也是 {0, 1, 2}，但它的 tag 2 是第 2 层，是周期层，所以落到 b）
   b. 否则若既有 0 又有 > 0：cand = tags == 0 的原子；
      若 cand 在化学键图里含有面内无限延伸的连通块 → 放弃 tags，转到第 3 步，并记说明
        "Atoms with tag 0 form a periodic layer, so the tags don't mark adsorbates; guessed from the geometry."
      否则 → cand，source = "tags"（ASE 约定：0 = 吸附物）
3. 几何猜测，只在 surface_normal(s, require_gap=True) 非空时做（有真空间隙或唯一的非周期轴；没有晶胞的团簇不猜，原型同步）：
   L = find_layers(s, direction, tolerance)（全部原子）；L.count < 2 → none
   G = bond_graph(s)（all 规则）；u = L.height
   E_low  = {高度 ≤ (min u + max u)/2 的原子的元素}
   E_rank = {按 u 排序后序号在 [⌊N/4⌋, N − ⌊N/4⌋) 内的原子的元素}
   E = E_low ∩ E_rank，为空时取 E_low                               # 基底元素
   重复：
     seeds = { i : sym_i ∉ E，且 i 不是替位掺杂 }
             替位掺杂：i 所在层里有 E 元素的原子 H，并且 cnE(i) ≥ median{cnE(h) : h ∈ H}（cnE = 指向 E 元素原子的边数）
     对 seeds 在 G 上求连通块；面内无限延伸的块，把它的 2-core（反复去掉块内度 ≤ 1 的原子）的元素并入 E
     E 没有变化时停止
   ads = 有限的种子块
   生长：对 ads 中每个 i 的每条边 (i, j)：j ∉ ads 且 sym_j ∈ E，并且 j 指向"不在 ads 中且元素属于 E"的边数 ≤ 1 → 把 j 加入 ads（只吸收端基原子）；重复到不再变化
   自由分子：若 G 有面内无限延伸的连通块，则原子数 ≤ N/2 的有限连通块整块加入 ads（真空里的分子、物理吸附的分子）
   丢掉 ads 内部在面内无限延伸的连通块（覆盖层、二维材料不算吸附物）
   结果非空 → source = "geometry"，否则 none
4. 否则 ([], "none")
```

- **为什么取交集。** `E_low` 在分子比 slab 还高时仍可靠（竖立的吡啶在 3 层 Pt 上），`E_rank` 在两面都有吸附物时可靠（对称 slab 的两个 CO 只占两头）。
  两者都不含的元素才当作外来元素（原型：乙醇、吡啶、两面 CO 都对）。
- **为什么用配位数判替位。** 空位里的吸附原子高度可能小于容差，与顶层并成一层：N/Fe(100) 在 0.27 Å，CN 5；同层 Fe 的中位 CN 为 8–10。替位的 Au 在 Pt(111) 顶层，CN 9，等于 Pt 的中位数（D7）。
- **2-core**：石墨烯/hBN 异质结的上层是周期块，整层元素并入基底，不当作吸附物；同一块上悬挂的 H 不在 2-core 里，所以石墨烯上的 H 仍被认出（E5）。
- **键必须按周期像逐条计数**（§3.7），否则小晶胞里桥氧的两个 Ti 会被当成一个，nsub 算成 1，晶格桥氧就成了吸附物。
- `details=True` 返回 `{indices, source, notes, substrateElements}`。
- 已知局限（写进文档与开关的悬停提示）：与基底同元素的吸附原子（Pt 上的 Pt、氧化物上的 O 原子）认不出来，请用 Mark as adsorbate；
  一侧的吸附物原子占全部原子的 1/4 以上、并且比 slab 还高时，可能只认出一部分；替位原子自成一层且对基底配位不足时会被当成吸附物。
  M5、M4 放置的吸附物有 `adsorbate_id`，不受这些局限影响。
- 复杂度：键图 O(N)（§3.7）＋生长与连通块 O(N + M)；E 的循环至多重复元素种数次。

### 3.9 暴露原子 `surface_atoms(structure, side="top", *, probe=None, direction=None, tolerance=None, skip_adsorbates=True, details=False)`

**定义**：把基底原子都看成半径 R 的球，R = ½ · median{d_i}，d_i 是原子 i 到最近基底原子（含所有周期像，距离 > 0.4 Å）的距离（偶数个时取中间两个的平均，即 numpy 规则）。
半径为 `p = κ·R` 的探针（κ = `probe` ?? `SURFACE_DEFAULTS.surface_probe` = 0.70）沿 −σn̂ 竖直落向原子 i（σ = +1 顶面，−1 底面）。若探针先碰到 i，i 就是该侧的暴露原子。

**闭式判据**（与 v1 逐原子模拟下落等价，`dbg_tio2.py` 核对）：记 s = R + p，对每个更高的原子 j（σ·Δh_ij > 0，Δh_ij = σ(u_j − u_i)），ρ_ij 为两者的面内距离，d_ij 为三维距离，令

```
t_j = ρ_ij                         若 ρ_ij < Δh_ij        （j 挡在下落路径上）
t_j = d_ij² / (2·Δh_ij)            否则                    （j 会碰到停在 i 上的探针）
s*_i = min_j t_j                   （没有更高的原子时为 ∞）
i 暴露  ⇔  s*_i ≥ s − 1e-6
暴露度 κ*_i = s*_i / R − 1          （i 暴露 ⇔ κ < κ*_i）
```

- 推导：探针中心沿 i 的竖直线下落，碰到 j 时的中心高度是 `u_j + sqrt(s² − ρ²)`（需要 ρ < s），碰到 i 时是 `u_i + s`；
  j 先碰到探针 ⇔ `ρ < s` 且 `Δh + sqrt(s² − ρ²) > s`。按 ρ 与 Δh 的大小分两种情况解出阈值，就是上式；两种情况在 ρ = Δh 处连续。
- 只有更高的原子可能挡住 i；`t_j ≥ ρ_ij`，所以只需查面内距离 < s 的原子（二维网格，格宽 = s，含面内周期像），复杂度 O(N·k)。
- 坐标用 §3.3 展开后的连续位置 `r_i − offset_i·a_axis`；方向取 slab 法向（auto）。
  `coords == "wrapped"`，或周期方向不是 slab 轴（`vacuum` 为空且 kind 为 periodic）时报错（§3.16）。
- **阈值表**（纯几何数，与晶格常数无关）：

  | 原子 | κ* | κ = 0.70 时 |
  |---|---|---|
  | fcc(111)、bcc(110) 第二层 | 2/√3 − 1 = 0.155 | 不暴露 |
  | hcp(0001) 第二层 | 0.179 | 不暴露 |
  | fcc(100) 第二层 | √2 − 1 = 0.414 | 不暴露 |
  | MoS2 的 Mo | 0.52 | 不暴露 |
  | TiO2(110) 的 Ti6c | 0.537（弛豫后 0.58–0.66） | 不暴露 |
  | fcc(211) 台阶底、bcc(100) 第二层 | √3 − 1 = 0.732（台阶边内收后 0.75–0.86） | 暴露 |
  | fcc(110) 第二层、bcc(111) 第三层、CeO2(111) 三层组下面的 O、SrTiO3 TiO2 终止的次表层 Sr、SrO 终止的次表层 O | 1.000 | 暴露 |
  | ZnO(10-10) 第二层 | 1.10 | 暴露 |
  | TiO2(110) 的 O3c、Ti5c；bcc(111) 第二层；fcc(211) 台面 | 2.13、3.93；2.00；2.46 | 暴露 |

- **κ 的选择**：常见约定是第一组不暴露、第二组暴露，两组之间的窗口是 (0.54, 0.73)。弛豫通常让次表层原子变得更暴露（κ* 增大，见上表括号），
  所以 κ 取在窗口上沿附近的 0.70，而不是中点：Pt 上 p ≈ 0.97 Å，结果与 v1 的 1.0 Å 相同，并且对所有 fcc/bcc 金属一致。
  代价：SrTiO3 的次表层 Sr（或 O）也算暴露原子（v1 用绝对探针时不算），因为它与 fcc(110) 槽底原子的 κ* 都是 1.000，没有一个 κ 能把两者分开（§8 R3）。
- **临界原子**：`|κ*_i − κ| < surface_borderline`（0.10）的原子列为 `borderline`，暴露与不暴露的两边都算（例如理想 fcc(211) 的台阶底一排，0.732 对 0.70）。界面在计数旁显示 "(3 borderline)"，可点开选中它们，悬停提示 "Atoms whose exposure is within 0.10 R of the probe: relaxation or another convention may change them."
- `side = "both"`：两侧分别计算后取并集；`details=True` 返回 `{top: [...], bottom: [...], radius: R, probe: κ, probeRadius: κR, exposure: {i: κ*_i}, borderline: [...]}`（∞ 写成 `null`）。
- 被排除的吸附物既不是候选，也不挡别人（吸附物下面的 Pt 仍是暴露原子）。
- 部分占位（C12）：每个位点按一个原子处理，结果附 §3.5 的占位提示（EM8）。
- 与 M5 的关系：本函数只回答"探针够得着哪些原子"。"哪些原子定义吸附位点"由 M5 的 `site_atoms`（默认 `auto` 规则）决定，M5 的 `exposed` 方法调用本函数（E6）。

### 3.10 几何选择函数

全部返回升序的原子下标列表（Python `list[int]`，JS `number[]`），不修改结构，也不改变选区。长度比较一律带 `position_tolerance` = 1e-5 Å（C10，D13）。

- **`select_layers(s, *, bottom=None, top=None, middle=None, all_but_top=None, top_layers=None, layer_indices=None, group="planes", direction=None, tolerance=None, skip_adsorbates=True)`**：
  六个选择器恰好给一个。`bottom=N` 选底部 N 行，`top=N` 选顶部 N 行，`middle=N` 选正中间的 N 行（要求 L − N 为偶数，否则报错），`all_but_top=N` 选除顶部 N 行以外的所有行，
  `top_layers=[1, 2]` 按"1 = 顶层"选，`layer_indices=[0, 1]` 按"0 = 底层"选。N 与层号都必须在范围内。"行"是原子面或单元（取决于 `group`）。
- **`select_height(s, lo=None, hi=None, *, relative_to="absolute", direction=None, tolerance=None, skip_adsorbates=True)`**：值为高度 u（absolute）、
  `h_top − u`（"top"：顶层平均高度以下的深度，向下为正）或 `u − h_bottom`（"bottom"）。顶/底层取排除吸附物之后的层；区间闭合；`lo`、`hi` 可只给一个。
- **`select_fractional(s, axis, lo, hi)`**：axis 为 a/b/c 或 0/1/2；周期轴用 F0-D `wrap_fractional` 包裹到 [0, 1)（与显示无关）；`lo ≤ hi` 时取 `lo ≤ f ≤ hi`，`lo > hi` 时取 `f ≥ lo or f ≤ hi`（例如 0.9 → 0.1）；
  非周期轴用不包裹的分数坐标，`lo > hi` 时报错。分数比较的容差为 1e-5 Å 除以该轴的面间距。
- **`select_within(s, centers=None, radius=3.0, *, point=None, centroid=False)`**：`centers` 为原子下标（单个或列表），或者给 `point`（笛卡尔 xyz）；
  `centroid=True` 时以 `centers` 的最小像中心为球心（以第一个原子为参考，其余原子取到它的最小像后求平均）。
  判据：存在周期像 t 使 `|r_i + t − c| ≤ radius + 1e-5`；像的范围按每个周期轴取 `ceil(radius / 面间距_k) + 1`（斜晶胞也正确，07 §9）。中心原子本身包含在内。要求 `0 < radius ≤ select_radius_max`。
  实现：中心数 × 原子数 ≤ 2e6 时直接循环，否则对原子（含边界像）建网格（格宽 = radius）。

### 3.11 查询引擎

#### 3.11.1 查询 JSON（Python、JS、REST、`facet.selectWhere` 共用；写进 `docs/SCHEMA.md`，EM7）

```json
{
  "version": 1,
  "match": "all",
  "layers": {"direction": "auto", "tolerance": null, "skipAdsorbates": true, "group": "planes"},
  "bonds": {"metalPairs": "smart"},
  "conditions": [
    {"prop": "element", "op": "in", "value": ["Pt", "O"]},
    {"prop": "layer", "from": "top", "op": "<=", "value": 2},
    {"prop": "height", "relativeTo": "top", "op": "between", "value": [0, 2.5]},
    {"prop": "frac", "axis": "c", "op": "between", "value": [0.9, 0.1]},
    {"prop": "distance", "op": "<=", "value": 3.0, "from": {"atoms": [12]}},
    {"prop": "fixed", "op": "is", "value": "any"},
    {"prop": "surface", "op": "is", "side": "top"},
    {"prop": "adsorbate", "op": "is not"},
    {"prop": "cn", "op": "<", "value": 6},
    {"prop": "prop:charges", "op": ">", "value": 0.1}
  ]
}
```

- `version` 缺省为 1；更高的版本报错 `query version 2 is newer than this Facet understands (1)`。
- `layers` 与 `bonds` 可省略，省略时取函数默认值（auto、`info.surface.layerTolerance` 或 0.3、排除吸附物、按原子面；smart）。
  界面求值时总是写入当前结构条目的参数，Copy as script 也连同它们一起复制，所以脚本能复现界面的结果（E9）。

| prop | 运算符 | value | 语义 |
|---|---|---|---|
| `element` | `in`, `not in`（`is`/`is not` 为别名） | 符号列表，或逗号分隔的字符串 `"Pt, O"` | 符号经 `normalize_symbol` |
| `index` | `in`, `not in` | 列表，或 `"0-35, 40"`（0 起，与界面的 `#i` 一致） | 越界的下标报错（与编辑一致） |
| `layer` | `=`, `!=`, `<`, `<=`, `>`, `>=`, `between`, `in` | 整数，1 起；`from`: `top`（默认）/`bottom` | 用查询里的 `layers` 参数；被排除的原子不匹配；行是原子面或单元 |
| `height` | `<`, `<=`, `>`, `>=`, `between` | Å；`relativeTo`: `absolute`/`top`/`bottom` | §3.10 `select_height` |
| `x`, `y`, `z` | 同上 | Å | **存储的笛卡尔坐标**（P5），与悬停卡片和文件一致；界面标注 "z (stored)"，并提示 "For slabs use Height, which follows the slab across the cell boundary." |
| `frac` | 同上；`between` 允许 lo > hi（环绕） | `axis`: `a`/`b`/`c` | §3.10 |
| `distance` | `<`, `<=`, `between` | Å；`from`: `{"atoms": [...]}` / `{"selection": true}` / `{"centroid": "selection" 或 [...]}` / `{"point": [x,y,z]}` | 最小像；`selection` 用**开始求值时**的选区快照 |
| `fixed` | `is`, `is not` | `all`（三个轴都固定）/`any`/`partial`/`a`/`b`/`c` | `is not any` = 完全可动 |
| `surface` | `is`, `is not` | `side`: `top`（默认）/`bottom`/`both`；可选 `probe` | §3.9 |
| `adsorbate` | `is`, `is not` | — | §3.8（含手动标记） |
| `cn` | 整数比较、`between` | 整数 | `coordination_numbers`，规则取查询的 `bonds.metalPairs`（默认 smart）；界面提示 "Counts covalent-radius bonds (not the bonds drawn); metal–metal contacts between atoms bonded to non-metals are not counted." |
| `tag`, `adsorbateId` | 整数比较、`in` | 整数 | 缺键时视为 0 |
| `prop:<name>` | 数值比较、`between` | 数 | 只用于标量数值的逐原子属性；非数值的原子不匹配 |

- `between` 两端闭合；长度属性的比较带 1e-5 Å，整数属性的 `=` 精确比较；浮点属性不提供 `=`。
- `match` 为 `all`（AND）或 `any`（OR）；条件列表为空时匹配为空（界面禁用 Select）。不支持嵌套括号（MS 也没有）；需要时分两次应用（第二次用 `intersect`）。
- 只在需要时计算派生量（层、暴露原子、吸附物、配位数），一次求值内缓存；界面里还复用 §3.14 的缓存。
- `parse_query(query) -> 规范化的查询`：校验与规范化，报错文案见 §3.16；命令参数与 REST 都先经过它。

### 3.12 约束

#### 3.12.1 存储（C3、C2、F0-D §3.8）

- `props.selective_dynamics`：N 个 `[bool, bool, bool]`，True = 沿该晶格矢量可动；缺键 = 全部可动；条目从不为 null。
- 读写只经过 F0-D `core/constraints`：`move_flags`（副本，缺键时全 T）、`set_move_flags`（缺键时先建全 T，经 `set_prop` 规范化，每次新建外层与内层数组，满足 I2）、`clear_constraints`（删键）、`constraint_counts`。
- 约束编辑不改变原子集合：源映射是恒等，不需要 `indexMap`；不清除 `info.spacegroup`（C7 未列入）；props 与帧无关，所有帧都受约束（C11 不适用）。

#### 3.12.2 操作（两种语言同语义；JS 的 `fixLayers`/`fixHeight` 是 `core/layers.js` 里的纯函数，node 测试可直接调用，E10）

```
move_flags(s) → (N, 3) bool 副本                                      # F0-D；Structure.move_flags() 是同名便捷方法（M4 同步，E3）
fix(s, indices, axes="abc") → 改变的原子数
    flags = axes_to_lattice(s.cell, axes)                              # §3.12.3：要固定的晶格轴集合
    new = move_flags(s)；对 i ∈ indices、k ∈ flags：new[i][k] = False
    与原来相同 → 0（不写入）；否则 set_move_flags(s, new)
free(s, indices=None, axes="abc") → 改变的原子数
    indices is None 且 axes 覆盖三个轴 → clear_constraints(s)（删键）
    否则同 fix，但置 True；结果全 T 时也保留键（与"从文件读入的全 T 保留"一致）
fix_layers(s, *, bottom|top|middle|all_but_top|top_layers|layer_indices, axes="abc", replace=True,
           group="planes", direction=None, tolerance=None, skip_adsorbates=True) → report
    target = select_layers(...)；slab = 参与聚类的原子（吸附物除外）
    replace=True（设定，K9）：target 的标志 = 恰好固定 axes、其余可动；slab − target 全部可动；吸附物不动
    replace=False（累加）：只对 target 调 fix(axes)
    report = {fixed, freed, changed, previouslyConstrained, warnings}
fix_height(s, depth=None, *, bottom_thickness=None, axes="abc", replace=True, direction=None, tolerance=None, skip_adsorbates=True) → report
    恰好给 depth 或 bottom_thickness：depth=d → select_height(lo=d, relative_to="top")（顶层平均高度以下 ≥ d Å）；bottom_thickness=t → select_height(hi=t, relative_to="bottom")
    其余同 fix_layers
fixed_indices(s, kind="any")    kind ∈ any | all | partial | a | b | c
constraint_summary(s) → {"fixed": 完全固定数, "partial": 部分固定数, "free": 可动数, "byFlags": {"FFF": 18, "TTF": 4}, "present": 是否有键}
                                                                         # = F0-D constraint_counts 加 byFlags（在它上面扩展，不另写一份）
```

- 验证：下标必须是范围内的整数（越界报错，而不是像 `app.select` 那样忽略，因为这是编辑）；`axes` 非空。
- `fix_layers`/`fix_height` 的警告：
  - 全部行都被固定：`all layers are fixed, nothing will relax`（界面 toast 显示）；
  - 要固定的原子里有 slab 中段（参与聚类原子的高度范围的中间三分之一）没有的元素（D8(c)）：`the fixed layers contain C, O, which the slab interior doesn't: check the adsorbate detection`；
  - 设定语义放开了原先有约束的原子：`report.freed` 中原先部分或完全固定的个数写进 toast（§5.7，D15/E16）。
- 两种"放开"的区别写进文档：`free(全部下标)` 保留全 T 数组，导出的 POSCAR 仍有 Selective dynamics 一节；Free all（`free()`）删除键，POSCAR 不再写这一节。

#### 3.12.3 约束模式与 x/y/z 的等价（全项目唯一规则，放进 F0-D `core/constraints`，K8）

- 一个标志模式（例如 T T F）允许的位移空间是 `V = span{a_k : 可动}`。它能写成笛卡尔约束"固定 X"（X ⊆ {x, y, z}），当且仅当 V 恰好等于 `span{e_q : q ∉ X}`。
  判定用 F0-D `lattice_to_cartesian_mask(flags, cell)` 是否精确（F0-D §3.8.3 的 `in_span`，相对容差 1e-6）。
- 由此派生：
  - **单轴标签** `axis_labels(cell) → ["a"|"x", "b"|"y", "c"|"z"]`：只固定轴 k 的模式精确等于"固定某个笛卡尔轴"时，轴 k 带笛卡尔名。
    界面显示 `a`、`b (y)`、`c (z)` 这种形式；标准取向的六方 slab 得到 `["a", "y", "z"]`。
  - **模式名** `cartesian_name(cell, flags) → "z" | "x, y" | "x, y, z" | None`：用于 "Fix z only"、"fixed along z" 这类文案；不精确时用晶格轴名（"Fix along c only"）。
  - F0-D 的 `constraint_axis_names(s)`（整体用 x/y/z 还是 a/b/c）改为由 `axis_labels` 派生：三个轴都有笛卡尔名时才整体显示 x/y/z（E3）。
- 常用两项的精确条件：**Fix z only**（T T F）需要 a、b ⊥ z；**Fix x, y only**（F F T）需要 c ∥ z。Facet 生成的 slab 两者都满足（C5）。
- `axes` 参数：`"abc"` 的任意非空子集总是接受；含 x/y/z 的字符串（`"z"`、`"xy"`、`"xyz"`）用 F0-D `cartesian_to_lattice_flags` 换成晶格轴，不精确时报错（§3.16）。
  v1 的 `cartesian_to_flags`（True 表示固定，与 C3 相反）删除。

### 3.13 手动标记吸附物

```
promote_adsorbates(s) → int                       # M4、M5 第一次写 adsorbate_id 前也调用它（M4 §10）
    s 中已有 adsorbate_id > 0 → 0
    ads, source = find_adsorbates(s)；source ∈ {tags, tags-oc20, geometry} 且 ads 非空：
        按化学键图（all 规则）在 ads 内求连通块，块按最小原子序号排序，依次写 adsorbate_id = 1, 2, …
    返回编号的块数
mark_adsorbates(s, indices) → 新编号的块数
    promote_adsorbates(s)
    把 indices 中 adsorbate_id == 0 的原子按连通块分组，每块写 next_adsorbate_id(s)（F0-D）
unmark_adsorbates(s, indices=None) → 改变的原子数
    indices 为空 → 所有原子的 adsorbate_id 置 0（键保留，C2 的默认值 0）；否则只置这些原子
```

- 每个都是一次撤销（网页走 `editActive`）。`tags` 不改（C4）；需要时用 "Set atom tags from layers"。
- 标记以后，吸附物来源变为 `adsorbate_id`，Layers 分区的 "Exclude adsorbates" 立即生效。
- 只要还有一个原子的 `adsorbate_id > 0`，取消标记的原子就算基底；全部取消后来源回到 tags 或几何猜测，猜测可能再次认出它们（界面提示 "No atoms are marked now, so adsorbates are guessed again."；不想要猜测时关掉 Exclude adsorbates）。

### 3.14 缓存（JS）

- `findLayersCached(s, opts)`：`WeakMap<Structure, Map<key, result>>`，每个结构最多保留 4 个参数组合。
  key = `structureDigest(s)`（`core/analyses.js:73`：只包括符号、当前帧坐标、晶胞、pbc、帧）＋ `adsorbate_id` 与 `tags` 的摘要 ＋ **解析后的**参数（方向的规范形式、实际容差、`skipAdsorbates`、`group`、`indices` 的摘要）。
  **不含 `selective_dynamics`**：固定或放开原子不会让层分析和吸附物识别重算（E8）。`info.surface.layerTolerance` 通过"实际容差"进入 key。
- `findAdsorbatesCached`、`surfaceAtomsCached`、`bondGraphCached` 同样处理；化学键图在一次层分析、吸附物识别、配位数查询之间共用。
- 撤销或重做恢复的是新的 Structure 对象，缓存自然失效（WeakMap 按对象），然后重算（EM3；预算见 §7.5）。
- Python 不缓存（调用方自己保存结果）。

### 3.16 报错文案（Python `ValueError` 与 JS `Error` 的文本相同；小写开头、无句号、引用用户给的值，04 §3.4）

|---|---|

**打开方式**：命令 `sel.query`（命令面板 "Atom Selection…"，**没有默认快捷键**，E20）；Structure 面板 Selection 分区的 "Select by query…" 按钮；

**布局**：桌面在视图右上角工具栏下方，宽 340 px，标题栏可拖动（应该），位置存在 `localStorage`（只是每个浏览器的便利设置，读写都包 try/catch）；
手机（≤ 920 px）为底部 sheet，高度 `max(50vh, 320px)`，打开时收起面板的底部 sheet 并隐藏选区卡片（两者互斥，E21）；都没有遮罩，视图仍可旋转和点选。
若 F0-A 提供 `shell.floatingCard`（§10.2），就用它；否则 M3 自己实现，避让规则见 §8 R6。

```
Atom Selection                                         [×]
Match [all ▾] of these conditions
 [Element        ▾] [is        ▾] [Pt, O        ]   [−]
 [Layer from top ▾] [≤         ▾] [2            ]   [−]
 [Distance       ▾] [within    ▾] [3.0] Å of [the selection ▾]  [−]

```

**属性下拉**（分组，括号里是查询的 `prop`）：

- Identity：Element（`element`）、Index #（`index`）、Tag（`tag`）、Adsorbate id（`adsorbateId`）
- Layers and position：Layer from top / Layer from bottom（`layer`）、Height（`height`, absolute）、Depth below top（`height`, top）、Height above bottom（`height`, bottom）、
  x / y / z (stored)、Fractional a / b / c（`frac`）
- Neighbourhood：Distance（`distance`）、Coordination number（`cn`，应该）
- Surface：Exposed to a probe（`surface`）、Adsorbate（`adsorbate`）
- Constraints：Constraint（`fixed`）
- Properties：结构里每个标量数值属性一项（`prop:<name>`，例如 "charges"，应该）

**运算符与值控件**：Element → `is` / `is not` + 文本框（datalist 元素表，逗号分隔）；整数属性 → `=`, `≠`, `<`, `≤`, `>`, `≥`, `between`（两个框）；浮点属性 → `<`, `≤`, `>`, `≥`, `between`；
Fractional 的 `between` 允许 lo > hi，旁注 "wraps around"；Distance → `within` / `between` + 半径 + "of" [the selection / the centre of the selection / atom # / point]（后两者再出输入框）；
Constraint → `is` / `is not` + [fully fixed / partly fixed / fixed along a / b / c / any axis]（轴名按 §3.12.3 加笛卡尔提示）；Exposed → `is` / `is not` + [top / bottom / either side]；
Adsorbate → `is` / `is not`；Coordination number 旁有 ⓘ，文案见 §3.11.1。

**实时预览**：条件或模式变化后防抖 120 ms 求值（结构超过 5 万原子时 300 ms）。原子数超过 `analysis_lazy_atoms` 且条件里有 `surface`、`adsorbate` 或 `cn` 时，
不自动预览，显示 "Large structure: press Preview" 和 Preview 按钮。匹配的原子用 `viewer.setHighlight('query', matches, { export: 'never' })` 标出；计数行 `aria-live="polite"`。
预览不改变选区，不进历史，也不标记未保存。卡片关闭、结构切换或撤销时清除高亮并重新求值。

**错误**：在出错的条件行下方显示 `p.err-text`（`role=alert`），例如 "Layer: enter a whole number from 1 to 4."、"Distance: enter a radius from 0 to 50 Å."、"Distance from the selection: select atoms first."；有错误时 Select 禁用。

**应用**：Select（或 Enter）→ 在本地按模式组合后调用一次 `app.select(result, { mode: 'replace' })`，选区只发一次事件。卡片不关闭，可以继续改条件再按（MS 的连按用法）。
焦点在卡片内时按 Esc 关闭卡片，**不**清空选区：卡片根元素在捕获阶段处理 Escape 并阻止冒泡。

**会话记忆与脚本**：本会话保留上一次的查询（模块状态）。"Copy as script ▾"（应该）复制带 `layers`、`bonds` 的完整查询，模式取当前选择的模式（E9）：
JS `facet.selectWhere(<query>, { mode: 'add' })`；Python `from facet.analysis import select_where` 加 `sel = select_where(s, <query>)`。

- 没有约束："No constraints. Select atoms and press Fix (Shift+L), or use Surface ▸ Layers ▸ Fix."；有 SD 键但全为 T："Selective dynamics present · all atoms free"。
- 编辑按钮受 `canEdit` 守卫（F0-A）。
- `signature` 加入约束摘要的哈希（`structureKey` 不感知 props 的问题由 F0-A 修，这里双保险）。

- 超预算时的退路：层聚类可以换成 O(N) 分桶（桶宽 tol/2，桶内间隙必 < tol，只需比较相邻非空桶的 max/min，结果与排序法完全相同）。

### 8.2 需要用户知道的取舍（按推荐实施；用户若有不同意见，改动都很局部）

1. **SrTiO3 等氧化物的次表层原子算"暴露"**：κ = 0.70 时，TiO2 终止 SrTiO3(001) 的次表层 Sr、SrO 终止的次表层 O 都在 Select surface atoms 的结果里。
   它们与 fcc(110) 槽底原子的阈值同为 1.000，任何单一探针都不能保留后者、排除前者。位点识别不受影响（M5 自己的规则）。
2. **分子在真空中部时按最宽的间隙归属**：15 Å 真空里离表面 7 Å 以上的 CO 会画在、也算在 slab 下侧（与 U1 的显示一致）；它仍被认作吸附物。
3. **`cn` 的 smart 规则在高覆盖度下会少计**：1 ML 吸附物时顶层金属之间的键不计（所有顶层原子都连着非金属）；需要时在查询里写 `"bonds": {"metalPairs": "all"}`。
4. **界面里的层参数不进文件**：脚本要复现界面结果时，用 Copy as script（它带上参数），或显式传 `tolerance`/`direction`。

### 10.3 M2（切面与 slab）

1. 切面时层数按 `find_layers(slab, "c", SURFACE_DEFAULTS.layer_tolerance)` 计数，并在 `info.surface` 写 `layerTolerance`（实际用的容差）与 `bulk.reducedFormula`；保证 Cleave 里的 "4 layers" 等于 Layers 列表的行数。
2. 写 `props.tags = layers.from_top + 1`（C4），用 M3 的结果，不另写聚类。
3. 终止面枚举用 `find_layers(ouc, "c", tol)` 的周期模式。**v2 的变化**：没有真空间隙时，切口在环上最宽的间隙（并列时优先晶胞边界），层高落在 [cut, cut + P) 内；
   枚举终止面请只依赖相邻关系与间隙，不依赖切口的位置。
4. 固定底层：`Structure.fix_layers(bottom=N, axes=AXES)`（K9 设定语义；`tolerance=None` 时读 `info.surface.layerTolerance`）。CLI `facet build surface … --fix-bottom N [--axes AXES]` 调用它。
5. `slab_extent(exclude_adsorbates=True)` 用 `find_adsorbates`。

### 10.4 M5（吸附物）

1. 放置的吸附物原子写 `props.adsorbate_id`（1…n）与 `tags = 0`；第一次写之前调用 `promote_adsorbates`（M4 §10 的同一请求），否则已经猜出来的吸附物会变成基底。
2. `exposed` 方法调用 `surface_atoms(structure, side, probe=None, skip_adsorbates=True, details=True)`。**v2 的变化**：`probe` 是相对 R 的比例（默认 0.70），不是 Å；`details` 多了 `exposure` 与 `borderline`。

   展开后的连续位置 = `positions − offset[:, None] · cell[axis]`。

## 未采纳的意见

1. **D1(c)：没有 ≥ 5 Å 间隙时，退回的切口要避开穿过化学键的间隙。** 未采纳。理由：v2 先按 U1 用真空间隙切开；没有合格间隙时切在环上**最宽**的间隙。
   有真空的结构（哪怕不足 5 Å），最宽的间隙就是真空，不会落在分子内部（分子内沿法向的间隙 ≤ 1.4 Å，吸附高度约 2 Å）。
   真正没有真空的是体相，体相里每个间隙都穿过键，这个检查无从满足。D1 举的失败例子（CO 在 7 Å、v1 退回晶胞边界）在 v2 里已经正确。
2. **D2：straddle 降为信息行，只在提供 Centre slab 按钮时显示。** 未采纳，按 E1 删除提示与按钮。理由：U1 要求无感；U1 之后跨边界的 slab 在视图里连续画出，没有需要用户处理的问题；居中属于 M2 的 Slab 分区。`straddles` 字段保留在 API 里。
3. **D4(a)：由 M3 统一实现 `surface_atoms(method="auto" | "exposed")`，`auto` 用 M5 的 CN 规则。** 未采纳，按 E6 处理。理由：M5 已经设计并验证了自己的 `site_atoms`（它还依赖覆盖判据和位点规则），搬进 M3 会让职责交叉、第 1 波的工作量变大。
   D4 想要的"一份代码"在共用部分已经做到：化学键图与 smart 规则只有一份（M3），`exposed` 方法直接调用 M3 的函数。
4. **D4(b)：κ = 0.72。** 部分采纳：采用相对探针，但 κ 取 0.70。理由：原型给出 fcc(211) 台阶底与 bcc(100) 第二层的阈值都是 √3 − 1 = 0.732；κ = 0.72 只差 0.012，台阶边外移 0.05 Å（阈值 0.715）就会翻转。
   0.70 时 TiO2 的 Ti6c 在文献量级的弛豫下（≤ 0.66）仍被挡住，而台阶边的典型弛豫（内收）使台阶底更暴露（0.75–0.86），所以 0.70 两边都有余量；少见的外移组合（台阶边外移、台阶底内移各 0.05 Å）会落到 0.700，这类原子会列为临界原子。
5. **工程审查第三部分第 2 条：保留 1.0 Å 的绝对探针。** 未采纳。理由：原型与 D4 都复现了随晶格常数翻转（bcc(100) 的 Mo 与 W 只差 0.6% 的晶格常数，结果不同）；相对探针在 Pt 上就是 0.97 Å，对 Pt 的结果不变。
6. **E4：`cn` 默认数全部元素对（不加 smart）。** 未采纳，默认用 smart，`"bonds": {"metalPairs": "all"}` 可选。理由：查询配位数最常见的用途是氧化物表面（Ti5c 与 Ti6c、O2c 与 O3c），不加 smart 时阳离子之间的接触都算作键，`cn < 6` 选不出 Ti5c（D5）；
   smart 规则也是 M5 位点配位数的定义，两处一致。E4 的核心诉求（不读显示设置、与 Python 一致、可复现）已全部满足。
7. **D9：把层参数写进结构的 `info.layers`（随 extxyz 导出）。** 未采纳"写进 info"，按结构条目 `entry.layers` 保存。理由：这些是界面的分析参数，写进 `info` 会改变导出的文件（与 U1"不改导出的文件内容"的精神相反），
   改一次容差还会成为结构编辑、产生撤销步骤。按条目保存同样做到了"每个结构一套、随项目保存、Duplicate 时复制"；脚本通过 Copy as script 或显式参数复现。
8. **D10(b)：用 M2 的 `info.surface.layersPerPeriod` 把每 m 个原子面合成一行。** 未采纳这个方法，改用化学计量单元的动态规划。理由：`layersPerPeriod` 是沿法向一个周期里的原子面数，刚玉 (0001) 是 18 个面，而化学计量单元是 3 个面（Al–O3–Al）；
   导入的 slab 也没有这个字段；按 m 分组时，如果顶面不是单元的起点，就会错位。动态规划对 TiO2、CeO2、刚玉、ZnO 都给出期望的单元（原型）。
9. **D18：固定原子光环用红色系。** 未采纳，用蓝色。理由：选区光环是琥珀色（`--accent`），固定光环套在选区光环里面，红色与琥珀色对红绿色弱的用户几乎无法区分；
   MS 的红色是给原子上色（Color by Constraint），本模块的 `constraint` 配色方案照样用红色，想要 MS 风格时选它即可。
10. **D3(b) 的第二个判据"层厚落在 [tol − 0.15, tol]"。** 改为"层内最大台阶 ≥ tol − 0.15"。理由：一层是否会被拆开取决于层内相邻原子的最大高度差，不取决于层的总厚度；按厚度判断会对起伏均匀、台阶很小的层误报。
11. **E1(5)：`wrapped` 模式只用 `wrap_fractional` 的 [0, 1) 规则（与显示无关）。** 部分采纳：与显示设置无关这一点保留，但有间隙的轴先用 U1 的 `unwrap_along_gap`，与 D2 的建议一致。
    理由：无理方向的高度依赖原子被包裹到哪个像；用 U1 的规则才与用户看到的画面一致，而且它只取决于结构本身，不取决于显示开关。
12. **E19：请 F0-A 新增 `json` 参数类型。** 未采纳，查询作为字符串参数，由 `parseQuery` 校验。理由：只有这一个命令需要它，不必扩展 F0-A 的参数 schema。
13. **D20：宽度差 ≤ 0.5 Å 时优先 c。** 不在 M3 定：方向一律来自 F0-A 的 `surface_normal`，这条偏好已转给 F0-A/F0-D（与 M2 的 `set_vacuum` 一致更好）。M3 只在 Direction 标签上显示所用的轴与真空宽度。
14. **E12：`edit fix --where JSON` 作为默认功能。** 列为可选（M3-25）。理由：范围切线（E25）；`--atoms`、`--depth` 和按层选择已经覆盖常见用法。
15. **M4 工程审查（经 E4 转述）建议的判据 `0.1 < d ≤ …`。** 未采纳：保持 v1 的 `0.4 < d < …`，M4 v2 §3.4 已按此定稿，全仓库一份判据比改动边界更重要。
