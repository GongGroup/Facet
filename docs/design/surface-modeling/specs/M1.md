## 0. 关键决定一览

| # | 决定 | 理由（简） |
|---|---|---|
| K1 | **一个矩阵工具**承担 MS 的 Supercell 与 Redefine Lattice：整数 3×3 矩阵（或三个重复数、或 2×2 面内矩阵、或 Wood 文本/预设）。`det = ±1` 时叫"重定义晶格"，`\|det\| > 1` 时叫"超胞"。**手性规则（D7）**：只拒绝"把右手晶胞变成左手晶胞"（`det P < 0` 且输入右手）；输入已是左手时允许 `det P < 0`；另有 **Make right-handed**（交换真空轴以外的两根矢量，笛卡尔坐标不动）。 | 简报 C1；VASP 拒绝左手晶胞，修正方法就是 det = −1 的换基，v1 一律拒绝 det ≤ 0 使左手 POSCAR 无法修正 [V]。 |
| K2 | **格点精确枚举**：P 的 Hermite 标准形给出 `\|det P\|` 个陪集代表，整数运算 `n·adj(P)` 映入新晶胞；顺序按新分数坐标的整数键字典序；对角 P 时与 `repeat` **逐位相同**。 | 精确、O(\|det P\|)，两种语言天然一致 [V1]。 |
| K3 | **包裹只动必须动的轴**（D4、E4）：第 k 轴的新分数坐标 `f'_k = f·adj(P)[:,k]/det` 与旧值相同（`adj(P)` 的第 k 列 = `det·e_k`）时**不包裹**；其余周期轴按 F0-D 的 `wrap_fractional` 规则（`floor(f + 1e-12)`）只按整数个新晶格矢量平移；但**真空轴永远不用 floor 规则**，而是按结果的最宽间隙切口整体放置（F0-D `unwrap_along_gap`），slab 不会被拆开。 | 面内矩阵、Reduce cell、原胞从来不改变 f_c，v1 却沿 c 包裹，把略低于 0 或跨边界的 slab 拆成两半 [V：v1 规则 6 个原子被搬到真空顶部；v2 规则 z 集合不变]。 |
| K4 | **`info.supercellMatrix`** = 整数矩阵 M，"当前晶胞 = M @ 母晶胞"；M1 的每个基变换左乘累计，结果非整数时删除；没有它而有旧键 `info.supercell` 时以 `diag(supercell)` 为初值；总矩阵为对角时同时写 `info.supercell`（与 F0-D 的 `repeat` 相同，E20）。 | C6；累计后命名能写 `(3√3×3√3)R30°`；`repeat` 与 `make_supercell(diag)` 的 info 因此完全相同。 |
| K5 | **命名只有一套机制**（D10、D11、E8、E17）：结构名等于 M2 的自动名（`name == info.surface.name`）时，由 M2 注册的 `info.surface` 处理器更新来源字段并给出新名（C9 的 `Pt(111) p(3×3) 4L`）；否则 `rename_after_cell_change` 在名字里找到旧标签就整体替换为累计标签，找不到就追加，总矩阵幺模时去掉标签。超胞、重定义、约化、原胞、右手化都走它。从预设创建时用预设自己的标签（D13）。 | v1 只有超胞改名、两个面板两套命名；依据来源信息而非"是否 slab"，符合 U1。 |
| K6 | **晶胞参数编辑保持当前取向与手性**（`L_new @ R`）；保留 MS 的 "Keep fractional coordinates fixed"（默认开）；**新增 "Keep the vacuum gap"**（有真空轴时可用，默认开）：面内参数按分数坐标缩放原子，改真空轴矢量（c、α、β）只改真空、原子高度不变；**任何保持笛卡尔坐标的改变真空轴矢量的操作先把 slab 沿间隙接成一块**（D5）。 | 直接用 `cellFromParams` 会偷偷旋转结构；VASP 包裹过的 CONTCAR 改 c 会被撕成 1 + 3 层 [V：v2 间隙 23.20 Å]；F0-A US3 的例子会把 slab 拉长 38 %。 |
| K7 | **应变**：笛卡尔对称小应变张量 `F = I + ε`，输入**张量分量 εij**（不是 Voigt 工程剪切，D15）；模式 isotropic / biaxial / uniaxial / tensor；方向可用 a/b/c/x/y/z/normal、矢量、`{hkl}`、`[uvw]`（DM5）；**`keep_vacuum="auto"` 在所有入口相同**（有真空轴即保持，D18）；另可"按晶格常数缩放"（DM4）。 | 简报要求"只应变面内、保持真空"；同一操作在界面与 API 中结果必须相同（P1/P6）。 |
| K8 | **约化**：二维 Gauss 一份冻结契约 `gauss_reduce_2d(a, b, *, angle="obtuse" \| "acute" \| None)`（平局"半数向零"，M5/M6 共用，E6）；三维 Niggli 的晶胞版叫 `niggli_reduce_cell`（ASE 名，E23）；**Reduce cell 由真空轴决定路径**：有真空轴 → 二维约化 + 真空矢量最近向量修正；没有 → Niggli；显式选 3-D 而真空矢量被移动或反向时给出说明（D6）。 | 3-D Niggli 在 200 个 TTT slab 晶胞中把真空矢量反向 103 次 [V]，在 p(8×8) 上把真空换到 a [V]。 |
| K9 | **原胞（纯平移搜索，无点群）**：身份键默认只用 `occupancy`、`initial_magmoms`、`initial_charges`、`masses`、`selective_dynamics`、`tags`、`poscar_species`（**不用 labels**，D2/E1），数值按排序间隙聚类（D3）；候选按"窗口内分母整除 g 的最简分数"量化，核对后要求置换的所有循环长度等于平移的阶，群闭包不超过 g（D1）；核对按固定的低差异顺序、记住失败过的原子与"空洞"（E11）；默认搜索轴 = 真空轴以外的周期轴（D20）；可选轨道平均坐标（EM4）。 | P1 CIF（包括本应用自己导出的）全被判"已是原胞" [V]；无标签的带噪声 slab 报 E-PC2 或内存耗尽 [V，v1]；v2 全部得到理想群阶，10k 原子 JS ≤ 52 ms、Python ≤ 0.4 s [V]。 |
| K10 | **重定向** = 真旋转（det +1），默认 a ∥ x、b 在 xy 面内；真空轴不是 c 时先循环轮换 (a,b,c)（同步 pbc、约束、`supercellMatrix` 行列与 `info.surface.axis`）；相机随结构一起转；左手晶胞给出说明（c 会指向 −z）。 | 07 §2.7；轮换保持手性。 |
| K11 | **多帧**：改变晶格或原子集合的操作只作用于当前帧并丢弃其余帧（C11，核心函数要求单帧，网页 `singleFrame: true`）；**刚性的整体操作（重定向、平移原点、包裹）处理所有帧**，重定向用当前帧的 R（D19、O4 采纳）。 | 刚性操作不改变帧之间的相对几何，AIMD 轨迹后处理需要；Python 核心层与网页从此一致。 |
| K12 | **约束与派生信息**：原子不随晶胞变的操作调用 F0-D `apply_basis_change`；每个操作按 F0-D §3.7 的表调用 `mark_edited`（对角超胞 `"repeat"`、其余改晶格 `"cell"`、重定向 `"rotate"`、平移/包裹不调用）——计算结果（能量、力、应力）因此被删除并留备注（E9）。 | F0-D v2 已定的唯一入口；与 ASE 的"晶胞一变结果作废"一致。 |
| K13 | **网格分类、预设与 Wood 标签只用一套判据**（D8、D9）：先确定基（调用方的基已是约化基就用它，否则用 Gauss 约化基），再分类（窄容差 1e-3、0.1°，不成功再用"变形"档 3 %、2°），**预设矩阵与标签都在理想化网格上计算**；方形、六方网格上 `p(m×n)`/`c(m×n)` 写成 m ≥ n。 | v1 中网格还判为六方时预设已被拒、标签已丢 [V]；剪切基上 c(2×2) 被标成 p(2×1) [V]。 |
| K14 | **预设与读数相对 1×1 参考网格**（D10、EM1、F0-A D6）：参考网格 = `info.supercellMatrix` 的母网格，否则（有真空轴且 ≤ 5 000 原子）面内平移搜索得到的衬底原胞网格，否则当前网格；预设换算 `P_cur = P_ref · K⁻¹`，不是整数时灰显并说明；矩阵模式总是相对当前晶胞。 | Wood 记号与覆盖度都相对 1×1 网格；在 p(2×2) 上套 "√3" 实际得到 (2√3×2√3)R30° [F0-A 领域审查实测]。 |
| K15 | **一个超胞编辑器**：Structure › Cell › Supercell 与 M2 的 Surface › Slab › Surface supercell 嵌入同一组件、同一核心函数、同一限额与命名；M2 不再有自己的预设表（D10）。 | 同名按钮在两个面板结果不同、两套限额、两种名字（v1 + M2 v1）。 |
| K16 | **`info` 处理器注册表**（E8、DM8）：M1 的每个操作在结果上调用按键注册的处理器（M2 注册 `surface`，M5 注册 `surface.adsorbates`，M6 注册 `interface`），M1 不需要知道它们的字段表；M1 自带 `surface` 的几何默认处理器（`normal`、`axis`）。 | `info.surface` 的 `supercell`、`wood`、组成、吸附物记录在 M1 操作后过期 [E8]。 |

## 1. 用户故事与 Materials Studio 对照

### 1.1 用户故事（逐个走查简报场景中与 M1 有关的部分）

1. **Pt(111) p(3×3) 4 层、底 2 层固定、CO 放 fcc 空位和顶位、导出带 SD 的 POSCAR。** 通常由 M2 在切面时直接选 `p(3×3)`；若用户拿到的是 1×1 slab，
   在 Structure › Cell › Supercell 选 Repeat `3 × 3 × 1`：读数 `4 atoms → 36 atoms · p(3×3) of the 1×1 cell`，视图里出现虚线新晶胞；点 **Create supercell**。
   结果 36 个原子、18 个 `[F,F,F]`（约束精确保持，无备注）、`tags` 逐像复制、`info.supercellMatrix = diag(3,3,1)`、`info.supercell = [3,3,1]`。
   名字：M2 的自动名 `Pt(111) 4L` → M2 的处理器重算为 `Pt(111) p(3×3) 4L`（C9）；用户改过名字时追加 `3×3×1`。底层略低于 z = 0（弛豫后常见）时 slab 仍连续（K3）[V]。
2. **Cu(100) c(2×2)-O、4 重空位；Ag(111) (√3×√3)R30°。** Presets 菜单在方形网格上给出 `c(2×2) = (√2×√2)R45°`（det 2）、`c(4×2)`、`(√5×√5)R26.6°`……；
   从 `c(2×2)` 预设创建时名字写 `Cu(100) c(2×2) 4L`（D13）。Ag(111) 上 `(√3×√3)R30°` 自动按 120°/60° 网格填 `[[2,1],[-1,1]]` 或 `[[1,1],[-1,2]]`，
   a′ = 5.0092 Å、γ′ = 120°，4 层 12 个原子 [V1]。网格因弛豫或单轴应变偏离六方 ≤ 3 %/2° 时预设仍可用并注明 `Mesh: hexagonal (distorted by 0.20 %)`（K13）[V]。
3. **Ru(0001)/Co hcp(0001)；ZnO (10-10)。** hcp(0001) 网格与 fcc(111) 同为六方，预设相同；hcp 与 fcc 空位的区别由 M5 处理，M1 只保证超胞后 `tags` 与层序不变。
   ZnO(10-10) 的网格是矩形（a × c），六方预设灰显并说明 `(√3×√3)R30° does not fit this surface mesh (rectangular)`，`p(2×1)`、`c(2×2)` 可用 [V]。
4. **fcc(110) 短桥与长桥、fcc(211) 台阶、bcc Fe(110)。** fcc(110) 矩形网格：`p(2×1)`、`p(1×2)`（缺列重构）、`c(2×2)`、`c(4×2)`；在剪切基上同一子格仍得到
   `c(2×2)`（v1 得到 `p(2×1)`，D8）[V]。fcc(211) 网格为矩形（台阶方向 × 台阶周期），只有 p(m×n) 与矩阵模式。bcc(110) 为有心矩形，Gauss 约化 109.47°（钝角）或 70.53° [V1]。
5. **金红石 TiO2(110) 删桥氧做氧空位**：p(2×1)、p(4×2) [V1]；删原子后 Primitive cell 正确报 `No lattice translation found within 0.05 Å.`（不再说"已是原胞"，E29）；
   顶层空位排在原子序末尾也不再拖慢搜索（v1 最坏 1–6 s → v2 34–390 ms，E11）[V]。
6. **SrTiO3(001)**（SrO/TiO2 终止、7 层对称 slab）：方形网格预设 `c(2×2)`、`(√5×√5)R26.6°`；外延应变研究用 Strain › Biaxial，平面默认取表面平面，
   `Keep the vacuum gap` 默认勾选（K7）；按目标晶格常数缩放：输入 `from 3.905 to 3.945 Å` 自动换算 +1.0243 %（DM4）。极性提示属于 M2。
7. **CeO2(111)、NaCl(100)、刚玉 (0001)**：原胞 CeO2 3 原子、NaCl 2 原子 [V]；刚玉的六方惯用胞（R 心）可由平移搜索约化为 10 原子菱方原胞，再用 **Conventional cell**
   回到六方设置（`hexagonal R`，Q 的 det 3）[V：R 心的 30 原子刚玉型晶胞 → 10 原子 → 六方 R]。
8. **从惯用胞切面与最小表面网格；切原胞 POSCAR**：M2 调用 `primitive_cell(ouc)`（三轴）得到最小网格，惯用胞与原胞给出同一 slab；从 **CIF 读入**的惯用胞同样成立
   （v1 因 `labels` 失败，D2/E1）[V：P1 CIF → 1 原子]。fcc/bcc 原胞上 F0-A 的 Miller 控件提示 "Use Cell › Conventional cell first"，即本模块的 K17 [V]。
9. **石墨烯 / MoS2 单层**（已是 slab）：√3 → 6/9 个原子，4×4 → 32 个原子，pbc 与 c 不变 [V1]；`p(30×30)` 石墨烯无标签带噪声时原胞搜索得到 900 阶 [V]。改真空属于 M2。
10. **VASP CONTCAR**（pbc T T T，Selective dynamics，底层在分数 z = 0 或被包裹到 0.9995，c 有 15 Å 真空）：
    - 2×2×1：约束精确保持；面内矩阵不沿 c 包裹，底层不会被挪到真空顶部（K3）[V]；
    - Reduce cell：真空轴由 F0-A `surface_normal` 判定为 c → 只约化 a、b，c 只做"尽量垂直"的整数修正 [V：p(8×8) 的 C 保持 c]；
    - Primitive cell：默认只在面内搜索，回到 1×1 [V]；
    - Lattice parameters 改 c（Keep fractional 关掉、或 Keep the vacuum gap 开）：先把被包裹的底层接回，间隙 15 → 23.2 Å [V]；
    - Re-orient：c 倾斜或整体旋转过的 CONTCAR 转回 a ∥ x、法向 ∥ z；真空在 a 时先循环轮换 [V]；左手 CONTCAR 先 **Make right-handed**（交换 a、b）[V]。
11. **大体系**：Pt(111) p(6×6) 6 层（216 原子）上一切交互 < 20 ms；1 万原子 slab 超胞 JS 9 ms [V1]、面内原胞搜索 JS 34–52 ms（无论缺陷在原子序何处）[V]；
    12 万原子超胞前 F0-A 的大结构确认（30 000 原子以上），撤销一步约 4.6 MB（F0-A 二进制快照，64 MiB 预算约 13 步，EM8）。

### 1.2 与 Materials Studio 对照（06 报告）

| 功能 | Materials Studio | Facet（本规格） | 不同及理由 |
|---|---|---|---|
| 对角超胞 | Build › Symmetry › Supercell，A/B/C，*Create Supercell*（06 §4） | Cell › Supercell 的 Repeat 模式；命令 `Supercell…`（别名 Supercell、Create Supercell） | 同一工具也接受矩阵、预设、Wood 文本（K1） |

### 3.2 整数运算（`core/intmath.py` / `core/intmath.js`，M1 的 T1 建立，M2 之后追加 `plane_basis`）

全部用 Python `int`；JS 用 Number，每个乘积检查 `Number.isSafeInteger`，否则 `RangeError('integer overflow in lattice arithmetic')`。
除法一律**向下取整**（Python `//`，JS `Math.floor(a / b)`）。原胞 HNF 的峰值在 1 万原子 slab 上为 6.3e5 [工程审查实测]，远低于 2^53。

```text
egcd(a, b) → (g, x, y)，a·x + b·y = g ≥ 0
int_det3(M)、int_adjugate3(M)（M @ adj = det·I）、is_unimodular(M) ⇔ |det| = 1
as_int_matrix(P, what)：长度 3 → 对角；2×2 → 面内嵌入（嵌入轴由调用方给出，默认 a、b）；3×3；有限、|p − round(p)| ≤ 1e-8、|p| ≤ max_matrix_entry
hermite_normal_form(rows)：行式，k ≥ 3 行，秩 3；上三角、对角为正、0 ≤ H[i][j] < H[j][j]（v1 §3.2 的算法不变）
hermite_normal_form_2d(M) → (a, b, c)：2×2 情形，[[a, b], [0, c]]，a, c > 0，0 ≤ b < c（M6 的命名，E6）
hnf_matrices_2d(n)：[[i, j], [0, n/i]]，i | n，0 ≤ j < n/i；按 (i, j) 升序（E6）
supercell_lattice_points(P)：D ← |det P|；P' ← det P < 0 ? −P : P（取负不改变格）；对 P' 按 v1 §3.2 枚举（K2）
```

M2 原先请求的 `hnf_rows` 不另设别名：M2 改用 `hermite_normal_form`（一个函数一个名字，E7-5）。

### 3.3 `make_supercell`

```text
make_supercell(s, P, wrap=True, *, label=None) → CellOpResult
    require_single_frame(s, "make_supercell")
    P ← as_int_matrix(P, "supercell matrix")；D ← int_det3(P)
    D == 0 → E-SC1；|D| > max_supercell_det → E-SC3
    D < 0 且 det(s.cell) > 0 → E-SC2（会变成左手晶胞）                       （K1 手性规则；输入左手时允许，结果右手）
    s.cell 为空或 pbc 全 F → E-SC4；pbc[k] = F 的轴：P 的第 k 列必须是 e_k → 否则 E-SC5
    pts ← supercell_lattice_points(P)；new_cell ← P @ cell
    pos ← [ r_a + n @ cell  for n in pts for a in atoms ]（cell-major，与 repeat 同式）；src ← [ a for n in pts for a in range(N) ]
    out ← s.copy()；out._remap(src, positions=pos, frames=[])；out.cell ← new_cell
    wrap → (pos, shift) ← wrap_after_basis_change(out, P, vacuum_axis(s))             （§3.3.1；shift 供网页 imageShift）
    apply_basis_change(out, old_vectors=cell, new_vectors=new_cell)                    （F0-D；只检查部分约束）
    renumber_adsorbate_ids(out, n_images=|D|, n_atoms=N)                               （§4.1）
    mark_edited(out, "repeat" if P 对角 else "cell")                                  （K12）
    update_supercell_matrix(out.info, P, s.info)                                        （§3.5.5：左乘、旧键初值、对角时写 info.supercell）
    apply_info_handlers({kind: "supercell", old: s, new: out, matrix: P, images: |D|, id_offset: V})   （§3.15）
    out.name ← cell_change_name(s, out, P, label)                                       （§3.5.4）
    notes：N-SC1（重复或混入真空轴）、N-SC2（真空矢量反向）、N-LH（结果仍是左手）
    返回 {structure: out, src, shift, matrix: P, label: supercell_label(...), lattice_changed: True, changed: True, notes}
```

#### 3.3.1 包裹（K3）

```text
changed_axes(P) = { k : adj(P)[:, k] ≠ det(P)·e_k }               （f'_k = f·adj(P)[:,k]/det；其余轴 f'_k ≡ f_k，不需要也不允许包裹）
wrap_after_basis_change(out, P, k_vac):
    f ← out.positions @ inv(new_cell)；shift ← 0
    对 k ∈ changed_axes(P) 且 pbc[k]：
        k == k_vac 且 find_vacuum_gap(out, k, min_width=0) = g 非空 → shift_k ← floor(f_k − gap_cut(g))   （整体放在 [cut, cut+1)，slab 不被拆开）
        否则 → shift_k ← floor(f_k + 1e-12)                                                        （F0-D wrap_fractional 的规则）
    shift ≠ 0 的原子：pos ← pos − shift @ new_cell；其余原子坐标逐位不变
```

- 面内矩阵（√3、c(2×2)、p(n×m)）、Reduce cell 的 C、原胞（群无 c 分量时）的 `changed_axes` 都不含真空轴 → 沿 c 的坐标**逐位不变**；
  `a' = a + c` 这类混入 c 的矩阵、`diag(1,1,2)` 这类沿 c 叠 slab 的矩阵才沿 c 放置，且按间隙切口整体放置。
- [V] 底层在 z = −0.01（f_c = −0.00046）的 TTT Pt(111) 4L：√3、3×3×1、60°→120° 的 C 之后 z 集合不变、slab 连续（v1 规则：6 个原子被搬到真空顶部）；
  以 z = 0 居中的跨边界 slab（各层 −3.39、−1.13、1.13、3.39 Å）：3×3×1 与 √3 之后 z 集合不变（v1：底下两层被搬到 18.39、20.65 Å）；
  `a' = a + c`、`diag(1,1,2)`：每个 slab 都是一块 [`test_ops2.py`]。
- `make_supercell(diag, wrap=False)` 与 `repeat` 逐位相同；`wrap=True` 对已包裹（f ∈ [0, 1−1e-12)）的输入也逐位相同 [V1]。结果是 F0-D `Structure.wrap()` 的
  不动点（至多差 1e-11 Å：`wrap()` 把 [−1e-12, 0) 的分数坐标置 0）——但**沿真空轴的 floor 规则除外**，这正是 K3 的目的；文档写明 `Structure.wrap()` 会拆开跨边界的 slab，
  界面的 Wrap 命令用 `wrap_into_cell(keep_slab=True)`。
- 浮点：Python `np.linalg.solve(cell.T, pos.T).T`，JS `inv3` 后行矢量乘；两者差 ~1e-16，只在 `f + 1e-12` 恰好跨整数时影响结果（原子本就在晶胞面上）；
  金标比较前按新晶胞包裹并允许"面上原子差一个晶格矢量"。
- 跨边界读数：`wrap=True` 且 slab 沿真空轴跨过晶胞边界时 note N-WR1（建议 M2 的 Centre slab），不自动居中（那是 M2 的显式编辑）。

### 3.5 网格、Wood 标签与命名

#### 3.5.1 网格分类 `classify_mesh(a, b)`（K13）

```text
(u, v, U) ← gauss_reduce_2d(a, b, angle="obtuse")
kind ← mesh_kind(u, v, 窄档 1e-3, 0.1°)：|u| ≈ |v| 且 γ ≈ 120° → hexagonal；γ ≈ 90° → square / rectangular；
                                        |u| ≈ |v| 或 2|u·v| ≈ |u|² → centred-rectangular；否则 oblique
kind ∈ {centred-rectangular, oblique} 时再用"变形"档（3 %、2°）判一次：得到 hexagonal / square / rectangular → kind 取它，distorted ← True
基：调用方的基"已约化"（|a·b| ≤ (1 + 0.1)·min(|a|², |b|²)/2，任意次序、60° 或 120°）→ base = (a, b)，W = I；否则 base = (u, v)，W = U
理想化 ideal = (p_i, q_i)：与 base 同平面、p 方向不变；hexagonal：两长取平均、夹角取 base 自己的 60° 或 120° 精确值；square：等长、90°；
                          rectangular：长度不变、90°；等长的 centred-rectangular：等长、角度不变；oblique：不变
distortion ← max(相对长度偏差, 角度偏差（弧度）)
返回 {kind, distorted, distortion, base, W, ideal}
```

- "已约化"判据带 10 % 容差：应变 3 % 的 120° 网格只超过平局边界几个百分点，而剪切基（`[[1,0],[1,1]]` 等）超过 50 % 以上，二者分得开 [V]。
- [V]：Pt(111) 120°/60° → hexagonal；Cu(100) → square；fcc(110)、金红石(110) → rectangular；bcc Fe(110) → centred-rectangular；单轴 +0.05 % → hexagonal；
  +0.2 %～+4 % → hexagonal（distorted）；分量噪声 1e-5～1e-3 Å → hexagonal，√3 标签与预设 300/300 都在（v1：标签丢失 67 %～100 %，预设拒绝 0～23 %）。

#### 3.5.2 `wood_label(M, a, b)`（2×2 整数，det > 0；返回字符串或 None）

```text
m ← classify_mesh(a, b)；M_b ← M @ inv(W)（整数：同一子格在 base 中的表示）
M_b = I → "p(1×1)"（写死，调用方决定是否省略，D21）
M_b 对角 → "p(m×n)"
否则 → v1 规则 2–5 作用于 (M_b, ideal)：六方上用户自己的正交基 → (p×q)rect；通用 Wood 搜索 → p(p×q) 或 (p×q)Rθ°；六方约化基正交 → rect；
       矩形/方形上的有心胞 → c(m×n)；否则 None
方形、六方网格上 p(m×n)、c(m×n) 写成 m ≥ n（a、b 等价；矩形等其他网格保持轴序：fcc(110) 的 p(1×2) 与 p(2×1) 不同）
```

- 因为基先确定、再在理想网格上计算，标签与基无关（D8）、与预设一致（D9）。[V] fcc(110)、fcc(100) 的 c(2×2)、c(4×2) 在三种等价基上标签相同
  （v1：`p(2×1)`、`(√6×1.63)R35.3°`、None）；v1 §3.5.2 表中的 20 个用例结果不变 [`test_ops2.py`]。
- 数值格式按 §3.1（`fmt_sig3`、`fmt_angle`，半数向上，两种语言逐字相同）；长度比写成 `s√r` 的规则不变（k = x² 接近整数 K 时）。

#### 3.5.3 三维标签 `supercell_label(P, cell, *, reference=None, style="bulk")` 与 `matrix_label(M)`

```text
P 对角：style == "surface" 且 P_kk == 1（k 为真空轴，默认 c）→ "p(n1×n2)"；否则 format_repeat → "n1×n2×n3"
P 为面内形式（真空轴的行与列为 e_k）：w ← wood_label(P 的面内 2×2, reference 网格或 cell 的面内两行)；w 非空 → w + ("" if P_kk == 1 else f" ×{P_kk}")
否则 → matrix_label(P)
matrix_label(M) = "[" + ", ".join(每行用空格连接的整数) + "]"，2×2 写 "[2 1, -1 3]"，3×3 写 "[2 1 0, -1 1 0, 0 0 1]"（ASCII 减号；M2 的网格记号也用它，E8-4）
```

`style="surface"` 只供 M2 生成自动名（C9 的 `Pt(111) p(3×3) 4L`）；M1 追加后缀时用 `style="bulk"`（U1：不按 slab 换风格）。

#### 3.5.4 名字 `cell_change_name(old, out, P, label)`（K5）

```text
old.info.surface 存在且 old.name == old.info.surface.name，且 surface 处理器给出了 out.info.surface.name → 返回 out.info.surface.name   （M2 的自动名，§3.15）
否则 → rename_after_cell_change(old.name, P, cell=old.cell, previous=old 的累计矩阵, label=label)
rename_after_cell_change(name, P, *, cell, previous, label=None)：
    prev ← previous ?? diag(old.info.supercell) ?? None；total ← P @ prev（prev 为空时 total ← P）
    parent ← prev 非空 ? inv(prev) @ cell : cell
    lab_new ← label 且 total == 该预设的矩阵 ? label : supercell_label(total, parent)        （D13：从预设创建时用预设自己的标签）
    total 幺模 → lab_new ← ""                                                              （原胞把 p(3×3) 变回 1×1 时去掉标签，D11）
    old_lab ← supercell_label(prev, parent) 的 bulk/surface 两种写法、旧的 ASCII "AxBxC" 与 JS 旧的 " (A×B×C)" 中在 name 里最后出现者
    找到 → 在该位置替换为 lab_new（并去掉多余空格）
    否则 → P 对角 → add_repeat_suffix(name, diag(P))；否则 name + " " + lab_new（lab_new 为空时不变）
```

- [V1] `Pt(111) 4L` → √3 → `Pt(111) 4L (√3×√3)R30°`；p(3×3) 再 √3 → `Pt(111) 4L (3√3×3√3)R30°`、`supercellMatrix = [[6,3,0],[-3,3,0],[0,0,1]]`；
  `hcp [[2,1,0],[-1,1,0],[0,0,2]]` → `Ru hcp (√3×√3)R30° ×2`。按 v2 规则（T5 的金标用例）：p(3×3) 后原胞 → `Pt(111) 4L`（v1 仍写 3×3×1，D11）；
  Cu(100) 用 c(2×2) 预设 → `Cu(100) 4L c(2×2)`（v1 为 `(√2×√2)R45°`，D13）。
- 名字是 M2 自动名时由 M2 的 `surface_name(info)` 生成（`Pt(111) p(3×3) 4L`、`Pt(111) (3√3×3√3)R30° 4L`），M1 不拼字符串；M2 没注册处理器时退回上面的通用规则。

#### 3.5.5 `info.supercellMatrix` 的维护 `update_supercell_matrix(info, P, old_info)`

- `prev ← old_info.supercellMatrix ?? diag(old_info.supercell) ?? None`（D17：旧文件的超胞历史不丢）；
- 超胞、重定义、右手化、约化、惯用胞：`M ← P @ prev`（prev 为空时 `M ← P`）；原胞：`M ← T @ prev`，为整数时写入，否则删除；重定向轮换：行与列按同一置换（§3.13）；
- 写入后：M 为对角 → `info.supercell = diag(M)`，否则删除 `info.supercell`（E20：与 F0-D `repeat` 写法一致，`make_supercell(diag)` 与 `repeat` 的 info 完全相同）；
- M 幺模且不是单位阵也保留（例如约化后的 `[[1,0,0],[-1,1,0],[0,0,1]]`，参考网格要用它）；单位阵时删除两个键。
- 晶胞连续形变（晶胞参数、应变、改真空、重定向）后关系仍成立（母晶胞同样被形变），键不变。R4（有人直接 `set_cell` 到无关晶胞）：`set_cell(scale_atoms=False)` 的新旧晶胞
  不是整数关系时删除该键。

CLI `--surface-cell`、REST `spec`、M2 的 Wood 文本都走它。

#### 3.6.4 参考（1×1）网格 `reference_mesh(s, *, max_atoms=reference_mesh_atoms)`（K14、EM1）

```text
k ← vacuum_axis(s) ?? 2；(i, j) ← k 以外的两轴
M ← info.supercellMatrix；M 存在且为面内形式（M 的第 k 行、第 k 列为 e_k）
    → K ← M 的 (i, j) 子块；ref ← inv(K) @ [a_i; a_j]；source "supercellMatrix"
否则 vacuum_axis(s) 非空且 N ≤ max_atoms：
    sub ← adsorbate_id = 0 的原子（衬底）；r ← primitive_cell(sub, axes=(i, j))（默认容差、默认身份属性）
    r 的群阶 > 1 → ref ← r 的面内两行（Gauss 约化）；K ← r.supercell_matrix 的 (i, j) 子块；source "translations"
否则 → ref ← 当前面内两行；K ← I；source "current"
```

- 结果按（结构条目 id、`rev`）缓存；网页在 Supercell 分区展开时计算（≤ 5 000 原子 JS < 20 ms，不需要异步）。
- 来源为 "translations" 时**只用于读数与预设**，不写 `info.supercellMatrix`（不为导入的结构编造来源）；名字仍按 §3.5.4（相对当前晶胞）。
- [V] 无 `supercellMatrix` 的 p(2×2) slab → K = 2I（translations）；p(3×3) + CO（`adsorbate_id`）→ K = 3I；带 `supercellMatrix` 的 p(3×3) → K = 3I；
  √3（相对 1×1）在 p(3×3) 上 `P_cur = [[0.667, 0.333], [-0.333, 0.333]]` 不是整数 → 不适用 [`test_ops2.py`]。
- M5 由 `info.supercellMatrix` 还原 1×1 网格的写法（`inv(M[:2,:2]) @ [a; b]`）改为调用 `reference_mesh`（它检查面内形式，D17）。

#### 3.6.5 读数与 F0-A `imatrixInput` 的钩子

- `area(value)`：`(2√3×2√3)R30° of the 1×1 cell · 12× its area · 4 → 48 atoms`（相对参考网格；参考网格 = 当前网格时省略 "of the 1×1 cell"）；
  从预设选中时写预设标签并在后面注明等价写法 `c(2×2) = (√2×√2)R45°`（D13）。
- `warn(value)`（F0-A §10.2 指定的两句，文案由 M1 定）：
  - 真空轴的行或列不是 e_k → `This repeats the slab along the vacuum axis; use a 2×2 surface matrix.`（N-SC1）
  - det > 0 但新真空矢量与旧的点积 < 0 → `This matrix turns the slab upside down (c reverses); the top and bottom surfaces swap.`（N-SC2）
- 网格读数：`Mesh: hexagonal (a = b = 2.772 Å, γ = 120°)`；变形时 `Mesh: hexagonal (distorted by 0.20 %)`。

### 3.7 重定义晶格与右手化

#### 3.7.1 `redefine_lattice(s, U, wrap=True)`

`U ← as_int_matrix(U, "lattice matrix")`；`|det U| = 1`，否则 E-RL2（指向超胞）；`det U = −1` 且输入右手 → E-RL1（文案见 §3.17：`negate one row, or swap two rows`，
二选一，E14）；输入左手时 `det U = −1` 允许（结果右手）。复用 §3.3（|D| = 1 时格点只有 (0,0,0)，`src` 恒等，原子顺序不变）；`mark_edited(out, "cell")`；
`info.supercellMatrix` 左乘 U（不存在时不写）；名字按 §3.5.4（总矩阵幺模时去掉旧标签）。可选 O1 的有理数矩阵见 §2.3。

#### 3.7.2 `make_right_handed(s)`（D7、DM1）

```text
det(cell) > 0 → unchanged（note "The cell is already right-handed."）
k ← vacuum_axis(s) ?? 2；(i, j) ← k 以外的两轴；U ← 交换 I 的第 i、j 行（det −1）
返回 redefine_lattice(s, U)          （笛卡尔坐标不动；真空轴与 slab 的"上方"不变；标志的 i、j 分量随之交换，apply_basis_change 精确；
                                      info.supercellMatrix ← U @ M；info.surface.axis 不变）
```

- 为什么交换而不是把 c 取负：取负会把 slab 上下翻转（M3 的顶层、M5 的放置面都依赖 +c 一侧）。
- [V] a、b 互换的 Pt(111) slab（det −145.0）：`make_right_handed` 给出 `U = [[0,1,0],[1,0,0],[0,0,1]]`，结果右手、原子坐标逐位不变；
  右手晶胞上同一矩阵被拒，文案含 `negate one row, or swap two rows`；左手晶胞上 det +3 的 √3 允许（结果仍是左手，附 N-LH）[`test_ops2.py`]。
- 左手结构的提示：摘要与 Cell 分区读数 `Left-handed cell: VASP refuses such cells. [Make right-handed]`；F0-D 的 POSCAR 导出检查已有左手晶胞警告（F0-D K9）。

### 3.8 晶胞参数与晶胞矢量

#### 3.8.1 校验 `check_cellpar(a, b, c, alpha, beta, gamma)`（v1 不变 [V1]）

长度有限且 > 0；角度有限且 0° < x < 180°；**α < β + γ，β < α + γ，γ < α + β，α + β + γ < 360°**（E-LP3）；
`1 − cos²α − cos²β − cos²γ + 2 cosα cosβ cosγ > 1e-10`（E-LP4）。两万组随机角度上与"Gram 行列式 > 0"结论相同。
JS 现有 `cellFromParams` 不校验（01 §4.2）；新的 `cellparToCell` 先调用 `checkCellpar`，旧函数保留给现有调用者。

#### 3.8.2 保持取向 `oriented_cellpar_to_cell(cellpar, reference)`（v1 不变 [V1]）

`standard_frame(cell, "a-x")`：x̂ = â，ŷ = unit(b − (b·x̂)x̂)，ẑ = x̂ × ŷ（det R = +1）；`"c-z"`：ẑ = ĉ，x̂ = unit(a − (a·ẑ)ẑ)，ŷ = ẑ × x̂。
`oriented_cellpar_to_cell(p, ref) = cellpar_to_cell(*p, handed=sign(det ref)) @ standard_frame(ref)`：新 a ∥ 旧 a，ab 平面不变，左手保持左手。

#### 3.8.3 `set_lattice_parameters(s, *, a=None, …, gamma=None, scale_atoms=True, keep_vacuum="auto")`

```text
require_single_frame；cp ← 当前参数，用给出的值覆盖（未知名字 → E-LP0）；check_cellpar；new ← oriented_cellpar_to_cell(cp, s.cell)
k ← vacuum_axis(s)；kv ← (keep_vacuum == "auto") ? (k 非空) : bool(keep_vacuum)；kv 且 k 为空 → E-ST5
vac_changed ← k 非空且新旧真空轴矢量不同（逐元素 > 1e-12 Å）
kv：                                   （面内参数按分数坐标缩放；真空轴矢量的改变只改真空，原子高度不变）
    pos ← make_contiguous 后的坐标（沿 k，F0-D 规则）；n̂ ← unit(a_i × a_j)（朝 a_k 一侧）；z ← pos·n̂；
    (x, y) ← pos 的面内分量在 (a_i, a_j) 下的坐标；pos' ← x·a_i' + y·a_j' + z·n̂'（n̂' 同法取新晶胞的，ab 平面方向不变故 n̂' = n̂）
    apply_basis_change(out, old = cell @ F_keepᵀ, new)            （F_keep 为面内块 ⊕ 法向恒等）
scale_atoms 且非 kv → pos ← frac @ new（标志不变）
非 scale_atoms → pos 不变；vac_changed → 先 make_contiguous（D5）；apply_basis_change(old, new)
mark_edited(out, "cell")；apply_info_handlers({kind: "deform", old, new, deformation: F = (inv(cell) @ new)ᵀ})
```

- 未修改的字段保持**精确**的当前值（界面只解析被编辑过的字段）。
- [V] Pt(111) 4L、15 Å 真空、`keep_vacuum` 开：c 21.79 → 30 Å 原子高度逐位不变（间隙 23.20 Å）；a = b 2.7719 → 2.80 Å 面内分数坐标不变、高度不变；
  VASP 把底层包裹到 f_c = 0.9995 的 CONTCAR 保持笛卡尔改 c → 先接回 1 个原子，间隙 23.20 Å（v1：14.99 Å，slab 被撕成 1 + 3 层）[`test_ops2.py`]。
- 有真空轴而 `keep_vacuum` 关、编辑 c/α/β 时，读数提示 N-LP2；六方网格上 γ 在 60° 与 120° 之间切换时提示 N-LP1（D14：[V，审查脚本] 最近邻 2.772 → 2.445 Å）。

#### 3.8.4 `set_cell(cell, scale_atoms=False)`

- 3×3、有限、`|det| > 1e-9·∏|a_i|`（与 `fixDegenerateCell` 同一判据），否则 E-SC6；
- `scale_atoms=True`：`pos ← frac @ new`；新旧手性不同 → E-SC7；
- `scale_atoms=False`：坐标不变；真空轴矢量变化时先 `make_contiguous`（D5）；`apply_basis_change`；新旧晶胞不是整数关系时删除 `info.supercellMatrix`；
- 新晶胞是旧晶胞的纯旋转（`new @ newᵀ ≈ old @ oldᵀ`，1e-9 相对）→ `mark_edited(out, "rotate", rotation=R)`；否则 `"cell"`。

### 3.9 平移原点与包裹

```text
shift_origin(s, origin, *, fractional=True, axes=None, wrap=True):
    origin 为 3 个有限数（否则 E-SO1）
    axes ← axes ?? (vacuum_axis(s) 非空 ? 另两轴 : (0, 1, 2))     （D4：有真空轴时默认只平移面内，法向分量置 0）
    t ← −origin；笛卡尔输入先换成分数坐标；不在 axes 中的分数分量置 0（有真空轴时即法向分量）
```

### 3.10 应变

#### 3.10.1 张量

| 模式 | ε（e = percent / 100） | 方向参数 |
|---|---|---|
| `isotropic` | e·I | — |
| `biaxial` | e·(I − n̂ n̂ᵀ) | `direction` = 平面法向 n̂：默认 `surface_normal(s).normal`（F0-A；没有表面时 c*）；可给 `a`/`b`/`c`/`x`/`y`/`z`、矢量、`{"hkl": [h,k,l]}`（n̂ = `miller_normal(cell, hkl)`）、`{"uvw": [u,v,w]}`（n̂ = 该方向）（DM5）；界面 Plane 选项 `Surface plane`/`a–b`/`b–c`/`a–c`/`(h k l) plane…` |
| `uniaxial` | e·û ûᵀ | `direction` 必填：`a`/`b`/`c`（晶格矢量方向）、`x`/`y`/`z`、`normal`、矢量、`{"hkl"}`（晶面法向）、`{"uvw"}`（晶向） |
| `tensor` | 对称张量 ε；`tensor=` 6 个**张量分量** `[εxx, εyy, εzz, εyz, εxz, εxy]`（百分数；**不是** Voigt 工程剪切 γ = 2ε）或 9 个（须对称，1e-12） | — |

`F = I + ε`；`det F ≤ 0` → E-ST3；\|ε\| 的最大分量 > 50 % → E-ST2。`apply_strain(s, percent=None, *, mode="isotropic", ...)`：tensor 模式不用 `percent`
（给了也报 E-ST4，E27）。文档与界面写明"张量分量 εij"；从 Voigt 应变（第 4–6 分量为 γ）换算时剪切分量除以 2（D15）。
`uniaxial a` 是"沿 a 方向的笛卡尔拉伸"：六方晶胞的 b 也会变长；只想改 a 的长度应使用 Lattice parameters（界面提示）。
**按晶格常数缩放**（S7）：界面把 `from`/`to` 换算成 `percent = (to/from − 1)·100`（不取整），API 直接传 percent。

#### 3.10.2 普通应用（`keep_vacuum` 为假，或没有真空轴）

`cell' = cell @ Fᵀ`，`pos' = pos @ Fᵀ`（行矢量，C1）；约束不变（K12）；`mark_edited(out, "cell")`。
[V1] Pt(111) 双轴 +2 %：a、b ×1.02，c 与原子 z 不变；Pt 体相 −1 %：晶胞 ×0.99；hcp 单轴 c +3 %；含剪切的张量体积比 = det F。

#### 3.10.3 `keep_vacuum`（`"auto"` = 有真空轴时为真，K7、D18；显式 True 而无真空轴 → E-ST5）

v1 §3.10.3 的算法不变：k = 真空轴；`P∥ = I − n̂n̂ᵀ`；面内块 `A = I + P∥ ε P∥`；`e_n = n̂ᵀ ε n̂`；混合剪切 `P∥ ε n̂` 忽略并 note N-ST2；
沿 k 的展开改用 F0-D 的 `unwrap_along_gap`（切口在间隙中点）；`r' = A·(r − z n̂) + (z_m + (1 + e_n)(z − z_m)) n̂`；
`a_i' = A a_i`，`a_j' = A a_j`，`a_k' = A (a_k − (a_k·n̂)n̂) + (a_k·n̂ + e_n·t) n̂`；`apply_basis_change(old = cell @ F_keepᵀ, new = cell')`。
[V1] 间隙 15.0000 → 15.0000 Å、厚度 6.7896 → 6.9254 Å（各向同性 +2 %）；仅法向 −3 % → 6.5859；倾斜 c 的面内分量按 A 缩放、间隙不变。
勾选 Keep 后的各向同性应变不是各向同性形变，空间群标签照样清除（E25，`"cell"` 本来就清除）。

### 3.11 约化

#### 3.11.1 二维 Gauss `gauss_reduce_2d(a, b, *, angle="obtuse")`——冻结契约（E6；M2、M5、M6 共用，M5/M6 删除各自的版本）

```text
要求 |a × b| > 1e-8·|a||b|（否则 E-RD1）；u ← a；v ← b；M ← I
循环（≤ 10 000 次）：
    u·u > v·v·(1 + τ) → (u, v) ← (v, −u)；M ← [M1, −M0]                      （τ = gauss_tolerance；保持手性）
    x ← (u·v)/(u·u)；μ ← |x| > 0.5 + τ ? sign(x)·floor(|x| + 0.5 − τ) : 0       （就近取整，恰为半数时向零；M5 的 round-half-up 改为此规则）
    μ = 0 → 结束；v ← v − μu；M1 ← M1 − μ·M0
angle = None → 返回 (u, v, M)                                                  （|u| ≤ |v|，|u·v| ≤ |u|²/2，不做角度与符号规范化：M6）
angle = "obtuse"/"acute"：d ← u·v，s ← τ·|u||v|
    "obtuse" 且 d > s，或 "acute" 且 d < −s：
        |d| ≥ |u|²/2·(1 − 1e-6)（六方型平局）→ v ← v ∓ u（u 保留）；否则 → (u, v) ← (v, −u)（两根最短矢量交换次序：此时可能 |u| > |v|）
    符号：u 与输入 a 的夹角余弦 < −τ（或 ≈ 0 且 v 与 b 的 < −τ）→ (u, v) ← (−u, −v)
返回 (u, v, M)：[u; v] = M @ [a; b]，det M = +1；JS 返回 {u, v, M}
```

[V1] 2000 个随机基规范化；六方 60° → 120° 且 a 保持；bcc(110) 钝角 109.47°、锐角 70.53°；Python 与 JS 的整数矩阵在全部非退化输入上逐项相同
（工程审查重跑 parity：512/516，4 个不一致来自生成器造出的**奇异**基，两侧都应报 E-RD1——金标生成器先剔除 `|a × b| ≤ 1e-8·|a||b|` 的输入）。

#### 3.11.2 三维 Niggli `niggli_reduce_cell(cell, eps=None)`（v1 §3.11.2 的 8 步表不变 [V1]）

Křivý & Gruber (1976) + Grosse-Kunstleve, Sauter & Adams (2004) 的 ε；每步矩阵 det = +1；结果 `C @ cell`，取向保持；ε 默认 `1e-5·V^(2/3)`（Å²）。
[V1] 7 种格 × 30 个随机幺模基度规相同；210 个基上与 ASE 3.29 一致；两种语言整数矩阵 180/180 逐项相同；JS 每次 37 µs。
结构级 `niggli_reduce(structure)` = `reduce_cell(mode="3d")`（ASE 同名，但不按晶胞参数重建取向，文档写明）。

#### 3.11.3 `reduce_cell(s, *, mode="auto", angle="obtuse", wrap=True)`

```text
k ← vacuum_axis(s)
mode = auto：k 非空 → "2d"（轴 k）；否则 "3d"
"3d"：要求三轴周期（E-RD2）；C ← niggli_reduce_cell(cell).C
      k 非空：j ← 与旧 a_k 夹角余弦绝对值最大的新矢量；j ≠ k → note N-RD2 "moved the vacuum gap from c to a"；cos < 0 → N-RD3 "reversed c"
"2d"：(i, j) ← k 以外的两轴（必须周期，E-RD3）；(u, v, M2) ← gauss_reduce_2d(a_i, a_j, angle)
      (p, q) ← closest_in_plane(a_k, u, v)（平局按 (距离取 9 位, |p|+|q|, p, q)）；C ← I；C 的 i、j 行列 ← M2；C[k] ← e_k − p·C[i] − q·C[j]

```

- [V] TTT p(8×8) 4L（|a| 22.2 Å > |c| 18.8 Å）auto：C = I，真空保持在 c（v1 原型：`C = [[0,0,1],[1,0,0],[0,1,0]]`，真空换到 a）；同一结构 mode 3d：
  note `Niggli reduction moved the vacuum gap from c to a`；200 个倾斜的 TTT 晶胞：二维路径反向 0 次，3-D Niggli 移动或反向 103 次、每次都有 note [`test_ops2.py`]。

- 聚类是单链的：0.00、0.04、0.08 在容差 0.05 下连成一类；文档写明容差必须小于物理上不同的值之差。

  `initial_magmoms` 0.645 ± 1e-5 → 约化（v1：一个也约化不掉）；0.6 ± 3e-3 → 约化；AFM ++−− 的 8 原子超胞 → 2 个原子（不被约化成非磁 1 原子）[`run_trans.py`]。

#### 3.12.2 候选与量化（D1）

```text
要求周期晶胞；tol ∈ [translation_tolerance_min, 0.25 × 最小晶面间距)（否则 E-PC1）
axes ← axes 参数："all" → 全部周期轴；None → 真空轴以外的周期轴（D20；没有真空轴时为全部周期轴）；元组 → 与周期轴求交
f ← 分数坐标（周期轴按 wrap_fractional 包裹）；(cls, used) ← identity_classes；g ← 各类大小的最大公约数
g == 1 或 axes 为空 → 群 = {0}
divs ← g 的全部约数（升序）；ε_k ← tol / h_k（h_k 为晶面间距）
rare ← 最小的类（大小相同取首原子下标最小者）；ref ← rare 的第一个原子
对 rare 中其他原子 j：d ← f_j − f_ref
    axes 中的轴 k：x ← d_k − floor(d_k)；(p, q) ← snap(x, ε_k, divs)：按 q ∈ divs 从小到大，p = ceil((x − ε_k)·q − 1e-12)，p ≤ (x + ε_k)·q + 1e-12 即命中；
                   不命中 → 丢弃候选；u_k ← (p·(g/q)) mod g；残差 r_k ← x − p/q
    非 axes 的周期轴：r_k ← d_k − round(d_k)；非周期轴：r_k ← d_k
    |r @ cell| ≥ tol 或 u = 0 → 丢弃
    排序键 (floor(|t_cart|·1e6 + 0.5), u0, u1, u2)，t 取 u/g 的最短代表；按 u 去重
```

- 依据：群阶整除每一类的大小，故整除 g；有效平移的每个分量是分母整除 g 的分数，平移以**精确整数** `u ∈ Z_g³` 表示。
  v1 的 `round(d·g)` 在 g 很大（无标签 slab 的 g = 原子数）时把带噪声的候选量化到错误的分数，产生伪生成元（D1）。

#### 3.12.3 核对、循环检查与有界闭包（D1、E11）

```text
order ← 低差异访问顺序：o_k = (k·s) mod N，s = floor(N·0.6180339887498949 + 0.5) 起递增到 gcd(s, N) = 1（N ≤ 2 时为恒等）
matcher ← 周期分箱表：每轴箱数 clamp(floor(span_k·h_k / max(2·tol, 1 Å)), 1, 256)；箱宽 ≥ 2·tol，故 tol 球只伸到每轴靠近的那一个邻箱 → 每次查询 8 个箱；
          同类、最小像距离 < tol 中取最近者（tol < h_min/4 保证 round 即最小像）
learned ← {atoms: [], holes: []}（各至多 translation_learned_max = 64 个，按加入顺序）
group ← {0}；gens ← []
按排序遍历候选 u（u ∈ group → 跳过）：
    t ← u/g
    预检（只会提前拒绝，不改变结果）：learned.atoms 中的原子、以及"在某个空洞 h 下方 t 处"的同类原子（matcher 查 h − t），逐个做真正的匹配；有一个失败 → 拒绝
    核对：按 order 依次（Python 分块 8、16、32…、4096 向量化），原子 i 找 j = match(f_i + t)
        找不到 → 把 i 加入 learned.atoms、把 (cls_i, f_i + t) 加入 learned.holes，拒绝；j 已被占用（不是置换）→ 拒绝；perm[i] ← j
    循环检查：L ← u 的阶 = g / gcd(g, u0, u1, u2)；perm 的所有循环长度都等于 L ⇔ perm^L = id 且对 L 的每个素因子 r，perm^(L/r) 没有不动点
        不满足：L0 ← 原子 0 的循环长度；L0 ∤ g 或循环长度不一致 → 拒绝；
                否则按 perm 求平均位移 t̄（周期轴取最小像），u ← (round(t̄_k·L0) mod L0)·(g/L0)（axes 轴），阶须为 L0、残差 < tol → 用它（"救回"）
    有界闭包：new ← ⟨group, u⟩，元素数一旦 > g 立即放弃；|new| ∤ g → 放弃（伪生成元）
    group ← new；gens.append((u, perm))
```

- **Python 批量预筛**（只为速度，结果相同）：候选多于 16 个时，先对全部候选一次性核对 `order` 的前 `translation_screen_atoms` = 4 个原子（每个原子一次向量化调用），
  失败的候选直接去掉。JS 不需要（逐个核对已经很快）。
- 复杂度：每个新生成元至少使群翻倍，完整核对 ≤ log₂(k) + 3 次，每次 O(N)；带缺陷的近似平移因 learned 而在几次查询内失败。
- [V]（`run_trans.py`、`trans2.mjs`；"群阶"均为理想值）：

#### 3.12.4 原胞

```text
k ← |group|；k == 1 → unchanged（N-PC1："No lattice translation found within 0.05 Å."，E29；不记历史）
rows ← {g·e_1, g·e_2, g·e_3} ∪ {生成元 u}；H ← hermite_normal_form(rows)                    （新矢量 = H/g 在旧基下）
约化（reduce=True）→ T_num ← reduce_rows(H, g, cell, axes, k_vac)：
    axes 恰为两轴 (i, j) → 只对 H 的 i、j 行做 Gauss（钝角），第三行不变
    三轴搜索且 k_vac 非空 → 以 k_vac 为第一主元的 HNF：第 0 行 = 堆垛矢量（k 分量 > 0），第 1、2 行 = 面内子格；整数行 det < 0 时第 2 行取负；
                            面内两行 Gauss（钝角），堆垛矢量做 closest_in_plane 修正，放回下标 (i, j, k)
    没有真空轴 → Niggli（niggli_reduce_cell）
T ← T_num / g；new_cell ← T @ cell；supercell_matrix S ← round(inv(T))（整数，det = k；旧 = S @ 新）；transform = {num: T_num, den: g}（新 = T @ 旧，C1 方向）
轨道：按 i 升序，未访问的 i 为代表；沿所有生成元置换做 BFS，同时累积精确整数平移 acc_i（mod g）；轨道大小 ≠ k → E-PC2
坐标：average 为假 → 代表的原坐标；为真 → 轨道内 (f_j − acc_j/g) 经最小像对齐后的平均（EM4）
包裹：按 K3（S 的第 a 列为 e_a 的轴不动；真空轴不用 floor）
image_shift_i ← round(f_i(新) − f_rep(i)(新))（每个旧原子相对其代表的整数新格矢；网页 imageShift 用它）
out ← s.copy()；out._remap(reps, positions=…, frames=[])；cell ← new_cell；apply_basis_change；mark_edited "cell"；adsorbate_id 紧凑重编号（§4.1）
info.supercellMatrix：T @ M 为整数则替换，否则删除；名字按 §3.5.4；非身份属性在某个轨道内不同 → N-PC2（列出键名，含 labels）
```

- 用生成元置换做 BFS 而不是逐个群元素查找：噪声不累加 [V1]。代表默认不取平均（不偷偷改几何）；`average=True` 给 M2 的分析步骤用
  （[V] p(6×6) σ = 0.01 Å：平均后高度误差 0.0020 Å，代表 0.0114 Å）。
- [V] fcc 惯用胞 → 1 原子（det 4）、NaCl 2、CeO2 3、bcc Fe 1（det 2）；SrTiO3 5、金红石 6、hcp Ru 2、纤锌矿 4 已是原胞；
  TTT p(8×8) 4L 三轴搜索 → 4 原子、c 原样；双 slab（`diag(1,1,2)`）→ 4 原子、c′ = c/2 沿 +z；底层在 z = −0.01 的 CONTCAR 2×2 → 4 原子、z 不变；
  R 心刚玉型 30 原子 → 10 原子（det 3）[`run_trans.py`]。
- 面内变体（M2 的最小表面网格，M6 的准备步骤）：`primitive_cell(s, axes=(i, j))`：c 原样保留，只对面内两行做 Gauss [V1]。

### 3.13 重定向 `reorient(s, convention="a-x")`

```text
k ← vacuum_axis(s)（当前帧）
k ≠ None 且 k ≠ 2 → perm ← [(k+1)%3, (k+2)%3, k]（循环轮换，det +1）：所有帧的晶胞行按 perm；pbc ← pbc[perm]；
                    selective_dynamics 按 perm 重排；info.supercellMatrix 的行与列同样置换；info.surface.axis ← 2；note N-RO2
R ← standard_frame(当前帧晶胞, convention)
所有帧：cell' ← cell @ Rᵀ（|x| < 1e-12·max|cell| 置 0）；pos' ← pos @ Rᵀ             （D19：同一个 R，轨迹整体刚性旋转）
mark_edited(out, "rotate", rotation=R)；info.surface.normal 存在 → 乘 R（M2 §10、M4 §10 的请求）
R ≈ I（1e-12）且无轮换 → unchanged（N-RO1，不记历史）

返回 {rotation: R, lattice_changed: 轮换时 True}                                       （网页：先算 r，再 editActive(..., {cameraTransform: r.rotation, refit: false})）
```

- [V1] 随机旋转过的 CONTCAR 转回后与原晶胞、坐标相差 < 1e-9；约束不变；左手晶胞得到 c_z < 0 且 R 是真旋转。

- `"c-z"`（MS 的三方取向）只在界面上对没有真空轴的结构提供；API 照常可用。

### 3.14 惯用胞 `conventional_lattice(cell)` 与 `miller_basis_note(cell, hkl)`（K17、EM3）

```text
conventional_lattice(cell) → (kind, Q) | None，惯用胞 = Q @ cell：
    (red, C) ← niggli_reduce_cell(cell)
    red 的度规为 fcc 原胞（三长相等、三角 60°，1e-3 / 0.1°）→ ("cubic F", F0-A 的 [[-1,1,1],[1,-1,1],[1,1,-1]] @ C)；109.47° → ("cubic I", [[0,1,1],[1,0,1],[1,1,0]] @ C)
    否则成对搜索：候选矢量 = red 下系数 ∈ [−2, 2]³ 的格矢，按 (Σ|n_i|, 然后 n 的降序字典序) 访问（单位阵最先）；
        对每种 kind（立方 → 六方 → 四方）：等长的一对 (v_i, v_j) 夹角为 90°（六方 120°）→ 法向上最短的第三个格矢 v_k（系数 ∈ [−3, 3]³，v_k·n > 0；立方还要求等长）
        → D = det([n_i; n_j; n_k])，取 1 ≤ D ≤ 4 中最小者（同 D 取先访问到的）
    kind 与 D 命名：立方 P/I/F（D = 1/2/4）、六方 P/R（1/3）、四方 P/I（1/2）；Q ← Q_red @ C；都没有 → None
conventional_cell(s) = make_supercell(s, Q)（Q = I → unchanged，note "The cell is already conventional (cubic P)."；None → E-CV1）
miller_basis_note(cell, hkl)：(kind, Q) 存在、Q ≠ I 且 kind ∉ {cubic F, cubic I}（这两种由 F0-A 的 centeredCellHint 处理）
    → hkl_c ← Q @ hkl 约去公因子；六方写四指数 (h k i l)；返回如 "(1 0 0) here is the conventional (1 0 1̄ 1) plane (hexagonal R)."（标准正向菱方基）；否则 None
```

- 有真空轴的结构上 Conventional cell 不可用（分区说明 `Conventional cells are for bulk crystals; this structure has a vacuum gap along c.`）。
- 只看晶格度规：原子排列的对称性更低时，Q @ cell 仍是正确的超胞，只是"惯用"二字仅指晶格；更低对称的格（正交、单斜……）返回 None（不在本期范围）。
- [V] Niggli 后的 fcc 原胞 → cubic F（F0-A 的矩阵）；bcc → cubic I；fcc 原胞经随机幺模基 → cubic F；刚玉型菱方原胞 → hexagonal R（det 3）；
  体心四方原胞 → tetragonal I；hcp Ru → hexagonal P，Q = I；SrTiO3 → cubic P，Q = I；Python 16–37 ms（成对搜索，JS 预计 < 5 ms）[`test_ops2.py`]。

### 3.15 `info` 处理器注册表（K16、E8）

```text
register_info_handler(key, fn, *, replace=False)        （key：info 的顶层键或点分路径，如 "surface"、"surface.adsorbates"、"interface"）
apply_info_handlers(ctx)：对 ctx.new.info 中存在的每个已注册键，按注册顺序（父键先于子键）调用 fn(info_value, ctx) → 新值（None = 删除该键）
ctx = {kind: "supercell" | "basis" | "primitive" | "rotation" | "deform" | "translate", old, new, matrix (P 或 C), transform (原胞), rotation (R),
       deformation (F), src, images (|det P|), id_offset (adsorbate_id 每个像的增量 V), perm (轮换)}
```

- **M1 自带的 `surface` 几何默认处理器**：`rotation` → `normal ← R @ normal`；`basis`/`supercell`/`primitive`/`deform` → 找出另两根新矢量都与 `normal` 垂直（1e-6）的轴写入
  `axis`，并按新晶胞重算 `normal = unit(a_i × a_j)`（朝 +a_k）；找不到 → 删除 `axis` 与 `normal`；轮换 → `axis ← 2`。
- **M2 注册 `surface`（`replace=True`）**：在调用 M1 的几何辅助函数 `update_surface_geometry(surface, ctx)` 之外，更新 `supercell`、`wood`、组成、`name`
  （自动名由 `surface_name(info)` 生成，§3.5.4）等自己的字段；**M5 注册 `surface.adsorbates`**：超胞时按像复制记录，id 加 `q·V`（与 §4.1 的 `adsorbate_id` 重编号同一规则）；
  **M6 注册 `interface`**。没有注册的模块，M1 什么也不做（不删除未知字段）。
- 处理器必须是纯 JSON 变换、两种语言各一份、同名同义；M1 的测试注册一个假的处理器核对调用顺序与 ctx 字段。

### 3.16 网页预览的计算方式

## 5. 界面

### 5.0 状态模型（E12）

F0-A 的分区单独重绘：签名变了才重绘该分区，用户正在该分区输入时延到离开输入框（F0-A §3.17）。M1 在此基础上规定：

1. **草稿**：模块级 `drafts = Map(entryId → {sectionId → draft})`，存每个分区未提交的输入（6 个晶胞参数或 9 个矢量分量与"哪些字段被编辑过"、超胞模式/矩阵/预设与参数、
   应变模式与数值、容差与 Find 的结果、原点矢量）。该分区提交、或该条目的 `rev` 变化（撤销、重做、其他编辑）时清空该条目的草稿；P-swap 预览不改变已提交结构的 `rev`，不会清空。
2. **签名**：`signature(app) = [entryId, s.rev, app.session?.owner === sectionId, draft.mode, referenceMeshKey].join('|')`；选区、测量、显示设置不进签名。
3. **读数就地更新**：输入的 `onChange` 经元素引用改写读数节点（`4 atoms → 12 atoms`、体积、Wood 标签），不触发重绘。
4. **重绘后重新接线**：渲染时若 `app.session?.owner === sectionId`，把新控件接到现有会话；虚线晶胞的 `cellOutlineLayer` 句柄存在模块级 `outlines = Map(entryId → handle)`，
   重绘不重建它。
5. **深链接**：`cell.redefine` 用 F0-A 的 `openSection('structure', 'cell.supercell', {tab: 'matrix', focus: 'matrix'})` 打开 Matrix 页。
6. 测试（Playwright 或假 DOM）：在矩阵里输入 → 选一个原子 → 切换显示样式 → 输入的值与预览都还在。

### 5.5 Reduce, primitive & conventional

- **Reduce cell**：读数在分区展开时计算（微秒级）：`Niggli-reduced cell: a = b = c = 2.772 Å, α = β = γ = 60°` 或
  `Reduces a and b; c holds a 15.0 Å vacuum gap and is only made as perpendicular as the lattice allows.` 或 `The cell is already reduced.`；
  有真空轴时 `seg` `120° / 60°`（角度约定，默认 120°）；高级 `seg` `Auto / 2-D / 3-D`（3-D 在有真空轴时附 N-RD2/N-RD3 的预告）；按钮 `Reduce cell`。撤销 `Reduce cell` / toast `Cell reduced`。
- **Primitive cell**：`Tolerance`（`numberInput`，unit `Å`，默认 0.05，0.0001–0.5）；有真空轴时 `Search along the vacuum axis too`（默认不勾；不勾 = 只在面内搜索，D20）；
  `Also distinguish atoms by`（多选：结构中存在的、默认不参与的属性，如 `labels`、`magmoms`、`adsorbate_id`，默认都不勾）；`Average positions`（默认不勾）；
  按钮 `Find`（> 5 000 原子时分块计算、F0-A `app.busy` 进度条与 Cancel，§3.16）→ 读数 `Found 36 lattice translations: the primitive cell has 6 atoms (1/36 of this cell).`
  或 N-PC1（及 S10 的宽容差提示）；然后 `Make primitive`（P-swap 预览可选，`indexMap = orbit_of`）。超过 `primitive_atoms_web` 时按钮禁用：
  `Primitive-cell search is limited to 50,000 atoms in the browser; use the Python API or the CLI.` 撤销 `Make primitive cell` / toast `Made the primitive cell: 6 atoms`。
- **Conventional cell**：读数 `This is a cubic F lattice; the conventional cell has 4× the atoms.` 或 `The cell is already conventional (cubic P).` 或
  `No cubic, tetragonal or hexagonal setting was found for this lattice.`；有真空轴时显示 §3.14 的说明；按钮 `Make conventional cell`。撤销 `Make conventional cell`。

### 5.6 Orientation & origin

- `Re-orient to standard` 按钮 + `seg` `a along x` / `c along z`（后者仅在没有真空轴时显示）；`Already in the standard orientation.` 时按钮禁用；
  `const r = reorient(work); editActive('Re-orient cell', (s) => s._adopt(r.structure), {cameraTransform: r.rotation, refit: false, toast: 'Cell re-oriented: a is along x'})`（原子集合不变，追踪器给出恒等映射）（E18：R 先算好，`refit: false` 防止画面跳动）。
- `Make right-handed`（只在左手晶胞上显示，DM1）：读数 `Left-handed cell: VASP refuses such cells.`；撤销 `Make right-handed` / toast `Swapped a and b: the cell is right-handed`。
- `Shift origin`：F0-A `vec3Input({frames: ['fractional', 'cartesian'], frame: 'fractional', cell})`、`In-plane only`（有真空轴时显示，默认勾选）、`Wrap atoms`（默认开）、按钮 `Shift`；
  实时 P-swap 预览（`sameAtoms: true`）；所有帧。`Move selected atom to origin`（恰好选中 1 个原子时可用，否则 tip `Select one atom first.`）。撤销 `Shift origin` / toast `Origin shifted`。
- `Wrap atoms into cell`：`Keep the slab in one piece`（有真空轴时显示，默认勾选）；撤销 `Wrap into cell` / toast `Wrapped 12 atoms into the cell`（0 个时 `All atoms are already inside the cell.`，不记历史）；
  slab 跨边界时附 N-WR1。

### 6.5 CLI（M7 统一前的提议）

```text
facet transform INPUT [-o OUTPUT] [--format FMT] [--from FMT] [--index N] [--plugins DIR] OPS...

    --cellpar A B C ALPHA BETA GAMMA（_ 表示不变）[--keep-cartesian] [--no-keep-vacuum]
    --strain MODE PERCENT（MODE: iso | biaxial | uniaxial-a|b|c|x|y|z|normal）[--plane H K L | --along U V W] [--no-keep-vacuum]
    --strain-tensor XX YY ZZ YZ XZ XY [--no-keep-vacuum]（张量分量 εij，%）   --scale-lattice FROM TO [--no-keep-vacuum]（= iso (TO/FROM − 1)·100 %）

    --reorient [a-x|c-z]           --shift-origin X Y Z [--cartesian] [--with-normal]   --wrap [--split-slab]
```

- 读入用 `read(args.input, format=args.from_, index=args.index if given else -1)`；`--index` 只接受单个整数（切片报 `facet: error: transform works on one frame; use --index N`，E21）；
  notes 打印到 stderr（`facet: note: …`）；`ValueError` → `facet: error: …`，退出码 1（04 §2.5）。负数在 `nargs=3/9` 中能正确解析 [V1，04 §2.5]。

### 8.1 决定记录（U6：设计完成后直接开发，由负责人按简报原则定案）

| # | 问题 | 定案 | 理由 / 备选 |
|---|---|---|---|
| Q1 | C11 对刚性操作是否丢帧 | **不丢**：重定向、平移原点、包裹处理所有帧（O4 采纳，D19） | 刚性操作不让其他帧失去意义；代价是 NPT 轨迹的其他帧不一定是标准取向（文档写明，EM7） |

## 未采纳的意见

| 意见 | 理由 |
|---|---|
| D2 第 2 点：请 F0-D 让读取器给没有标签的位点设 `labels = 元素符号` | 对 M1 已无必要（labels 不再是身份属性）；CIF 规范要求位点标签唯一，写出器照旧写 `Pt1, Pt2…`，读取器改动只会让往返结果变化。读取器归 F0-D，留给 F0-D 决定 |
| D7 第 1 点的严格规则"结果必须右手" | 对左手输入做 det > 0 的普通超胞（例如 2×2）也会被拒，导入的左手结构寸步难行；v2 只禁止"制造"左手晶胞，左手结果给出提示与一键 Make right-handed（§8.3 第 2 条） |
| D9 "偏离 > 1e-4 时写 distorted" | 窄档容差（1e-3、0.1°）内的偏差通常是写出精度（6 位小数）造成的，标"变形"会让几乎所有导入的结构都带这个字样；只在用到变形档时写 |
| D10 切换项默认 "Current cell" | Wood 记号与覆盖度都相对 1×1 网格（F0-A v2 采纳的 D6），默认相对参考网格；参考网格就是当前网格时（最常见）两者相同，切换项也不显示 |
| D12 有真空轴时对角面内超胞写 `p(m×n)` | 按间隙改变命名风格是 U1 禁止的"区分"；改为依据来源信息（M2 的自动名），效果相同而不需要判断"是不是 slab" |
| D13 通用标签器在方形网格上优先写 c(2×2) | 简报 C9 的范例用 `(√2×√2)R45°`；只在用户选了 c(2×2) 预设时用预设标签 |
| D16 采用 M2 的"宽度差 ≤ 0.5 Å 按 c、b、a 优先" | F0-D v2 已定稿并列规则（1e-5 Å 内按 c、b、a），全模块只用一套；0.5 Å 的规则会让两个真空宽度接近的轴选择不稳定 |
| D17 "矩阵不满足 M[0][2] = M[1][2] = 0 就删除该键" | `supercellMatrix` 对体相的一般三维超胞同样有意义；需要面内形式的使用方（M5）改为调用 `reference_mesh`，由它检查 |
| D6 第 2 点：`reduce_cell(mode="3d")` 遇到真空轴时报错 | 显式选择 3-D 是用户的明确意图（例如真空很小、其实是体相）；给出 note 说明真空被移动或反向，比拒绝更有用 |
| DM10 超胞后按层、按元素排序 | 简报 C1 规定对角超胞的原子顺序与 `repeat` 完全一致；F0-D 已提供可撤销的 "Sort atoms by species"，POSCAR 写出器本来就按元素分组 |
| E3 第 2 点：计数器名用 `version` | F0-D v2 K13 已定为 `rev`（F0-A 与 M1 v1 都按此写），M1 跟随唯一的实现方 |
