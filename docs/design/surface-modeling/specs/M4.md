## 0. 摘要：关键决定

## 1. 用户故事与 Materials Studio 对照

### 1.1 用户故事

1. **调 CO 的高度**（Pt(111) p(3×3) 4L，底两层固定，CO 在顶位）：点 Pt，Shift 点 C，选区卡片显示 `Distance 1.850 Å`；点数值，输入 `1.9`，回车。C 和 O 一起沿 Pt→C 方向移动，O 不变形；一次撤销。反过来先点 C 再点 Pt 也一样（移动的仍是 CO，因为 Pt 是基底）。
2. **顶位 CO 倾斜 30°**：依次点 Pt、C、O，卡片 `Angle 180.0°` 改成 `150`；只有 O 绕 C 转，倾斜方向默认是屏幕右方（共线起点没有转轴，§3.8.4）。空位 CO（Pt–C–O 本来就是 129.7°，D11）用 Transform › Geometry › `Tilt from normal`（应该）：选 C、O，输入 `30°`。
3. **把吸附物拖到另一个位点**：双击 CO（选中 C、O 两个原子，不含表面 Pt，§3.5.3），按 G，直接拖 CO：它在表面平面内移动，高度不变（K4）；HUD 显示 `1.85 Å above Pt #12`；靠近另一个位点时吸附过去（应该；M5 上线前只吸附到表面原子的顶位）。Esc 中途取消。
4. **复制吸附物**：选中 CO，Ctrl C；右键另一个顶位的 Pt → `Paste above Pt #20`；CO 以复制时的 Pt–C 键长（1.85 Å）落在该 Pt 正上方。粘到空位（选 3 个 Pt、`Paste above selection`）时同样保持 1.85 Å 的键长，HUD 显示 `Pt–C 1.85 Å to 3 atoms · Site: 3-fold hollow (fcc)`；要用空位常见的 2.08 Å，在 Paste special 里输入键长，或粘贴后用 `Set…`。导出 POSCAR：新的 C、O 是 `T T T`，底两层 `F F F`。
5. **O/Cu(100) 四重空位**：Cu(100) p(2×2) 上框选一个四重空位周围的 4 个 Cu，Transform › `Add atom` → `O`、`Above selection`，键长默认 1.98 Å（共价半径之和 0.66 + 1.32），预览读数 `Cu–O 1.98 Å to 4 atoms · Site: 4-fold hollow`，`Add`。在 c(2×2) = (√2×√2)R45° 晶胞里四个角是两个原子的周期像，按源原子选不出空位（D6）：用 Surface › Adsorbates（M5）的位点，或 `Fractional` 输入，或脚本传显式像（§3.9.2）；选两个原子时 HUD 如实显示 `Site: bridge`。
6. **石墨烯上放吸附原子**（应该）：`Add atom` → `Pt`、`Click in view`；悬停在 C 上时幽灵原子吸附到该 C 正上方（键长 = 共价半径之和 2.12 Å），否则落在指针下方的局部表面上方；点击放置，Esc 结束。
7. **把分子插入 slab**：项目里有一个 Build › Molecule 建的 `Water`；Structure 面板 › Transform › `Insert`：`Water`、`Above selection`（选中一个 5 配位 Ti）、锚点 `Binding atom: O #0`、键长 2.2 Å、`Orient: Binding atom down`（应该），`Insert`。
8. **数值平移/旋转**：Transform › Move：`Out of the surface 1.0 Å` 把选中的顶层整体抬高；Transform › Rotate：绕 `Normal`、`90°`、中心 `Centre of selection`，旋转吸附分子；中心也可以是 `Slab centre`（应该，用于两面对称的操作）。
9. **底面**（对称 7 层 SrTiO3、或用 Shift+N 看底面）：选底面的 4 个 O，`Add atom above selection`：新原子落在底面**下方**，表单写 `below the bottom surface`（K9）。
10. **脚本**：`s.set_distance(12, 36, 1.9, move="auto")`；`s.rotate(90, "z", center="COP", indices=[36, 37], mic=True)`；
    `p = site_point(slab, [12, 13, 14], bond=1.85).point`；`slab.extend(co, position=p, anchor="binding", adsorbate=True)`（§6.1）。
11. **从 CONTCAR 导入的 slab**（pbc T T T，有 SD，底层在 z = 0，部分底层原子存为 f ≈ 0.9999）：Surface 框架、`Out of the surface`、"上方"放置照样可用（法向来自 F0-A `surfaceNormal` 的真空间隙，U1）；被 VASP 包裹到晶胞顶部的底层原子不会被当成"表面顶部"（编辑坐标系与显示同一切口，§3.2）。没有 tags 时基底由 M3 的几何识别给出。
12. **台阶面**（Pt(211)）：从低平台复制顶位 CO，粘到台阶边缘原子上方：Pt–C 仍是 1.85 Å（v1 会算成 0.25 Å，D4）。

## 3. 算法

### 3.1 约定与常量

- 坐标按 C1：晶胞的行是晶格矢量，`cart = frac @ cell`；长度 Å，角度度。
- 旋转矩阵作用于列矢量：`p' = R @ p`，行矢量数组写成 `P' = P @ R.T`。`R(axis, θ)` 是右手 Rodrigues 公式
  `R = cosθ·I + sinθ·[â]× + (1 − cosθ)·â âᵀ`；轴长 < 1e-12 抛错。
- 二面角：IUPAC 符号（Blondel–Karplus，`crystallume/analysis/geometry.py:52-65`；审查用真 ASE 3.29 在 200 组随机点上核对，最大差 5.7e-14°），
  API 返回 [0, 360)；界面显示 (−180°, 180°]，用 F0-D 的 `signedAngle(dihedralFromVectors(...))`（F0-D §3.15.1，修正 `render/viewer.js:1950` 与
  `ui/selectioncard.js:54` 的反号）。设定值接受任意实数，内部 `diff = ((target − current + 180) mod 360) − 180`（最短转向）。
  绕 `r_k − r_j`、过 `r_k` 右手转 +θ 使二面角 +θ（v1 原型 `dih_sign.py`）。
- 退化判据：矢量长 < 1e-8 Å 视为零；角的两边共线：`|v10 × v12| < 1e-8·|v10|·|v12|`；二面角未定义：`|b0 × b1| < 1e-8·|b0||b1|` 或 `|b1 × b2| < 1e-8·|b1||b2|`。
- 常量（C10：加入 `SURFACE_DEFAULTS`，两种语言同值，测试核对；键名 Python snake_case / JS camelCase）：

| 键（Python） | 值 | 用途 |
|---|---|---|
| `bond_scale` / `bond_min` / `bond_max` | 1.15 / 0.4 / 5.0 | **与 M3 共用**（M3 §3 开头的表）：化学键判据 `bond_min < d < min(bond_max, bond_scale·(r_i + r_j))` |
| `place_bond_factor` | 1.0 | 默认放置键长 = 系数 × (r_cov,X + r_cov,M)（§3.9.3） |
| `add_height` | 2.0 Å | 找不到可接触的基底原子时的回退高度 |
| `site_contact_tol` | 0.15 Å | 位点标签：离放置点在 `d_min + 0.15` 以内的基底原子数（§3.9.4） |
| `paste_gap` | 1.5 Å | 偏移粘贴时与原分子的间隙 |
| `paste_offset_min` | 3.0 Å | 偏移粘贴的最小平移长度（E22-f） |
| `overlap_tol` | 0.1 Å | 判定"粘贴会与原原子重合"（编辑坐标系中） |
| `snap_translate` / `snap_rotate` / `fine_factor` | 0.1 Å / 5° / 0.1 | 移动工具取整与精细 |
| `contact_factor` | 0.75 | 近距离接触：`d < 0.75·(r_cov,i + r_cov,j)` |
| `unwrap_bond_limit` | 5000 | 超过这个原子数的组不建组内键图，直接走快速路径（§3.7.1） |
| `mic_tie` | 1e-8 Å | 最小像候选长度差在此以内视为并列（§3.2.2） |
| `lowest_tie` | 1e-3 Å | "最低原子"比较的容差（并列取质心，§3.9.8） |
| `clipboard_max_atoms` | 200 000 | 复制上限（`copy` 事件必须同步写入） |

### 3.2 编辑坐标系与最小像（K3）

#### 3.2.1 编辑坐标系 `edit_frame(structure)`

```
edit_frame(s) -> EditFrame{ gaps, cut[3], shift (n×3 int), pos (n×3), mic_axes }
  gaps    = { k : find_vacuum_gap(s, k) }，k 为周期轴且有宽度 ≥ vacuum_gap_min（5.0 Å）的贯穿间隙（U1；F0-D 实现、F0-A §3.8.2 的确切语义：
            包裹到 [0,1) 排序、圆周上最大间隙、等宽取 start 最小者、centre = (start + Δ/2) mod 1）
  cut[k]  = centre > 0.5 ? centre − 1 : centre            # 与 F0-A 显示的切口逐字相同
  shift_i,k = −floor(f_i,k − cut[k])   (k ∈ gaps；其他轴为 0)  # 只按整数个晶格矢量平移
  pos_i   = r_i + shift_i @ cell                            # 沿间隙轴落在 [cut, cut+1)，与画出来的一致
  mic_axes = 周期轴中不在 gaps 里的轴                        # slab：a、b；体相：a、b、c；盒中分子：空
```
- **差矢量**：`vdiff(i, j) = mic_vector(pos_j − pos_i, cell, axes = mic_axes)`。沿间隙轴不取最小像——slab 的两端隔着真空，按切口坐标就是连续的，
  厚度超过 c/2 也不会被折到真空另一侧（E4：v1 在 Pt(111) p(6×6) 6L、10 Å 真空上把顶层折到 z = −10 Å；v2 原型 `scen2.py` 6L/10 Å、8L/15 Å 都正确）。
- 对成键的近邻原子，`vdiff` 与普通最小像完全相同；只在两原子沿间隙轴相距超过 c/2 时不同（此时普通最小像穿过真空，物理上是错的）。
- 编辑坐标系不依赖 `display.wrap`；网页端的"画出位置"另由 §3.2.3 换算。
- CONTCAR：底层原子存为 f = 0.99995 时，编辑坐标系把它放在 −0.001 Å（与显示一致），顶层仍是 6.79 Å（`scen2.py`）。
- 复杂度：每轴 O(n log n)；JS 按 `structureKey` 缓存（P-pos 预览期间用会话开始时的那份，与 F0-A 冻结切口一致）；Python 每次调用重算（1 万原子 5 ms，`perf2.py`）。

#### 3.2.2 精确最小像 `mic_vector(v, cell, pbc, *, axes=None) -> (w, image)`

替换 `crystallume/analysis/geometry.py:21-40` `minimum_image_vectors` 的实现（签名不变，另加仅限关键字的 `axes`），JS 在 F0-D 新建的 `core/geometry.js` 中加同算法的
`micVector(v, cell, pbc, {axes})`。修两个问题：现有"先 round、再查 27 个像"对斜晶胞会错（报告 07 第 13 条：极端剪切给 2.73 Å 而不是 0.50 Å）；
两种语言在半格矢处选不同的像（E11：六方 p(3×3) 胞 9/18、斜胞 6/18 不一致）。

```
P = axes ∩ 周期轴（默认全部周期轴）；P 为空 → 返回 (v, 0)
A = [cell[k] for k in P]（m×3）；G = A Aᵀ；coords(x) = G⁻¹ A x          # x 在 span(P) 上正交投影的系数（m = 3 时即分数坐标）
g  = coords(v);  n0_k = −floor(g_k + 0.5)  (k ∈ P)                     # 两种语言都用 floor(x + 0.5)，不用 round（numpy 银行家舍入、JS 向上舍入）
v0 = v + n0 @ cell;  R = |coords(v0) @ A|                                # v0 的面内部分长度
h_k = a_k 到 span{a_j : j ∈ P, j ≠ k} 的距离（m = 3：V/|a_i × a_j|；m = 2：|a_k × a_j|/|a_j|；m = 1：|a_k|）
m_k = ceil(R / h_k + 0.5)；枚举 n_k ∈ [−m_k, m_k]（k ∈ P），候选 w = v0 + n @ cell     # 由 |(g + n)_k|·h_k ≤ |w| ≤ R 得到，保证不漏
若 ∏(2 m_k + 1) > 125：先用 M1 的 gauss_reduce_2d（m = 2）/ niggli_reduce（m = 3）约化 P 的基（按晶胞缓存），在约化基里做同样的枚举，结果换回原基的像
L* = min |w|；并列 = { |w| ≤ L* + mic_tie }；并列多于一个时取 key 字典序最小者，key_k = round(1e6·(g + n0 + n)_k)   # 原基下的有效坐标；1e-6 的取整吸收末位误差
返回 (w, n0 + n)
```
- **已验证**（`mic_py.py` + `mic_js.mjs`）：六方 p(3×3) slab 胞、c 倾斜的斜胞、极端剪切胞 [[1,0,0],[7.3,0.4,0],[0,0,10]]、Cu c(2×2) 胞，
  半格矢组合加 300 个随机矢量，三轴与"只在 a、b 上"两种模式：与穷举比较 1988 个矢量 0 不符；Python 与 JS 选出的像 2544 个中 0 不同（两边线性求解的实现不同，
  并列规则照样一致）。
- 并列规则的含义：等长时优先分量更小（更负）的有效坐标，例如 c(2×2) 中 (−0.5, 0.5) 与 (0.5, 0.5) 等长时取 (−0.5, …)。
- `Structure._vector`（`core/structure.py:481-487`）随之改用新实现：`get_distance(mic=True)` 只在斜晶胞（原来算错）和精确并列时结果改变，属于修正。
- 核心层 `mic=True` 仍是"所有周期轴上的普通最小像"（ASE 语义）；"不跨真空"的编辑坐标系只用于 §3.6–3.10 的 GUI 语义与新帮助函数（K1）。

### 3.3 表面法向、外法向与框架

```
surfaceNormal(s) -> {normal, axis, source} | null          # F0-A §3.13.2（info → vacuum → pbc → ab-plane → null）
hasSurface(s)    = surfaceNormal(s)?.source ∈ {'info', 'vacuum', 'pbc'}      # 体相的 'ab-plane' 不算（D14/E10）
side(s, points, side='auto') -> ('top' | 'bottom', n_out)
  n = surfaceNormal(s).normal（hasSurface 为假时 n = +z，side 固定 'top'）
  H = 基底原子（§3.5；没有基底时用全部原子）在编辑坐标系中沿 n 的高度；top = max H，bottom = min H
  h = 点集（编辑坐标系）质心沿 n 的高度

               否则 h ≥ (top + bottom)/2 → 'top'，否则 'bottom'
  n_out = (side == 'top') ? n : −n
```
- 所有"上方""Out of the surface""高度"读数、点击放置、粘贴都用 `n_out`（D5：v1 对底层三重空位放置时新原子离第二层 Pt 只有 0.263 Å；

```
frame_axes(s, frame):

```

### 3.6 哪些原子移动：`moving_group(s, atoms, mode='auto', *, graph=None, substrate=None)`（K2）

#### 3.6.1 两侧的定义（与 v1 相同）

k = len(atoms) ∈ {2, 3, 4}，按点选顺序。

| 几何 | 末侧（last）根 | 切断的键 | 禁入顶点 | 末侧不得包含 | 末侧必须包含 | 首侧（first）根 / 不得包含 / 必须包含 |
|---|---|---|---|---|---|---|
| 距离 a0–a1 | a1 | (a0, a1) 的所有像 | — | a0 | — | a0 / a1 / — |
| 角 a0–a1–a2 | a2 | (a1, a2) | a1 | a0 | — | a0（切 (a1, a0)，禁入 a1）/ a2 / — |
| 二面角 a0–a1–a2–a3 | a2 | (a1, a2) | — | a0, a1 | a3 | a1 / a2, a3 / a0 |

#### 3.6.2 算法

```
moving_group(s, atoms, mode):
  mode 是下标列表 → 'custom'：G 去重排序；G 必须含 atoms[-1]、不得含 atoms[0]，否则
                     ValueError("the atoms that move must include the last atom and not the first one")；返回 {G, side 'last', rule 'custom'}
  mode == 'last'   → {[atoms[-1]], 'last', 'last'}
  graph = graph or bond_graph(s)；sub = substrate or substrate_mask(s, graph).mask
  nonsub = { i : not sub[i] }
  候选(X)：                                   # X ∈ {last, first}，root/cut/blocked/不得/必须 按 3.6.1
    if mode == 'fragment':                    # 严格 MS（只供 API）：全图、只看末侧
        R2 on 全图；满足"不得/必须"即候选（即使 extended）
    elif sub[root]: 无候选                     # 基底原子永远不作为片段移动
    else 依次：
      R1 'adsorbate'：adsorbate_id(root) > 0 → 同 id 的全部原子（满足"不得/必须"、组内连通且不是 extended）
      R2 'fragment' ：component(graph, root, cut, blocked, allowed = nonsub)    满足"不得/必须"且非 extended
      R3 'molecule' ：同 R2，另 skip 金属–非金属键                             满足"不得/必须"且非 extended
      （R2 因"不得包含"失败时记 ring = True：两侧经非基底原子相连，例如环上的键）
  if mode == 'fragment': 末侧候选存在 → 返回它
  else ('auto'):
    L = 末侧第一个候选；F = 首侧第一个候选
    if L 且 F：
       if (|L| > n/2 且 |L| > 2|F|)                 # L 是体系主体（例如无晶胞的 Pt55 团簇 + CO）
          or (L 含完全固定(F F F)原子 且 F 不含):   # 约束只作平局规则（D2/E3）
          L = None
    L → 返回 {L, 'last', rule}；否则 F → 返回 {F, 'first', rule}
  回退 'atom'：end = atoms[-1]，side 'last'；若 mode == 'auto' 且 end 完全固定而 atoms[0] 不是，end = atoms[0]（side 'first'）
               组 = {end} ∪ {end 的非基底端基：只与 end 成键、且不是定义原子的原子}；ring 标志随结果返回
返回 MovingGroup{indices（升序）, side, rule, root, offsets（相对 root 的整数像偏移，custom 时为 None）, ring}
```
- `offsets` 直接给出移动组的紧凑像（§3.8 旋转时用），不需要另做展开。
- 规则名（界面说明行）：`adsorbate group` / `bonded fragment` / `molecule (bonds to metal atoms ignored)` / `atom and its terminal neighbours` / `last atom only` / `chosen atoms`。
  `ring` 为真时说明行加 `This bond is in a ring; only C #1 and its H move.`（E25-a）。
- 与 v1 的差别：(1) 键图与显示无关（§3.4）；(2) 基底优先，"锚定"不再看约束（v1 的 `anchored(G) = extended 或含约束原子` 删除）；(3) 回退时只在两端都是基底
  （晶格内的键）或环上的键时发生，因此只剩"完全固定"的平局规则。

#### 3.6.3 `Both sides`（仅距离，D17）

两端的根都不是基底原子时可用：`G_last`、`G_first` 分别按 3.6.2 的 auto 规则只取各自一侧（某侧无候选时用该端原子加非基底端基），两组不相交；
`set_distance(fix=0.5)`，`G_first` 中每个原子与 a0 同移（`x·fix·D`），`G_last` 中每个原子与 a1 同移（`−x·(1−fix)·D`）。环上的键（苯 C–C）因此得到
"两端各带自己的 H 各动一半"。一端是基底时选项禁用，tip `Both sides needs two atoms that are not part of the slab.`。

#### 3.6.4 `Swap ends` 与 `Custom…`

- `Swap ends` 把原子顺序反转（角、二面角对顺序反转对称；距离等价于交换两端），说明行与高亮随之更新。
- `Custom…`：Geometry 表单进入拾取模式（选区不变，点击/框选切换"要移动"的原子，高亮 `m4-moving`），`Done` 结束；API `move=[indices]`（D2-5）。

### 3.7 展开、质心与刚体变换

#### 3.7.1 展开一组原子 `unwrap_group(s, indices, *, ref=None, ref_pos=None, graph=None, frame=None) -> P[k, 3]`

```
fr = frame or edit_frame(s)；ref = ref ?? indices[0]；ref_pos = ref_pos ?? fr.pos[ref]   # 合同：ref_pos − r_ref 是格矢
无晶胞或 pbc 全 F → 存储坐标
len(indices) > unwrap_bond_limit（5000）→ 快速路径：P_j = ref_pos + vdiff_to(ref_pos, fr.pos[j])      # 向量化，见下
否则：在组内子图上 BFS（component(graph, root, allowed = set(indices))），先处理含 ref 的分量：
  root == ref：base = ref_pos − r_ref
  其他分量：   base = (ref_pos + mic_vector(fr.pos[root] − ref_pos, axes = fr.mic_axes)) − r_root   # 该分量的根放到离 ref 最近的像
  非 extended 分量：P_j = r_j + offsets[j] @ cell + base
  extended 分量（整层、整块）：P_j = ref_pos + mic_vector(fr.pos[j] − ref_pos, axes = fr.mic_axes)   # 只在面内取最小像，沿间隙轴用切口坐标
```
- 快速路径的向量化：所有原子一次求投影系数、`floor(x + 0.5)`，再按 §3.2.2 的界枚举（约化基里通常为 ±1，即 9 或 27 个候选），并列规则同 §3.2.2；1 万原子 Python 4.7 ms（`perf2.py`），
  JS 预算 ≤ 10 ms。
- 验证：SrTiO3 7L（审查 `t_unwrap_thick.py`，v1 把顶层 8 个原子放到 z = −10 Å）与 Pt(111) p(6×6) 6L/10 Å、8L/15 Å（`scen2.py`）展开后 z 范围与存储坐标相同。

#### 3.7.2 质心与枢轴

- `get_centroid(indices=None, *, mic=False, weights=None)`：`mic=True` 时为 `unwrap_group(...)` 的平均（`weights='mass'` 为质心）；`mic=False` 为存储坐标的平均。
  `move_to`、`rotate(center='COP'/'COM')`、"上方"放置、复制载荷都用 `mic=True`。
- 网页端**枢轴的画出位置** = 质心 + (参考原子画出副本的位置 − 参考原子的编辑坐标)，参考原子 = 最后点选的原子（有点选副本时用那个副本，否则用家副本 `r + h @ cell`）。

#### 3.7.3 点选副本（D6 的部分采纳）

- M4 监听视图的 `atomclick`（以及 Move 工具里 `up()` 返回 `false` 后视图发出的点击，A-CR4），把被点中的副本记成存储像 `S = h_src + img`
  （`keyOf(model, d)` 给出 `src:ia,ib,ic`，`render/display.js:225`）：`pickedImages: Map<src, S>`，模块级状态，选区事件到来时删掉不在选区里的条目；
  框选、全选、按下标选择、撤销后清空。
- 当选区的**每个**原子都有点选副本时，质心、"上方"放置、卡片读数与 `Set…` 的定义位置都用这些副本（所见即所得）；否则用编辑坐标系（§3.7.1、§3.8.1）。
- 一个源原子只记一个副本，所以在 c(2×2)、p(1×1) 这类小晶胞里仍然无法"选中同一原子的两个像"组成空位；这类位点由 M5 的位点、`Fractional` 输入或 API 的显式像
  （§3.9.2）给出，HUD 的位点标签如实显示得到的是哪种位点（§3.9.4）。完整的"按副本选择"不在本期（见"未采纳的意见"）。

#### 3.7.4 平移

```

  v = vector @ cell if frac else vector      # frac 而无晶胞 → ValueError("fractional coordinates need a unit cell")
```

`Out of the surface`：`v = h · n_out`（§3.3），由调用方算好后 `translate`。

#### 3.7.5 旋转（ASE 形式，D13/E15/E16）

```
rotate(s, a, v, center=(0,0,0), rotate_cell=False, *, indices=None, mic=False):
  if a 不是实数: a, v = v, a                     # ASE：rotate('z', 90) ≡ rotate(90, 'z')；两矢量时交换后 v 是"源"，a 是"目标"（ASE atoms.py:1161-1248）
  v = axis_vector(s, v)        # 'x' 'y' 'z' '-x' …；扩展 'a' 'b' 'c' '-a' …（需晶胞）、'normal'（需 hasSurface）；或 3 矢量
  if a 是实数: R = R(v̂, a)
  else:                        # 把"源"方向转到"目标"方向（ASE 的两矢量形式）
     src = v̂（原来的第一个参数）；dst = unit(axis_vector(s, a))（原来的第二个参数）
     w = src × dst；s_ = |w|；c_ = src·dst
     s_ < 1e-7 → w = ẑ × dst；仍 < 1e-7 → w = x̂ × dst    # 平行或反平行（与 ASE 相同的确定性选择）
     R 由 cosθ = c_、sinθ = s_、轴 ŵ 组成
  rotate_cell: indices 必须为 None（否则 ValueError("rotate_cell rotates every atom; do not pass indices")）；
               所有原子与晶胞行一起旋转（cell' = cell @ R.T），约束标志不变（F0-D §3.8.3：刚性旋转）；
               info.surface.normal 存在时同样旋转；保留空间群（C7：刚性重定向）
  idx = indices or all；Q = unwrap_group(s, idx) if mic else s.positions[idx]
  C = center_point(s, center, Q)  # (x,y,z) | 'COP'/'centroid' → Q 的平均 | 'COM' | 'COU' → 晶胞对角线中点 | int → 该原子在 Q 中的位置；
                                  # int 不在 idx 中且 mic 时取它离 Q[0] 最近的像（E21-d）
  ΔP = (Q − C) @ R.T + C − Q；s.positions[idx] += ΔP          # 位移加回存储坐标：存储的像选择不变
  not rotate_cell → invalidate_symmetry_info(info)
```
- 验证：`rotate('x', 'y')` 把 (1,0,0) 变为 (0,1,0)（v1 伪代码先交换再取 `â × v̂`，方向反了，E15 的 `r6_rotate2v.py`）；`rotate(90, 'z')` 同 ASE。
- 多帧结构抛 `ValueError("rotate works on a single frame; this structure has 20 frames (use get_frame(i) first)")`（K7）。
- `mirror(normal, center=(0,0,0), *, indices=None, mic=False)`（可选）：`Q' = Q − 2((Q − C)·n̂) n̂`。
- `Skip fixed atoms`（应该）：对每个移动原子 i 的位移 d_i，`df = d_i @ inv(L)`，把 `selective_dynamics[i]` 为 False 的分量置 0，`d_i' = df @ L`；L = 晶胞，
  没有晶胞时 L = I（标志指 x/y/z，F0-D §3.8.1，E9）。旋转时这会破坏刚性，HUD 提示 `Fixed directions are kept; the group may deform.`。

#### 3.7.6 旋转周期网络与 `info.surface.normal`（D16、D14-3、E21-c）

- 被旋转的组包含某个 extended 分量的全部原子，或包含全部原子，且 R 不把周期格矢映到格矢（`R·a_k` 在晶胞基下的系数都在整数 ±1e-3 以内才算对称角，例如六方 60°/120°、
  四方 90°）时：预览条与 HUD 显示 `Rotating a periodic network breaks the crystal; use Cell › Re-orient to rotate the cell with the atoms.`，`Apply` 仍可用。整层平移不提示。
- `rotate_cell=False` 且旋转全部原子、结构有 `info.surface.normal`：删除该字段并 `add_warning(info, "the surface normal in info.surface was removed because all atoms were rotated without the cell")`
  （否则 F0-A `surfaceNormal` 规则 1 会给出过期的法向）；网页 toast 同一句（首字母大写）。

### 3.8 设定距离、角度、二面角

#### 3.8.1 定义几何的位置

```
defining_positions(s, atoms, *, mic=False, images=None, frame=None) -> P[k, 3]
  images 给出 → P_k = r[atoms[k]] + images[k] @ cell                   # images = 存储像 S（测量键、点选副本、API）
  mic=False   → P = r[atoms]                                              # ASE 原样
  GUI（move= 给出或网页端）→ 编辑坐标系：k == 3：P1 = fr.pos[a1]；P0 = P1 + vdiff，P2 = P1 + vdiff（两边从顶点出发）
                              否则最小像链：P0 = fr.pos[a0]；P_{k+1} = P_k + vdiff(P_k → a_{k+1})
  核心 mic=True（无 move）→ 同上的链，但用所有周期轴上的普通最小像（ASE get_dihedrals 的 mic 语义）
chain_images(s, atoms) -> images     # 上面 GUI 链对应的整数存储像，供 API 显式传入；网页的卡片读数、预填值、HUD 与 Set… 用同一组（E6）
```
- 测量键 `"i:I"` 的存储像 `S = h_i + I`（§3.2.3）。v1 的 `I − home(f)` 换算删除。
- 验证：`setgeo2.py`：O 存在 a 面另一侧（存储 C–O 8.395 Å，链上 1.150 Å），角度 180° → 150° → 170°，C–O 保持 1.1500 Å，O 仍在原来的存储像里。

#### 3.8.2 ASE 语义的核心（`move=None`）

```
set_distance(a0, a1, distance, fix=0.5, mic=False, mask=None, indices=None, add=False, factor=False, *, move=None, images=None)
  a0 ≡ a1 → ValueError("a0 and a1 must be different atoms")
  P = defining_positions(...); D = P1 − P0; L = |D|;  L < 1e-8 → ValueError("the two atoms are at the same position")
  target = add ? (factor ? L·distance : L + distance) : distance;  target ≤ 0 → ValueError("distance must be positive (got …)")
  x = 1 − target / L
  idx = mask→索引 / indices / 默认 [a0, a1]
  for i in idx: r[i] += (i == a0) ? x·fix·D : −x·(1 − fix)·D        # 与 ASE 完全相同（atoms.py:1577-1626，审查已核对）
set_angle(a1, a2, a3, angle, mask=None, indices=None, add=False, *, mic=False, images=None, move=None, toward=None)
  P = defining_positions(...); v10 = P0 − P1; v12 = P2 − P1；任一为零 → ValueError
  非 add 时 0 ≤ angle ≤ 180，否则 ValueError("angle must be between 0 and 180 degrees (got …)")
  diff = add ? angle : angle − ∠(v10, v12)
  axis = v10 × v12；共线时见 §3.8.4
  idx 默认 [a3]；Q = (mic、images 或 move 给出) ? 紧凑像（moving_group 的 offsets 接在 P2 上，或 unwrap_group(s, idx, ref=a3, ref_pos=P2)）: r[idx]
  绕 axis、过 P1 转 diff，位移加回 r[idx]
set_dihedral(a1, a2, a3, a4, angle, mask=None, indices=None, *, add=False, mic=False, images=None, move=None)
  未定义 → ValueError("this dihedral is undefined: three of its atoms are in a line")
  diff = add ? angle : ((angle − current + 180) mod 360) − 180
  idx 默认 [a4]；Q 同上，接在 P3 上；绕 axis = P2 − P1、过 P2 转 diff
rotate_dihedral(a1, a2, a3, a4, angle, mask=None, indices=None, *, mic=False) = set_dihedral(..., add=True)
```
- 与 ASE 的差别只在扩展参数：ASE 的 `set_angle/set_dihedral` 不支持 `mic`；`set_dihedral` 的 `add` 在 ASE 里由 `rotate_dihedral` 提供。
- `mask` 与 `indices` 同时给出：ASE 中 `set_distance` 以 mask 为准、`set_angle/set_dihedral` 以 indices 为准（审查已核对）；我们**一律报错**
  `use either mask or indices, not both`，在文档的"与 ASE 的差异"一节写明（D13-2）。
- 多帧结构抛错（K7）；`invalidate_symmetry_info`（C7）。

#### 3.8.3 GUI 语义（`move='auto' | 'last' | 'both' | 'fragment' | [indices]`）

```
apply_set(s, atoms, value, move='auto', images=None):
  g = moving_group(s, atoms, mode=move)                 # §3.6
  if g.side == 'first': atoms = reversed(atoms); images = reversed(images)
  images = images ?? picked images ?? chain_images(s, atoms)       # 编辑坐标系（§3.8.1）
```

#### 3.8.4 共线时的转向（`toward`，D11-3）

`set_angle` 的 v10 与 v12 共线（顶位 CO 的 Pt–C–O = 180°）时没有转轴。规则：`t = toward ?? 默认方向`，去掉沿 v12 的分量后单位化（为零时依次改用 b、y），
`axis = unit(v12 × t)`，转角 `φ = current − target`——末端原子朝 t 方向偏转。默认方向：网页 = 屏幕右方向（相机 right 矢量），API = 晶胞 a（无晶胞时 x）。
`setgeo2.py`：从 180° 设到 150°，O 朝 +a 偏转（位移 (0.575, 0, −0.154) Å）。

### 3.9 放置（K9）

#### 3.9.1 放置点 `site_point(s, atoms, *, images=None, bond=None, height=None, side='auto', symbol=None) -> SitePoint`

```
fr = edit_frame(s)；sub = substrate_mask(s).mask（为空时用全部原子）
Q = images 给出 ? [r_i + S_i @ cell] : unwrap_group(s, atoms, frame=fr)；c = Q 的平均
(side, n_out) = side(s, Q, side)                                                 # §3.3
height 给出 → point = c + height·n_out
否则：d = bond ?? place_bond_factor·(r_cov(symbol) + r_cov(选区中离 c 最近的原子))      # §3.9.3
      t* = max over 基底原子 j（取离 c 最近的像，vdiff）满足 ρ_j² = |Δ_j|² − h_j² < d² 的 [h_j + sqrt(d² − ρ_j²)]
           （Δ_j = vdiff(c → j)，h_j = Δ_j·n_out）
      没有这样的 j → t* = add_height，并记 fallback（界面提示 `No surface atom is within 2.02 Å of this point; placed 2.00 Å above it.`）
      point = c + t*·n_out
返回 SitePoint{point, normal: n_out, side, height: t*, bond: d, contacts: [离 point 在 d + site_contact_tol 内的基底原子], label}
```
- 为什么是闭式解：对 c 上方的点 c + t·n_out，到基底原子 j 的距离 `sqrt(ρ_j² + (t − h_j)²)` 在 t > h_j 时随 t 单调增；取各 j 的解的最大值，
  就同时保证"离所有基底原子 ≥ d"与"至少与一个原子恰为 d"。这与审查建议的"从上往下二分"给出同一个点，但不需要迭代（D4-1）。
- 选区质心在空位中心时 ρ = 外接圆半径，得 `h = sqrt(d² − ρ²)`；在原子正上方时 h = d；台阶面上取局部最高的接触，不受远处台阶边缘影响（D4）。

#### 3.9.2 显式像与小晶胞

`atoms` 可以带存储像：Python `site_point(s, [(6, (1,0,0)), (7, (0,0,0)), (6, (0,0,0)), (7, (0,1,0))], bond=1.96)`，JS `sitePoint(s, ['6:1,0,0', '7:0,0,0', …])`
（与测量键同一写法，像为存储像）。`scen3.py`：Cu(100) c(2×2) 胞里只选两个顶层原子得到桥位（高 1.486 Å），用四个显式像得到四重空位（高 0.758 Å，四个 Cu 都是 1.96 Å）。

#### 3.9.5 元素解析 `parse_element(text) -> str`（E18）

```
t = text.strip()；空 → ValueError("enter an element symbol")
t.lower() == 'x' → 'X'（哑原子）
t.upper() ∈ {'D', 'T'} → 'H'
sym = normalize_symbol(t)（Python core/elements.py:75-100；JS core/elements.js:138-154；都接受原子序数与 Fe3+、Fe_pv 之类）
sym == 'X' 或 不是已知元素 → ValueError("unknown element symbol 'Xx'")；界面 `“Xx” is not an element symbol. Try Fe, O or Ti.`
```
两种语言对一组输入（`fe`、`FE`、`CO`、`26`、`Fe3+`、`O2-`、`Fe_pv`、`D`、`x`、`Xx`、`Q`）逐项相同（跨语言金标）。现有 Replace（`ui/selectioncard.js:144`）不改（仍不允许 X）。

#### 3.9.7 加原子


#### 3.9.8 合并 `extend` 的放置、锚点与取向（D8）

```
extend(s, other, *, offset=None, rotation=None, center=None, position=None, anchor='centroid', normal=None, orient=None,
       mic=False, frame=None, adsorbate=False) -> self
  O = other.get_frame(frame) if frame is not None else other（网页：other 的当前帧，E21-a）
  Q = unwrap_group(O, all) if mic and O 周期 else O.positions
  A0 = anchor_point(O, Q, anchor, normal)：
       'binding'  → 下标 = 第一个不是 H 的原子（全是 H 时 0）；也可直接给 int
       'contact'  → 沿 -normal（默认 −n_out，没有时 −z）最低一层重原子（离最低重原子 ≤ 0.5 Å 的非 H 原子）的质心
       'bottom'   → 沿 −normal 最低的原子，比较带 lowest_tie（1e-3 Å），并列取并列原子的质心（D15-3）
       'centroid' / 'COM' / 3 矢量
  orient（应该）：'binding_down' → 把 unit(其余原子质心 − 锚点原子) 转到 n_out（ASE 两矢量规则）；
                  'flat' → 把最佳平面法向（协方差矩阵最小特征值的特征矢量，符号取与 n_out 夹角 ≤ 90°）转到 n_out；JS 用 3×3 Jacobi
  rotation：3×3（正交、det = +1，误差 1e-6）或 (angle, axis)；C = center ?? A0；Q = (Q − C) @ R.T + C；A0 同样变换
  t = (position − A0 if position is not None else 0) + (offset or 0)
  追加 Q + t：符号、坐标；帧规则同现有 Python extend（`core/structure.py:629-651`：帧数相同则拼接，否则丢 self 的帧并写警告）；JS 新增，同规则
  props：F0-D `_remap(…, added_props=other.props)`（键并集、缺键方用 PROP_DEFAULTS、RESULT_PROPS 规则）；
         adsorbate=True → §3.10.5；否则 adsorbate_id 按 M5 规则重编号（完整的源吸附物 g → g + max(self 的 id)，记录随之复制）
  selective_dynamics：不重置时，若两者晶胞不同，先对 other 的副本 F0-D apply_basis_change(other_copy, other.cell 或 I, s.cell)（E9）
  info：self 的保留，other 的忽略（M5 记录除外，§3.10.5）；invalidate_symmetry_info
  返回 self；源映射：原原子恒等，新原子 −1（网页端 indexMap 恒等）
```
- 审查原型 `t_anchor.py`/`t_jsmol.mjs`：两个分子库里 ammonia、water、methanol、ethanol 的"最低原子"多为 H；加 0.02 Å 起伏后用"最低原子"做锚点，双齿甲酸根面内偏 1.14 Å、
  平躺苯偏 1.93 Å，用 `contact` 两者 0.00 Å。所以界面默认 `Binding atom`（插入）与 `Contact atoms`（粘贴，载荷有锚定原子时用它，§3.10.1）。
- M5 放吸附物可直接用：`slab.extend(ads, position=site + h·n, anchor=ads_binding_index, rotation=R, adsorbate=True)`（§10）。

#### 3.10.3 放置模式（粘贴与插入共用）

平移 `t = T − A`；载荷原子在编辑前先按 `payload.normal → n_out` 的两矢量旋转对齐（两者都存在且夹角 > 1e-6 时；例如从顶面复制、粘到底面时 CO 翻转朝下）。

| 模式 | A（载荷锚点） | T（目标点） | 用途 |
|---|---|---|---|
| `same` | — | — | t = 0 |
| `offset` | — | — | t = offset（默认见 §3.10.4） |
| `centroid` | 载荷质心 | 目标选区（编辑坐标系）的质心 | 放到一组原子中间 |
| `above` | 锚点原子（`anchor`） | `site_point(目标选区, bond = payload.bond ?? 默认).point` | 顶位/桥位/空位：选 1/2/3/4 个原子 |
| `surface` | 锚点原子 | 锚点原来的面内位置上、按 §3.9.1 闭式解求的高度（c = 锚点面内位置投到局部表面） | slab → 另一个 slab，保持锚定键长 |
| `point` | 锚点或质心 | 给定点（Å 或分数） | 精确位置 |
| `here`（可选，仅界面） | 锚点原子 | 点击射线与"过原锚点、法向 n_out"的平面的交点 | 右键空白处 `Paste here`，保持高度 |

#### 3.10.4 Ctrl/⌘ V 的默认（D18、E22-c/f）

```
if 目标 == 源结构 且 not source.cut 且 载荷每个原子在 overlap_tol 内（vdiff，编辑坐标系）与同元素的现有原子重合:
    'offset'：L_min = max(载荷沿 u 的宽度 + paste_gap, paste_offset_min)       # u = 相机右方向投到表面内；API 用 â 的面内单位矢量
              有 1×1 表面网格（info.supercellMatrix 的 2×2 块 det > 1：t1, t2 = inv(S) @ [a; b]，M5 同一规则）：
                 候选 = i·t1 + j·t2（|i|, |j| ≤ 6，且不是晶胞 a、b 的整数组合——否则平移后与原分子的周期像重合），长度 ≥ L_min
                 取方向与 u 最接近者，并列取更短、再取 |i| + |j| 小、再字典序
              否则：offset = u·L_min
              偏移后若与现有原子有近距离接触（§3.13），依次试下一个候选（最多 12 个）
elif 目标 ≠ 源 且 hasSurface(目标) 且 payload.bond 不为 null: 'surface'
else: 'same'
```
- 偏移一个 1×1 表面格矢使复制出的吸附物落在等价位点上（搭覆盖度系列、比较构型最常用）；没有网格信息时（导入的 CONTCAR）退回非格矢平移——
  **不能**用晶胞自己的 a、b：那会与原分子的周期像完全重合。
- 竖立的 CO 沿 u 宽度约为 0：v1 只偏 1.5 Å，v2 至少 3.0 Å（E22-f）。

#### 3.10.5 粘贴/插入/加原子后的数据（D7、K6、K10）

```

    目标还没有 adsorbate_id 键，或没有 > 0 的值：先 promote——M3 find_adsorbates(目标) 的结果（来源 tags/geometry）按化学键连通片段各编一个 id（1, 2, …）
```

#### 3.11.1 手柄与尺寸（CSS px，在枢轴深度换算为 Å：`size_Å = size_px · viewer.worldPerPixel(pivot)`）

#### 3.11.2 拖动

记按下时的射线 ray0、枢轴 C（画出坐标），当前射线 ray。
```
轴：      q = viewer.pointOnLine(x, y, C, û)（F0-A）；Δ = (q.s − q0.s)·û；|û·d̂| > 0.996 时保持上一个值
平面：    q = viewer.pointOnPlane(x, y, C, n̂_plane)；Δ = q − q0
直接拖原子：有法向且未开 Screen plane 且 |n̂·d̂| ≥ 0.2：q = pointOnPlane(x, y, G, n̂)；否则 q = pointOnPlane(x, y, G, −viewDir)   # G = 抓取点（被按下副本的画出位置）
中心：    q = pointOnPlane(x, y, C, −viewDir)
旋转：    |û·d̂| > 0.2：q = pointOnPlane(x, y, C, û)；raw = signedAngle(q0 − C, q − C, û)
          否则（环侧对）：按下时取环在抓取点的屏幕切向 τ 与屏幕半径 ρ；raw = ((m − m0)·τ / ρ)·180/π
          θ = accumulate(θ_prev, raw_prev, raw)                                    # 跨 ±180° 连续
精细（Shift）：在增量上乘 fine_factor
取整（Ctrl/⌘ 或常开）：§3.11.3
预览：平移 P_i = base_i + Δ；旋转 P_i = base_i + (R(û, θ)(Q_i − C') + C' − Q_i)，Q = 按下时缓存的编辑坐标系紧凑像（§3.7.1），C' = 质心或活动原子
```
- 透视与正交相机都适用；相机在拖动中变化时用当前射线重算，Δ 以按下时为基准，因而连续。
- v1 原型 `movemath.mjs` 的用例（沿 x 拖 1.5 Å 得 1.500000；偏离轴 40 px 仍只得 x 分量；环 30° 得 30.000000；跨 ±180° 累加；轴平行视线返回 null）保留为单元测试；
  `pointOnLine` 由 F0-A 提供，v1 的 `rayAxisParam` 不再自写。
- D9：屏幕平面拖动时高度改变 = 屏幕竖直位移 × sinθ（θ 为视线与法向夹角；30° 时每拖 1 Å 高度变 0.50 Å），表面平面拖动时恒为 0。

#### 3.11.3 取整（D19）

- 轴：沿 û 的长度取整到步长；平面/中心/直接拖：在框架各轴的**逆变分量**上分别取整（`Δ = α·ê1 + β·ê2 (+ γ·ê3)`，对 Lattice 框架即 Δ 的分数坐标乘轴长）；旋转：θ 取整到步长。
- Lattice 框架另有 `Snap: 1/n of a, b`（可选）：n = `info.supercellMatrix` 的对角元（p(3×3) 时 1/3，正好一个 1×1 格矢）。

#### 3.11.4 拖动生命周期（F0-A §3.12.3–3.12.4 的契约）

```
claims(hit, e):  触摸/笔：命中手柄（屏幕空间）或 hit.atom 是已选原子
down(e, hit, p): 命中手柄 → 开始；hit.atom 是已选原子 → 记为"可能的直接拖动"（移动 ≥ 5 px 才真正开始）；其余返回 false（视图照常框选）
start:           session = app.beginStructureEdit(label, {kind: 'positions', owner: 'move-tool'})；缓存 base（当前帧 Float64 坐标）、选区、
                 紧凑像（只旋转需要）、h = viewer.homeOffsets()
move(e, p):      算 Δ 或 θ → 新坐标 → session.preview({indices, positions})；HUD 读数（aria-live 4 Hz 节流）
up(e, p, {click}): click → 返回 false（视图按普通点击处理：选择、双击检测，A-CR4）；
                 位移为 0 → session.cancel()；否则 session.commit(null, {keepFrame: true})（A-CR3：多帧时完整快照并只保留当前帧）
cancel(p, reason): session.cancel(reason)
```
- 修饰键：按下时的 Shift/Ctrl/⌘ 只在这次按下最终是点击时决定选择方式（`render/viewer.js:64` 的 `selectMode`）；拖动中只看实时的 Shift（精细）与 Ctrl/⌘（取整）；
  macOS 上 Ctrl+左键是右键（`render/viewer.js:368`），所以取整用 ⌘；Alt 在按下时表示平移视图（现状），拖动中按住 Alt 暂停目标吸附。
- 提交后若含受约束原子：toast `Moved 12 atoms (4 fixed atoms included).`（直接操作本身不发 toast）；丢帧的说明由 F0-A 的 `editActive` toast 统一给出（E20）。
- 预览期间画出的每个副本按其源原子的位移平移、键冻结（F0-A §3.7.1）；提交后正常重建：跨面的原子可能画到对面（§8 R3）。

### 3.12 编辑后的测量键（D3/E1，A-CR1）

规则：**存储像不变**。编辑前后对每个被测量引用的原子 i（下标先按 `indexMap` 映射）：
```
S = h_before[i] + I        # 编辑前视图用的 homeOffsets（P-pos 会话开始时冻结的那份）
I' = S − h_after[i']       # 编辑后按新坐标、新间隙重算的 homeOffsets
键 "i:I" → "i':I'"
```
- 被移动原子的存储坐标连续变化，同一个存储像就是拖动中跟着走的那个副本；没动的原子在间隙切口移动时（例如把分子拖进真空）同样保持指向同一副本。
- 由 F0-A 的 `editActive` 在 `_afterEdit` 第 2 步之后对所有 `latticeChanged` 为假的编辑执行（O(n)，1 万原子 < 1 ms），M3、M5、M2 的 `center_slab` 也受益；
  这是 F0-A 变更请求 A-CR1（F0-A §8 R7 把此事留给 M4，§10）。
- `keys2.mjs` 对照 F0-A 显示原型：底层原子（存为 f = 0.99995）上移 0.1 Å：键 `0:0,0,0` 不变、指向 0.099 Å 处的同一副本（v1 的 floor 规则改成 `0:0,0,1`，解析不到，测量被丢，
  E1 的 `r3_gapkeys.mjs`）；原子跨 a 面：正确；CO 被拖进真空 12 Å 使切口移动：C 的键改指存储像，该副本不再绘制，测量保留但不画（`render/viewer.js:1003-1028`
  的现有行为："kept but never drawn"），不会静默改指到另一个副本。此时 toast 第二行 `1 measurement is hidden: its atoms are no longer drawn next to each other.`。

### 3.13 近距离接触检查（应该）

对新加、粘贴、插入、被移动的原子集合 M（|M| ≤ 2000 时做）：在编辑坐标系中用网格找 M 中原子与其他原子的最近对（`vdiff`），若 `d < contact_factor·(r_cov,i + r_cov,j)`，
toast（info）`Close contact: C #73 is 1.33 Å from Pt #12.`（只报最近的一对，另附 `and 2 more`）。阈值例：C–Pt 1.59 Å、C–O 1.07 Å、O–H 0.73 Å。

## 8. 风险与开放问题

### 8.1 风险

| 编号 | 风险 | 对策 |
|---|---|---|
| R1 | 移动组规则是启发式，个别体系会出乎意料（无 tags 的同元素吸附原子、M3 几何识别的已知局限：两面都有吸附物、上半部的外来替位层） | 应用前高亮并列出将移动的原子；`Last atom only`、`Both sides`、`Custom…`、`Swap ends`；API 返回 `rule/side/ring`；21 个场景固化为测试；M3 的 `Exclude adsorbates` 开关与 `sel.adsorbates` 让用户看到识别结果 |
| R2 | 二面角显示与设定符号不一致（JS 现在符号相反） | 依赖 F0-D T9 先统一为 IUPAC（`dihedralFromVectors`/`signedAngle`）；M4 的卡片读数直接用它们 |
| R3 | 原子被移过晶胞面或真空中点后，提交时显示按新的包裹/切口重画：面内跨面的原子画到对面；吸附物被拖过真空一半时，F0-A 在 P-pos 期间冻结切口、提交后重算，它会被画到 slab 下方（E24） | 预览期间不重新包裹；测量键按存储像跟随（§3.12）；HUD 在移动组越过真空中点时提示 `Past the middle of the vacuum: it will be drawn below the slab.`；存储坐标不包裹（Q3） |
| R4 | 浏览器对自定义剪贴板类型的支持不一（Safari 按来源隔离、部分环境丢弃） | 文本里带标记 + 内存副本 + 带标记的 extxyz 可独立解析，三重保障；载荷一律校验 |
| R5 | 默认放置键长（共价半径之和）对金属上的 H 偏短约 0.2 Å、对 N/Ru 偏高（审查 `t_height2.py`） | 读数显示实际键长与位点，键长/高度可直接输入；精确的吸附几何由 M5 的库与模式给出 |
| R6 | 移动固定原子可能是误操作 | HUD 与 toast 提示；`Skip fixed atoms`（Q1） |
| R7 | 金属–非金属切键规则对金属有机配合物会把整个配体当作"分子"刚性移动 | 这通常正是想要的；可用 `Last atom only` 或 `Custom…` |
| R8 | 键图与基底在 1 万原子时首次计算约 250 ms，打开几何表单时有感知延迟 | `structureKey` 缓存；首次计算时说明行显示 `Finding fragments…` |
| R9 | `copy` 事件必须同步写入，超大选区会卡顿 | 上限 20 万原子；超过 5 万原子先 toast 提示 |
| R10 | 需要 F0-A 的四项变更请求（A-CR1–A-CR4）；若 F0-A 不接受 A-CR1，测量键会在切口移动后指向别的副本 | 在 §9 依赖列注明；A-CR1 不被接受时退路：M4 在自己的提交路径（P-pos 与 `editActive` 调用）里按同一公式重写键，只覆盖 M4 的编辑 |
| R11 | 台阶面边缘用宏观法向放置，对强烈倾斜的局部表面不理想（E 缺失项 7） | 闭式高度保证不穿进局部最高处；文档说明；局部法向留给 M5 |
| R12 | 小晶胞（c(2×2)、p(1×1)）里按源原子选不出空位（D6） | 位点标签如实显示；M5 位点、`Fractional`、API 显式像；故事 5 用 p(2×2) |
| R13 | 插入分子使最大间隙降到 5 Å 以下时，沿该轴的编辑坐标系与显示同时退回普通包裹（U1 的检测是全局的），Surface 框架与"上方"放置在这之后不可用（D14-5） | 这与显示一致，不另做特殊处理；工具就地说明 `No vacuum gap found …`（U1）；会话进行中的法向在会话内冻结 |

（v1 的 R5"每步撤销快照全部结构"已被 F0-A A-D3 解决——按条目二进制快照，拖动一步 156 字节——删除，E24。）

### 8.2 需要用户决定的问题（均已按推荐方案设计，U6）

- **Q1 移动工具是否默认跳过固定原子？** 推荐：不跳过，提示"含 N 个固定原子"（与 MS 一致，约束只作用于计算；两份审查同意）。约束不再决定移动哪一侧（K2）。
- **Q2 Ctrl V 粘贴到同一结构时的位置？** 推荐：与原原子重合时自动偏移一个 1×1 表面格矢（没有网格信息时至少 3 Å），API 确定性（与视图无关）。备选按 MS 原位粘贴：会产生完全重合的重复原子。
- **Q3 双击是否改为"选分子"？**（新）推荐：是，对 Select 工具与 Move 工具都改——吸附物与分子选中化学意义上的分子（不含表面原子），基底原子保持现有"沿画出的键"行为。
  备选只在 Move 工具里改：Select 工具的行为不变，但双击 CO 再按 G 会带上表面 Pt（D1/E5 的问题仍在）。
- **Q4 放到表面上的粘贴/插入是否默认重置约束与 tags、写 `adsorbate_id`？**（新）推荐：是（`Keep constraints and tags` 可保留）。备选保留源值：从固定层复制的原子导出后不弛豫且无提示（D7）。
- **Q5 "上方"放置的默认高度？**（新）推荐：按共价半径之和的键长求高度（§3.9.3）。备选固定 2.0 Å（v1）：空位上偏差 0.5–0.7 Å。
- **Q6 核心 API 默认语义与多帧**：维持 v1 的推荐（K1、K7；两份审查同意）。

### M1（晶胞与晶格工具）

- `gauss_reduce_2d(a, b)`、`niggli_reduce(cell)`：§3.2.2 的最小像在枚举范围过大时先约化（只影响速度，不影响结果）。

### M2（切面与 slab）

- M4 不再需要 `surface_top`（v1 的请求撤回：全局最高点在台阶面、共吸附与 CONTCAR 上都会出错，D4/E10）；表面法向一律用 F0-A `surfaceNormal`。
- **切口约定不一致（交叉检查项）**：M2 §3.14 的展开 `f ← f − floor(f − f_mid)` 落在 [f_mid, f_mid + 1)，F0-A 显示与 M4 编辑坐标系落在 [cut, cut + 1)（cut = centre − 1 当 centre > 0.5）。
  两者相差一个周期的整数选择，M2 内部无碍，但 `slab_extent` 的高度不能与显示/编辑坐标系的高度混用；建议 M2 改用 F0-A 的切口。
- `info.surface.normal` 由 M2 写入；M4 只在 `rotate_cell=True` 时旋转它、不带晶胞旋转全部原子时删除它（§3.7.6）。

### M3（层、几何选择与约束）

- 化学键判据与共用的成键邻居函数（M3 T3）：M4 的 `bond_graph` 直接用它（§3.4）；若 M3 不导出，M4 T2 提供 `bond_graph`，M3 复用，保证全仓库一份判据。
- `find_adsorbates(structure)`：M4 的基底掩码（§3.5.1）以它为第一来源；`surface_atoms(structure, side)`：移动工具的内置吸附目标（应该）。
- （建议）导入的 slab 没有 tags 时，M3 的 Layers 分区提供一次性的 `Assign layer tags`（用 `find_layers` 写 tags），让基底识别从 `geometry` 变为更稳的 `tags`（D 缺失项 1）。
  不能在导入时自动做（U1 要求导入不改数据）。

### M5（吸附物）——M4 提供与请求

  移动工具与 `place` 工具在 12 px 内吸附到这些点（E26）。
- 接受 M5 §10 的请求：合并/粘贴带 `adsorbate_id > 0` 的完整吸附物时按"目标最大 id + 原 id"重编号并复制、改写 `info.surface.adsorbates` 记录；只粘贴一部分时 id 置 0（非表面放置时，§3.10.5）。
- 请求 M5：(1) `adsorbate_id > 0` 但没有记录的原子组（M4 的表面放置、标记）在吸附物列表中按 `custom` 显示（名称 = 化学式）；(2) M5 第一次给结构写 `adsorbate_id` 时，
  同样先 promote M3 已识别的吸附物（§3.10.5 的理由）；(3) 复制来的记录 `site = null`、`bonds = []`，M5 的列表与重算逻辑接受这种记录。
