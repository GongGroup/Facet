## 0. 关键决定一览

1. **输入是项目里已有的两块 slab 或二维材料**（M6 不切面）。每块先在**私有副本**上"准备"（§3.2）：按 M1 `vacuum_axis` 的规则（唯一的非周期轴）或 F0-D `find_surface_gap` 找真空轴，
   循环轮换使其成为 c，用 F0-D `unwrap_along_gap` 展开，M1 `standard_frame` 转到标准取向（a ∥ x、a × b ∥ +z），c 改为垂直（约束经 F0-D `apply_basis_change`），
   默认用 M1 `primitive_cell(axes=(0, 1))` 约化到最小面内网格（身份属性 = M1 默认 + `interface_layer`），可选上下翻转（绕 x 轴 C2，真转动）。
   输入结构从不被修改（U1）。**匹配在"匹配网格"（准备后的网格）上做；名字、Wood 记号、错位单位用"参考网格"（表面的 1×1 网格）**（领域 #7）。
2. **匹配算法是 Zur–McGill（ZSL）的重写版**：按面积由小到大枚举两套 2D HNF 子格，比较约化基；相对 pymatgen 的 6 处有意改动见 §3.4。
   v2 修正：`max_area` 只限**基底**超胞面积（两个引擎同一定义）；格子转动阶数用一条宽容差、不抛错的规则；归类按 (m, n) 分块、用全序选代表，
   结果与遍历顺序无关；排序与 Pareto 的应变比较带 1e-5 的绝对容差 [R]。
3. **扭转角是匹配的输出**；给定目标扭转角时自动改用"重合矢量"引擎（§3.5）。v2：长度上界在 `max_aspect=None` 时也正确，扇形环带的包围盒精确，
   矢量对数在枚举中计数、超限立即停止，并先用先验估计 K̂ 拒绝过大的搜索。原型中两个引擎在全部 7 组对比上结果逐项相同（含 v1 失败的两个反例）[R]。
4. **应变分配**：`overlayer`（默认）/`substrate`/`both`（V^w 分摊）。列表与搜索判据是"全给覆盖层"口径的**失配**（mismatch）；选中行与来源信息给出所选分配下每层的**实际应变**。
5. **层间距默认 = vdW 接触规则**（§3.9）：取使两层之间每对原子距离 ≥ 接触半径之和的最小垂直间隙（闭式解）。半径：F0-D 的 `bondi_radius`（Bondi + Mantina），
   没有值的 d/f 区金属用 1.65 Å；**离子型层中的金属原子用 Shannon 阳离子半径**。`covalent` 用同一规则配 Cordero 共价半径（化学吸附、外延）；
   另有 `bulk`（应该）与数值。结果报告控制间距的原子对。原型：graphene/Ir(111) 3.35 Å（XSW 实测 3.38），氧化物与 NaCl 都由顶层阴离子控制，
   外延 Pt/Pt(111) 空位 2.20 Å（体相 2.263）[R]。
6. **结果是新结构**（P4）：**`pbc = [T, T, T]`**（U2）[U]，a ∥ x，c ∥ z（C5），**真空必填、无默认值**（U4）[U]，指叠层顶到下一个周期像底的总间隙，允许 0；
   真空很小时就是有两个界面的超晶格（不再有 `periodic` 参数），界面上"Use interlayer distance"按钮可把第二界面的接触间距填进真空框。基底原子在前、覆盖层在后；
   新逐原子属性 `props.interface_layer`；约束原样带入；基底保留 `tags`、覆盖层 `tags` 置 0；`adsorbate_id` 重新编号并合并吸附物记录；
   来源写入 **`info.surface.interface`**（C6，`info.surface.kind = "interface"`）；命名如 `MoS2 p(4×4)/Au(111) (√19×√19)R23.4°`。
7. **界面在 Surface 面板的 Interface 分区**（F0-A v2：`registerPanelSection('surface', {id: 'interface', order: 50})`），预览用 F0-A 的 P-swap 会话，
   Create 后作为新结构加入项目；命令 `build.layers`（"Build layers…"，MS 名 Build Layers）。搜索在主线程分片运行，进度只显示在分区状态行，**不占用全局忙碌状态**。
8. **服务器**：`/analysis/interface`（云模式需登录）与 `/build/interface`（云模式下只有给出两个矩阵、不需要搜索时才对匿名开放）；服务器有自己的工作量上限（§6.3）。
9. **跨语言等价**：v1 的规则已在 10 个场景上两语言逐项相同 [R，v1]；v2 新增的规则在 Python 原型上验证，其中唯一新增的浮点判定 `lattice_rotations` 已在 180 个网格上
   两语言逐项相同 [R]。v2 的全部离散判定只用加减乘除与开方，或与远大于舍入误差的容差比较（§3.12）。T2/T3 必须重跑完整的两语言比对。
10. **本模块必做、不可砍**（U3）[U]：§2 的"必须"项（含 REST、客户端、CLI）全部交付；进度紧张时只推迟"可选"，其次"应该"。

### 1.2 与 Materials Studio Build Layers 对照

MS 的事实来自 06 报告 §10（T17 pp.278, 287-288；部分为搜索摘要 [SN]，Matching 页的完整选项未能核实）。

| 方面 | Materials Studio（Build ▸ Build Layers） | Crystallume M6 | 理由 |
|---|---|---|---|
| 入口 | Build 菜单，模态对话框，四个选项卡（Define Layers、Layer Details、Matching、Options） | Surface 面板 ▸ Interface 分区（非模态，边改边预览）；命令 `build.layers`，标题 "Build layers…"，别名 "Build Layers"、"Build interface"、"Heterostructure" | 简报 §4：表面工具不用模态框，需要实时预览 |
| 层数 | 最多 3 层（Layer1..3），可重复构建 [SN] | 每次 2 层（基底 + 覆盖层），结果可再作基底（"Stack another layer…"）；三明治为可选功能 | 三方同时匹配是三个格子的公度问题；逐次叠加覆盖了 MS 的用法 |
| 输入 | 晶体、slab 或无定形盒子；教程里先把 2D 表面用 0 Å 真空转成 3D 再叠 | 项目里的 slab 或二维材料（有一根真空轴，另两轴周期）；体相、线、盒中分子都说明原因后禁用 | 本期不做无定形与溶剂层（简报 §0）；体相直接叠会把周期性边界当界面 |
| 晶格匹配 | 手动："select the lattice parameters for Layer 1"，其余层被拉伸；论坛经验"失配 < 5%" | 自动 ZSL 搜索所有超胞对和取向，按原子数与应变排序；另有 Manual（两个矩阵）与 "Keep the input cell"（等价于 MS 的"用 Layer 1 的晶格"） | MS 没有自动重合格点搜索（06 报告 §10 [I]） |
| 应变分配 | 选哪一层的晶格，其余层承担全部应变 | overlayer / substrate / both（权重可调）；报告每层的实际应变张量 | 薄膜与基底刚度不同时需要分摊；MS 不报告应变 |
| 错位 | 每层"origin offset (u, v)" [SN] | 覆盖层相对基底的面内位移 (u, v)，单位是基底**1×1 参考网格**的分数；top/bridge/fcc/hcp 预设（必须），M5 位点菜单（应该） | 与 MS 一致，并用位点名省去手算 |
| 扭转 | 无 | 匹配输出扭转角；可给目标角与容差 | 转角材料需要 |
| 翻转 | "Flip" 选项 [SN] | Flip overlayer / Flip substrate（绕 a 轴 180° 真转动，不用镜像） | pymatgen 用 z → −z 翻转（镜像），会改变手性（§3.2） |
| 层间距 | 未查到默认值；用户报告层间有多余空隙（06 报告 §2.4） | 默认 vdW 接触规则（完整半径表、离子型层用阳离子半径）；共价接触；显示控制间距的原子对与最近接触 | 可解释、可复现、两语言相同 |
| 真空 | 每层可设 Vacuum（"Increase the Vacuum for Layer 2 to 30.0"） | 叠层顶到下一个周期像的总间隙，**必填、无默认**（U4），允许 0；小真空即超晶格 | U4；与 M2 的真空语义统一 |
| 周期性 | 3D 周期文档 | `pbc = [T, T, T]`（U2） | 与 VASP、MS 一致 |
| 输出 | 新文档 `Layer.xsd`，无来源信息 | 新结构，名字可读，`info.surface.interface` 记录全部参数与应变，`props.interface_layer` 标记每个原子属于哪层 | 可追溯、可脚本化 |
| 约束 | 文档里的约束随原子走 | Selective dynamics 原样带入；固定原子落在界面上、固定层被施加应变时给出提示 | 与 C3 一致；防止常见失误 |

## 2. 功能清单

### 2.1 必须（第一个可交付版本；U3：全部交付）

| ID | 功能 | 行为与默认值 |
|---|---|---|
| M6-F1 | **层输入与准备** | 选择基底（Layer 1，底）和覆盖层（Layer 2，顶），可以是同一个结构（扭转双层）。准备（§3.2）：只用当前帧；找真空轴（有且只有一根真空轴、另两轴周期）；在私有副本上做标准取向、展开、c 垂直化；默认约化到最小面内网格（`primitive=True`）；`flip=False`。每层显示网格（a、b、γ、每胞原子数、是否已约化与约化前的胞，例如 "reduced from 3×3 (36 → 4 atoms)"）。 |

## 3. 算法

### 3.1 记号与约定

- 行矢量（C1）：2D 网格写成两行 `[u; v]`（Å，xy 平面内）；整数矩阵 M 的行是新基矢在旧基下的坐标，超格基 = `M @ [u; v]`。
- **F 用列矢量写法**：F 把覆盖层的矢量映到基底的矢量，`F o_i = s_i`，即 `F = [s1 s2][o1 o2]⁻¹`（列拼接）。极分解 `F = R U = V R`，R 是转动（扭转角 θ），U、V 对称正定。
- 应变正号 = 拉伸。扭转角正号 = 从 +z（真空侧）往下看逆时针转动覆盖层。
- 准备好的层的网格总是**右手**（a × b 沿 +z）；所有匹配都要求两个超格基同为正定向，因此 det F > 0（只有真转动）。
- **匹配网格**：准备后（约化、翻转之后）的面内网格，搜索与构建都在它上面做；它尊重原子的身份属性，带吸附物或带个别固定原子的 slab 的匹配网格就是输入胞。
- **参考网格**：表面的 1×1 网格（§3.2.2），只用于 Wood 记号、`index2d`、名字和错位单位；它不看 props 和吸附物。匹配网格 = `P @ 参考网格`（P 为整数矩阵）。
- `Mesh2D`：一层的匹配网格：约化基 (u, v)（§3.3(a)）、整数变换 T（约化基 = `T @` 网格基）、面积、每胞原子数、转动阶数 k ∈ {2, 4, 6} 与整数转动矩阵（§3.3(e)）。
  搜索得到的矩阵都相对约化基；相对参考网格的矩阵 `M_ref = M @ T @ P`；相对输入胞的矩阵 `M_in = M @ T @ K⁻¹`（K 见 §3.2）。

### 3.2 层的准备（`prepare_layer`）

#### 3.2.1 步骤

```
prepare_layer(structure, *, flip=False, primitive=True, frame=None) -> PreparedLayer
  s ← 指定帧的深拷贝（Python frame 默认 0；JS 默认 structure.frame）；n_frames > 1 → 警告 W1。输入结构从不修改（U1）
  1. 真空轴（U1：只看几何，不做 slab 分类；工程 #16）
     s.cell 为空                       → E1
     nper ← [k : pbc[k] 为假]
     len(nper) ≥ 2                     → E3
     len(nper) == 1                    → k ← nper[0]；gap ← None          # 二维原型（graphene、mos2、hbn：pbc T T F）：非周期轴不展开，直接用原子坐标
     否则（T T T）：
       gs ← F0-D find_vacuum_gaps(s)；wide ← {j : gs[j] 非空且 gs[j].width ≥ vacuum_gap_min − 1e-5}
       len(wide) ≥ 2                   → E4（线或盒中分子）
       g ← F0-D find_surface_gap(s)    # ≥ 5 Å 的最宽间隙；没有时退回 info.surface.axis 上最宽的间隙（小真空的叠层、超晶格）
       g 为空                          → E2（附 F0-D vacuum_gap_hint 的实测值）
       k ← g.axis；gap ← g
  2. 轮换：k ≠ 2 → 晶格矢量、pbc、selective_dynamics 的三个标志按 perm = [(k+1)%3, (k+2)%3, k] 循环轮换（det +1；与 M1 reorient 同一规则，精确）
     左手晶胞（det < 0）→ b ← −b（基变换，apply_basis_change，精确），使 +c 一侧成为 a × b 方向：**顶面 = +c 一侧**，与 F0-A `surfaceNormal`、M5 `surface_frame` 的定义相同
  3. 展开：gap 非空 → f_c ← F0-D unwrap_along_gap(f_c, gap)（按整数个 c 平移，只在副本上）
  4. 标准取向：R ← M1 standard_frame(cell, "a-x")；位置与晶胞右乘 Rᵀ（真转动）。此后 a ∥ +x，a × b ∥ +z
  5. c 垂直化：t ← z_max − z_min；c′ ← (t + 2·PREP_PAD)·ẑ（PREP_PAD = 10 Å）；z ← z − z_min + PREP_PAD
     约束：F0-D apply_basis_change(s, old_cell, new_cell)（倾斜 c 上的 [F,F,T] 收紧并写备注，领域 #23；[T,T,F]、全 T、全 F 精确）
     pbc ← [T, T, T]（U2）。层位于副本晶胞中部，所有 f_c ∈ (0, 1) 且远离 0 与 1，M1 的包裹不会沿 c 移动原子（工程 #1）
  6. 约化（primitive）：
     r ← M1 primitive_cell(s, axes=(0, 1), props = M1 translation_identity_props + ["interface_layer"])
         # 与 M1 默认相同（occupancy、磁矩、charges、labels、tags、selective_dynamics），只追加 interface_layer；
         # 不含 adsorbate_id（M1 有意排除：它是编号，参与会挡住 c(2×2)-O 这类满覆盖吸附层的约化，领域 #8）
     r 无变化 → K ← I；否则 s ← r.structure，K ← r.matrix 的面内 2×2（整数，det = 约化掉的倍数；"输入胞 = K @ 原胞"，M1 v1 的方向）
     位移检查（领域 #8）：q ← M1 make_supercell(s, embed(K))；与步骤 5 的副本按身份键逐原子配对（最小像，网格哈希）；
         最大位移 δ > interface_reduce_warn（0.01 Å）→ 警告 W6（M1 取代表原子的原坐标、不取平均，弛豫过的坐标会被换掉）
     参考网格与 P（§3.2.2）在这里求（约化之后、翻转之前）
  7. 翻转（flip）：绕 x 轴 C2：(x, y, z) → (x, −y, −z)（真转动）；晶胞同样转动后取基 (a, −b′, −c′)
     （diag(1, −1, −1) 的基变换，apply_basis_change，精确；保持 a ∥ +x、c ∥ +z、右手）；z ← z − z_min + PREP_PAD；
     interface_layer 存在时自下而上的编号随之反转：v ← max + 1 − v
     面内基换成 (a, −b′) 后，矩阵同步：K ← K·D，P ← D·P·D（D = diag(1, −1)；参考网格同样取 (a, −b′)）
  8. mesh ← Mesh2D(cell 前两行的 xy 分量, natoms = len(s))
  9. 锚原子候选（§3.8.3）、源映射（副本原子 → 输入原子，经 remap 链得到）
  返回 PreparedLayer{structure: s, mesh, inputMatrix: K, refMesh, refMatrix: P, flipped, rotation: R, axisPerm, sourceMap, warnings}
```

- **翻转为什么不能用镜像**：pymatgen `Interface.from_slabs` 用 `film_coords[:, 2] *= -1.0`（`src-pmgcore/pymatgen/core/interface.py:2838` [V，工程审查复核]），
  这是 z → −z 镜像，会把手性结构变成对映体。C2 转动不改变手性。
- **翻转改变网格**：斜方网格翻转后（从 +z 看）是原网格的镜像，与原网格不能经转动重合（只有 |a| = |b| 或 γ = 90° 时可以，附录 B）。所以**匹配必须在翻转之后的网格上做**；
  界面上切换 Flip 会重新搜索。v1 原型最初用翻转前的网格匹配，石墨烯 C–C 由 1.420 Å 变成 0.818 Å，修正后 1.416 Å [R]。
- 原型验证：CONTCAR 式输入（pbc T T T，底层在 z = 0、一个原子被包裹到 0.9999999）和斜 c 输入都得到相同的连续 z 序列 [R，`proto/m6/build_checks.py`]。
- 为什么要尊重 props：个别原子固定、带不同 tag 或带磁矩的 slab 不能被约化到比这些标记的周期更小的胞，否则约束、AFM 序会被改写（M1 的测试"AFM ++−− → 4、+− → 2"）。
  每层原子标记相同（例如 p(3×3) 4 层、底 2 层固定）时约化成 1×1 是正确的，标记随原子保留；**真正需要保留用户晶胞时用 Keep the input cell**（§3.7）。

#### 3.2.2 参考网格

```
reference_mesh(s5, info):          # s5 = 步骤 5 之后、约化之前的副本；info = 输入结构的 info
  1. info.surface.kind == "cleave"（M2 切面得到）：
       S0 ← info.supercellMatrix 的面内 2×2（M1 维护后续超胞的组合）；没有时用 info.surface.supercell；再没有时 I
       S0 是 det > 0 的整数矩阵 → ref ← inv(S0) @ (s5 的 a、b)                       # 输入胞的 1×1 网格
  2. 否则（导入的 slab、二维材料、M2 kind = "vacuum"、界面结果）：
       info.surface.interface 存在 → ref ← 该叠层记录的参考网格经 info.supercellMatrix 换算（叠层自己的 1×1 不存在，见下）
       否则 q ← M1 primitive_cell(去掉吸附物原子的 s5, axes=(0, 1), props=[])（只看元素；吸附物 = adsorbate_id > 0，没有该键时用 M3 find_adsorbates）；ref ← q 的面内基
  P ← 匹配网格基（约化前，步骤 6 的结果）在 ref 中的坐标；|P − round(P)| ≤ 1e-6 → P ← round(P)；否则 ref ← 匹配网格、P ← I、备注 W7
```

- 例：干净 Pt(111) p(3×3) 4L（M2 切面）：参考网格 = 1×1（a = 2.772 Å），匹配网格 = 1×1（约化），P = I；带 CO 的 p(6×6)：匹配网格 = 6×6（CO 挡住约化），P = 6·I，
  所以匹配矩阵 I 的 Wood 记号是 `p(6×6)` 而不是 v1 的 `(1×1)`（领域 #7）；c(2×2)-O/Cu(100)：O 不参与参考网格，参考网格 = 1×1 Cu(100)，匹配网格 = c(2×2)。
- 叠层作基底（逐次叠层）：叠层的 Wood 记号相对它**最底层**的参考网格（记录在 `info.surface.interface.layers[0]`），名字只用叠层标签（§4.4）。
- 参考网格不影响匹配结果，只影响显示与错位单位；求不出时退回匹配网格，不报错。

### 3.3 2D 原语（两种语言各一份，算术顺序写死）

**(a) 最短基约化 `reduce_basis_shortest(u, v)`（M6 私有，`latticematch` 模块内；不与 M1 的 `gauss_reduce_2d` 共用）**

```
reduce_basis_shortest(u, v):      # 返回 (u', v', T)，[u'; v'] = T @ [u; v]，det T = +1，|u'| ≤ |v'|，|u'·v'| ≤ |u'|²/2
  T = I
  循环（上限 10000 次，否则抛内部错误）:
    if |v|² < |u|² · (1 − SWAP_REL):  (u, v) ← (v, −u);  T ← [T₁; −T₀]      # 交换用 (v, −u)，det 保持 +1
    else:
      k = round_ties_to_zero(u·v / |u|²)
      if k == 0: return
      v ← v − k u;  T₁ ← T₁ − k T₀
round_ties_to_zero(x) = 0 if x == 0 else trunc(x + sign(x)·(0.5 − TIE_EPS))   # |小数部分| ≤ 0.5 + 1e-9 时朝 0 取整
```

- 平局规则必须写死：Python `round(0.5) = 0`（银行家舍入）而 JS `Math.round(0.5) = 1`（07 报告 §2.4）。
- **不用 M1 的函数**（工程 #4）：M1 v1 的 `gauss_reduce_2d(a, b, angle="obtuse")` 在锐角输入上做 (u, v) ← (v, −u) 的钝角约定，结果可能 |u| > |v|；
  引擎靠"λ1 = |u| 是逐次极小值"做预筛和二分，换成 M1 的版本会静默改变匹配表：graphene/Ni(111) 549 → 562 类（丢 17、多 30），斜方/石墨烯丢 26 类 [V，审查原型 `m1_gauss_swap.py` 复跑]。
  两个函数用途不同、名字不同；M1/M5/M6 三种平局规则的统一交 M7 记录。

**(b) 环带内格矢枚举**（同 v1）：给定约化基 (u, v)，列出所有 `r_min ≤ |i u + j v| ≤ r_max` 的整数 (i, j)。行距 `h = |u × v| / |u|`，
`|j| ≤ floor(r_max/h + 1e-12)`；对每个 j 解二次不等式得 i 的区间（端点各放 1e-9），再逐个检查 `r²` 是否在 `[r_min²(1−1e-12), r_max²(1+1e-12)]`。
排序比较器：长度差大于 `1e-9·max` 时按长度，否则按 j，再按 i。

**(c) HNF**：指数 n 的全部子格 `[[i, j], [0, n/i]]`，i | n，0 ≤ j < n/i，共 σ(n) 个；用 M1 `intmath` 的 `hnf_matrices_2d(n)`（M1 审查已要求写死 (i, j) 升序；§3.6 的归类与顺序无关，
所以 M6 不依赖这个顺序 [R]）。规范形 `hnf_2d(M) → (a, b, c)`（行运算化成 `[[a, b], [0, c]]`，a, c > 0，0 ≤ b < c；扩展 gcd 用 floor 语义）由 M6 在 `latticematch` 内实现
（M1 没有提供）。规范形是判断"同一子格"的唯一键。

**(d) 极分解、伸长与对称矩阵幂（无三角函数）**

```
stretches(F):   C = FᵀF = [[p, q], [q, r]];  m = (p+r)/2;  d = sqrt(((p−r)/2)² + q²)
                return (sqrt(m − d), sqrt(m + d))                         # 主伸长 λ1 ≤ λ2
sqrt_spd(S):    s = sqrt(det S);  t = sqrt(tr S + 2s);  return (S + s I) / t
polar(F):       U = sqrt_spd(FᵀF);  R = F U⁻¹;  V = F Rᵀ（再对称化）;  θ = atan2(R₁₀, R₀₀)（度，只用于显示与扭转窗口）
sym_pow(S, p):  m = (s11+s22)/2;  d = sqrt(((s11−s22)/2)² + s12²);  λ1 = m − d;  λ2 = m + d
                d ≤ 1e-12·λ2 → λ2^p · I                                   # 各向同性分支（工程 #25）
                否则 P2 = (S − λ1 I)/(λ2 − λ1);  P1 = I − P2;  return λ1^p P1 + λ2^p P2
```

`stretches` 只用加减乘除与 `sqrt`（两种语言都正确舍入），所以应变判据与排序键在 Python 和 JS 中逐位相同（v1 原型实测差为 0.0）[R]。
`sym_pow` 的 `pow` 可能差 1 ulp，只用于构建坐标（§3.12 第 2 条）。Python 不得改用 `np.linalg.eigh`，两种语言用同一闭式。

**(e) 格子转动 `lattice_rotations(u, v) → (k, [(angle, G)])`（v2：一条规则，领域 #9、工程 #11）**

```
lattice_rotations(u, v):            # (u, v) 为约化基；G 为整数，[u; v] 转动后 = G @ [u; v]
  lu, lv = |u|, |v|;  k = 2
  if |lu − lv| ≤ MESH_LEN_TOL · max(lu, lv):                   # 1e-3，与 M1 mesh_length_tolerance 相同
      c = u·v / (lu·lv)
      if |c| ≤ COS90_TOL: k = 4                                  # sin(0.1°) = 1.7453283658983088e-3
      elif ||c| − 0.5| ≤ COS60_TOL: k = 6                         # 1.5106e-3 ≈ 0.1° × sin 60°（与 M1 mesh_angle_tolerance 0.1° 相当）
  k == 2 → 返回 [(0, I), (180, −I)]
  转角 t·360/k 的 (cos, sin) 用精确常数：k = 4 → (1,0),(0,1),(−1,0),(0,−1)；k = 6 → (±1, 0)、(±0.5, ±sqrt(3)/2)
  对每个 t：G = ([u; v] g_tᵀ) [u; v]⁻¹（只用加减乘除）；Gi = round(G)
      max|G − Gi| > ROT_INT_TOL（1e-2）或 det Gi ≠ 1 → 返回 k = 2 的结果（不抛错）
  返回 (k, [(t·360/k, Gi)])
```

- 判定只用加减乘除与开方，两种语言逐位相同：`rot_v2.mjs` 与 Python 在 180 个网格（六方/正方/矩形/斜方 × 精确、3–6 位小数、2e-4–5e-3 畸变、随机转动）上 **0 处不同** [R]。
  G 离整数 ≤ 1e-2 才接受，取整方式（半数）无关。
- **为什么用宽容差**：手写或其他程序导出的 POSCAR 常只有 3–6 位小数。v1 的严格判据（1e-6、1e-4°）在 5 位小数时让原型 `RuntimeError`，
  4 位小数时降为 k = 2 后类数膨胀到 4475、第一行变成 θ = 60° 的 1×1 [领域审查实测]。v2 规则下 graphene/Ni(111) 在 3–6 位小数、2e-4 与 1e-3 畸变时都保持 k = 6、
  第一行仍是 θ ≈ 0 的 1×1；5e-3 畸变（真实的各向异性应变）才降为 k = 2 [R，`order_noise.out`]。
- 变体的 F 一律由整数矩阵重算，所以宽容差只影响"哪些匹配归为一类"，不影响任何一个匹配的数值；近似对称的网格上，同类变体的应变可以相差 ~1e-3，各自报告。

### 3.4 ZSL 引擎（任意扭转）

与 pymatgen `ZSLGenerator`（`src-pmg/pymatgen/analysis/interfaces/zsl.py`，MIT [V]）相比的有意改动（同 v1，审查复核"推导都正确"）：

| # | pymatgen | M6 | 原因 |
|---|---|---|---|
| 1 | 比较两个约化基的长度和**无符号**夹角（`vec_angle` 用 `arctan2(‖a×b‖, a·b)`），可能 det < 0 | 只接受 det F > 0 的对应 | 无符号比较会把镜像格当成匹配，构建时得到镜像结构 |
| 2 | 每对子格只比较一个约化基 | 枚举覆盖层子格中长度落在窗口内的**所有**基 (p, q) | 近平局时约化基选择不稳定会漏匹配；而且这样能得到所有取向 |
| 3 | 面积比容差后逐对比较 σ(m)·σ(n) | 先用逐次极小值 λ1、λ2 做精确必要条件筛选（按 λ1 排序后二分） | F 的奇异值在 [1−e, 1+e] 时，两套子格的逐次极小值之比也在此区间内；比较次数降为 1/10 [R] |
| 4 | 同一界面的更大超胞也会列出 | 去掉"派生匹配"（F 与更小面积的已登记 F 相同） | 派生匹配只是较小匹配的超胞，用户可用 M1 再扩胞 |
| 5 | 不归并 | 由两套网格转动联系的匹配归为一类，代表 + 变体 | 否则六方/六方每个匹配重复 6 次以上 |
| 6 | 长度 3% 与夹角 1% 两个判据 | 主伸长 max\|λi − 1\| ≤ e | 物理意义明确、一个旋钮、只需开方；pymatgen 判据作为可选（M6-C7） |

```

          if max(|λa−1|, |λb−1|) > e + 1e-12: continue

    块 (m, n) 结束 → 交给 §3.6 的分块后处理（JS 生成器在此处与内层循环中让出主线程，§3.13.2）
```

- 与 v1 的差别：(1) n 的上限按基底面积换算（v1 是 `max_area/A_o`，等于同时限制了覆盖层面积，与重合矢量引擎不一致）；(2) 引擎内只做"派生"去重，
  **同一块内的同类变体不再在发现时丢弃**——发现顺序决定代表的问题由 §3.6 的分块全序消除（工程 #8）。
- 对类数的影响 [R]：默认参数下 graphene/Ni(111) 549 → 561 类、graphene/Pt(111) 476 → 500、MoS2/Au(111) 144 → 148、hBN/graphene 198 → 202；Pareto 集合不变（§3.15）。
- 复杂度：子格总数 Σσ(k) ≈ 0.82 k_max²；成对比较经 λ1 二分后约为 σ(m)·σ(n) 的 5–10%。

### 3.5 重合矢量引擎（有扭转目标时）

ZSL 要枚举到最大面积的全部子格，对小扭转角（大胞）不可行：魔角 1.05° 需要 m = 2977。给定目标 θ0 时改为直接找重合矢量。

#### 3.5.1 长度上界与枚举

```
twist_raw(Ms, Mo, θ0, Δθ, e, max_area, max_atoms, max_aspect):
  λs = |Ms.u|（基底最短格矢）
  L = 2·max_area / (√3·λs)                                          # 约化超格长矢量的上界：|v| ≤ 面积/(|u| sin γ) ≤ 2A/(√3 λs)
  max_aspect 非空 → L = min(L, sqrt(2·max_aspect·max_area/√3))      # |v|² ≤ α|u||v| ≤ 2αA/√3
  （v1 在 max_aspect = None 时仍按 4 截断，两引擎因此不等价，工程 #7）
  e_deg = degrees(asin(min(1, e)))                                   # 拉伸 e 能带来的最大方向偏转
  windows = [θ0] if |θ0| < 1e-12 else [θ0, −θ0]

  A_list = 基底格中 0 < |A| ≤ L 且极角 ∈ [0°, 180°) 的矢量，按长度排序

    扇形环带 {r ∈ [|A|/s_hi, |A|/s_lo], 角 ∈ [angle(A) − c − Δθ − e_deg, angle(A) − c + Δθ + e_deg]} 在覆盖层分数坐标中的**精确**包围盒：
      候选角 = 两个端角 + 对每个分数分量 f_k（线性函数）使其在圆弧上取极值的角 φ_k、φ_k + 180°（落在角区间内时）；候选点 = 候选角 × 两个半径（工程 #30）
    包围盒内（各向外扩 1 个分数单位）逐点：|B| 在环带内、方向差 ≤ Δθ + e_deg + 1e-9 → 记录矢量对 (A 的整数坐标, A, |A|, B 的整数坐标, B, θ_AB)
```

### 3.6 后处理：分块归类、规范变体、代表、Pareto、排序

#### 3.6.1 分块归类（与遍历顺序无关，工程 #8）

```
postprocess(raw):                                     # raw 来自任一引擎
  按 (m, n) 分块，块按 (m, n) 升序处理；registry = 已登记的 F（分桶 floor(F00·1000)、floor(F11·1000)，查 3×3 邻桶，元素差 < 1e-9 判同）

    2. 其余按 F 分组；每组选一个候选：cmp_same_F = (aspect 小者，差 > 1e-9；再按规范 HNF 对 (hnf_2d(M_s), hnf_2d(M_o)) 的字典序)
       （aspect = 约化后基底超格的 |v|/|u|；它和规范 HNF 都与基无关，所以选择前不需要规范化）
    3. 各组选出的候选按 cmp_rep 全序排序后依次处理：
         F 已在 registry 中（本块中已建类的变体）→ 跳过

         否则建类：代表 = vs 中按 cmp_rep 最小者；变体 = vs

   1. tdist（无 θ0 时 |θ|，有 θ0 时 min(|θ − θ0|, |θ + θ0|)），差 > 1e-6° 才分先后
   2. θ ≥ −1e-6 者优先
   3. 规范 HNF 对的字典序
   4. 最大应变，差 > 1e-9
   5. F 的四个元素依次比较，差 > 1e-12
```

- 为什么与顺序无关：raw 的集合只由参数决定；分组、组内选择、组间排序都用与基无关的全序；跨块的唯一状态是 registry，它只取决于更小的块。
  同一 F 在同一块中有多个候选，正是"最小重合胞因 `max_aspect` 被滤掉、它的几个指数加倍的超胞互不为派生"的情形（审查的 MoS2/Au 宽窗口例，长宽比 5.02）。
- 原型 [R，`run_v2.py order`]：把 HNF 枚举顺序、基底子格循环、覆盖层区段循环和环带枚举全部反过来，graphene/Ni(111)（561 类、700 Å² 的 5349 类）、
  MoS2/Au(111) e = 0.5% 1500 Å²（162 类）与 15° ± 15° 1200 Å² 重合矢量引擎（96 类）上的**代表与变体矩阵逐项相同**。
- 因此 Python 端对 (m, n) 块做 numpy 向量化（§3.13）不会改变结果——这正是审查担心的 P1 风险。

#### 3.6.2 规范变体

```
canonical_variant(M_s, F):
  H = hnf_2d(M_s) 写成 [[a, b], [0, c]]
  (u, v, T) = reduce_basis_shortest(H @ 约化基_s);  M_c = T @ H
  (k′, rots) = lattice_rotations(u, v)                         # 超格自身的转动，同一规则（§3.3(e)）
  k′ == 6 且 u·v > 0 → M_c₁ ← M_c₁ − M_c₀（改用 120° 约定）；重新求 rots
  候选基 = {G @ M_c : (angle, G) ∈ rots}；取第一个矢量极角 mod 360（> 360 − 1e-9 记为 0）最小者（差 > 1e-9° 才算更小）
                                                               # 结果胞的 a 与基底 a 轴夹角最小
  覆盖层行：对 M_c @ 约化基_s 的每一行 s：g = F⁻¹ s，f = g 在覆盖层约化基下的分数坐标；|f − round(f)| ≤ 1e-6，M_o 行 = round(f)
  返回 make_raw(M_c, M_o)（重新计算 F、伸长、θ、面积、原子数、长宽比）
variants(r) = { canonical_variant(r.M_s @ G, F(r.M_s @ G, r.M_o @ H)) : G ∈ 基底转动, H ∈ 覆盖层转动 }，按（规范 HNF 对, F）去重
```

- 与 v1 的差别：超格自身的转动改用整数矩阵 `G @ M_c`（v1 把浮点转动后的矩阵直接取整、不检验）。
- 变体对应 `F′ = g F h⁻¹`（整个界面绕 z 转 g，再把覆盖层转 h）；面积、主伸长相同（近似对称网格上近似相同），θ 相差 g、h 的转角。
  变体只在"晶格层面"等价：slab 本身没有相应对称时（3 层 fcc(111) 只有 C3v，60° 转动给出孪晶取向；MoS2、hBN 同理）变体是物理上不同的结构，
  所以**变体保留并可选**，默认取代表；M6-S9 标出哪些变体真正等价（§3.6.6）。镜像相关的两类（θ 与 −θ）不合并（只用真转动），列表里成对出现。

#### 3.6.3 有扭转目标时的窗口

类内任一变体满足 `min(circ(θ mod P, θ0 mod P), circ(θ mod P, −θ0 mod P)) ≤ Δθ + 1e-9`（P = 360°/lcm(k_s, k_o)）才保留；代表按 cmp_rep（离 ±θ0 最近）选。

#### 3.6.4 Pareto 与排序

1. **Pareto**（"best trade-offs"）：按（原子数，最大应变）分组；某类为 Pareto 当且仅当其最大应变 < 所有原子数更少的类的最小值 − STRAIN_TIE，
   且 ≤ 同原子数组内最小值 + STRAIN_TIE。**STRAIN_TIE = 1e-5**（v1 是 1e-12）。
2. 排序：`sort = "atoms"`（默认）：原子数 → 最大应变（差 > STRAIN_TIE 才分）→ cmp_rep；`"strain"`：最大应变 → 原子数 → cmp_rep；
   `"twist"`（应该）：tdist（差 > 1e-6°）→ 原子数 → …；`"area"`（应该）：面积 → 应变 → …。
   不在默认里用"离目标最近"：应变容差较大时，面积更大的应变近似胞可能比严格公度胞更接近目标角 [I]。
3. 截取前 `max_results`（默认 200，上限 2000）类；同时返回总数与 Pareto 类数。
4. `key = "m:n:a,b,c:a′,b′,c′"`（代表的规范 HNF 对）；重复时按排序次序追加 `":2"`、`":3"`；界面用它在参数变化后保持选中。

STRAIN_TIE 的依据 [R，`pareto_tol.py`，graphene/Ni(111) 默认参数，两层晶格矢量四舍五入到 n 位小数]：1e-7（领域 #9 的建议）时 5 位与 4 位小数的 Pareto 集合都变了；
1e-6 时 4 位小数仍变；**1e-5 时 4、5、6 位小数的 Pareto 集合与精确输入完全相同**（8 类），类数也都是 561；3 位小数是真实的 ~4e-4 晶格变化，结果不同是合理的。
1e-5 的应变差在物理上没有意义（远小于 DFT 晶格常数的误差）。

#### 3.6.5 原型结果

graphene/Ni(111) 默认搜索：v2 规则下 561 类、Pareto 8 类；ZSL 内部按搜索归并得到的类与按对称生成的变体完全一致（每类 6 个或 18 个变体）[R]。

#### 3.6.6 物理上不同的取向变体（M6-S9，领域 #12）

```
slab_rotation_symmetries(layer):       # 每层算一次，O(k·m·N)
  对该层匹配网格的每个格子转动 (angle, G)：
    把准备后的 slab 绕 z 转 angle（cos/sin 用 §3.3(e) 的精确常数）
    在最稀少的身份键类中取第一个原子 r0；对同类且 z 差 ≤ tol 的每个原子 r_j，候选平移 τ = r_j − R r0（面内）
    用网格哈希核对：每个转动后的原子 + τ 都有同身份键、z 差 ≤ tol、面内最小像距离 < tol 的原子（tol = M1 translation_tolerance，0.05 Å）
    有 τ 成立 → 该转动是 slab 的对称
变体 (g, h) "等价"（与代表差一个面内平移，也就是只差错位）⇔ g ∈ Sym(基底) 且 h ∈ Sym(覆盖层)
```

推导：变体 = 代表整体转 g、基底层换成"转 g 的基底"、覆盖层换成"转 h 的覆盖层"；后两者与原层重合（差平移）当且仅当 g、h 是该层的对称。
例：graphene（6 个格子转动都是它的对称，差一个平移）/Ni(111) 3 层 ABC（只有 3 个）：一类的 6 个变体分成两组，组内等价、组间不等价（60° 使基底的 fcc 与 hcp 空位互换），
界面显示 "Orientation 0.0° · 1 of 2 distinct"；MoS2/Au(111) 两层都只有 3 重对称，同样要区分。

#### 3.6.7 匹配指纹（工程 #9）

每个匹配带 `meshes = {"substrate": [[ux, uy], [vx, vy]], "overlayer": [...], "flip": false, "flipSubstrate": false, "primitive": true}`（两层匹配网格的约化基，6 位小数）。
`make_interface(..., match=<dict>)` 重新准备两层后核对：任一网格矢量差 > 1e-6 Å，或用其矩阵重算的 `mismatch.max` 与记录差 > 1e-9 →
`ValueError("this match was computed for other layers or options; search again")`。典型误用：搜索后改了 Flip、在 M3 里固定了几层（约化结果变了）、换了输入结构。
REST 只收整数 `match`，不受影响；JS 同样核对。

### 3.7 手动模式与保持输入胞

- **Manual**：`substrate_matrix`、`overlayer_matrix`（相对匹配网格，行 = 新基矢）。校验：整数（|x − round(x)| < 1e-8，否则 `matrix entries must be integers`）；
  |x| ≤ 1000、det ≤ 1e6（M1 的 `max_matrix_entry`、`max_supercell_det`）；det > 0（否则 `substrate matrix determinant must be positive (got -2)`）。
  计算 F 与应变；最大失配 > `interface_large_strain_warn`（5%）只警告；> 50% → `the layers differ by 63% in size; check the matrices`。
  不做派生去重（用户要什么给什么），但仍生成变体供参考。
- **Keep the input cell**（领域 #6、工程 #13）：`substrate_matrix="input"`（界面默认）→ 基底矩阵 = **输入胞**在约化匹配网格中的整数矩阵 `K @ T⁻¹`
  （K 见 §3.2 步骤 6，T 见 §3.3(a)；输入胞是原胞的超胞，矩阵必为整数）；也可以给任意整数矩阵。只搜索覆盖层子格：m = det，`max_area` 不用于基底，n 的上限按基底超胞面积换算。
  - 干净 Pt(111) p(3×3) 4L（约化为 1×1）+ Keep → m = 9，即用户的 3×3 胞 [R：石墨烯 (2√3×2√3)R30° 配 Pt p(3×3)，−2.419%]；v1 会塌缩成 1×1。
  - 带 CO 的 p(6×6)（不可约化）+ Keep → m = 1（匹配网格本身就是 6×6）。
  - 在 2×2 的 graphene/Ni(111) 结果上叠 hBN → m = 4（"Stack another layer…"的预填）。
  - 若 max_area < 基底匹配网格面积且未选 Keep → E-AREA，提示改用 Keep。

### 3.8 构建步骤（`make_interface`）

#### 3.8.1 流程

```
make_interface(substrate, overlayer, *, vacuum, match=0, variant=0, substrate_matrix=None, overlayer_matrix=None,
               strain_to, strain_weight, distance, shift, shift_cart, anchor, flip, flip_substrate, primitive,
               keep_constraints, keep_overlayer_tags, name, frame, return_parts, **search):
  0. vacuum：Python 为必填的仅关键字参数（缺 → Python 自己的 TypeError）；JS 缺或 null → E-VAC；0 ≤ vacuum ≤ 200（U4）
  1. S ← prepare_layer(substrate, flip=flip_substrate, primitive, frame);  O ← prepare_layer(overlayer, flip, primitive, frame)
  2. 解析匹配：
     substrate_matrix 与 overlayer_matrix 都给出 → Manual（§3.7）
     match 为整数 → 用 **search（只给 substrate_matrix 或 "input" 时为 Keep 模式）搜索，取第 match 类（0 起）；越界 → E-RANGE；无匹配 → E-MATCH
     match 为对象 → 核对指纹（§3.6.7），用其矩阵在 S、O 网格上重算（不信任传入的数值）
     variant = k → 取该类第 k 个变体（越界 → E-RANGE）
  3. 面内超胞：S2 ← M1 make_supercell(S.structure, embed(M_s @ T_s))；O2 ← M1 make_supercell(O.structure, embed(M_o @ T_o))
     （embed = [[m11, m12, 0], [m21, m22, 0], [0, 0, 1]]；原子顺序、源映射、adsorbate_id 按像重编号与标志换算都由 M1 负责）
  4. 形变与分配：A = S2 面内基，B = O2 面内基；F = Aᵀ B⁻ᵀ（列写法）；(R, U, V, θ) = polar(F)
     w = {overlayer: 0, substrate: 1, both: strain_weight}；公共面内胞 C 的行 c_i = V^{−w} a_i（sym_pow，§3.3(d)）
     基底：面内分数坐标 f_s = xy·A⁻¹（保持），新 xy = f_s·C          # 等价于施加 G_s = V^{−w}
     覆盖层：f_o = xy·B⁻¹，新 xy = f_o·C                              # 等价于施加 G_o = V^{1−w} R（扭转 + 应变）；z 都不变
  5. 错位（§3.8.3）：确定锚原子与 shift 矢量；平移覆盖层使其锚原子的一个像位于 G_s(基底锚 xy + shift_vec)
     两部分面内分数坐标包裹到 [0, 1)（F0-D wrap_fractional）
  6. 层间距 d：数值 → d；"vdw"/"covalent" → §3.9 的闭式解；"bulk" → §3.9.5；覆盖层 z ← z − z_min(O) + z_max(S) + d
  7. 坐标系与晶胞：φ = atan2(C₀y, C₀x)；整体绕 z 转 −φ（C₀ ∥ x，C5）
     H = (z_top − z_bottom) + vacuum；cell = [[C₀x, 0, 0], [C₁x, C₁y, 0], [0, 0, H]]；**pbc = [T, T, T]**（U2，两块输入都是 T T F 时也一样）
     z 平移使最底原子 z = vacuum/2（叠层居中，U4 的"slab 居中"）
  8. 合并：两部分的晶胞先设为最终晶胞（面内矢量就是 C、c 都沿 z，所以标志不变，工程 #19）；
     out ← F0-D concat_structures([S2′, O2′], cell=cell, pbc=[T, T, T], renumber_adsorbates=True)（基底在前）；props 与吸附物记录见 §4.1
  9. info.surface、名字、警告（§4）；mark_edited(out, "atoms")（清除空间群，C7）；最近接触与周期像检查（§3.9.6）；约束检查（§3.8.4）
  10. return_parts（M6-S10）：另返回 out 去掉覆盖层原子、去掉基底原子的两个结构（同一 cell、pbc；remap 子集；名字加 " (substrate part)" / " (overlayer part)"；
      info.surface.interface.part = "substrate" | "overlayer"）
```

#### 3.8.3 锚原子、错位单位与预设（M6-F7，领域 #14）

- **锚原子**：基底 = 准备后基底中 z 最大的**非吸附物**原子（`adsorbate_id = 0`；z 差 ≤ 1e-3 Å 视为并列，取最小下标；工程 #20）；
  覆盖层 = z 最小的非吸附物原子。`anchor = (i_s, i_o)`（应该）给**输入结构**的原子下标，经准备的源映射找到对应原子（约化后取其轨道的代表）。
  `info.surface.interface.anchor` 记录输入结构中的下标（工程 #25）。
- **单位**：`shift = (u, v)` 是基底**参考网格**（1×1）的分数坐标；`shift_vec = u·a_ref + v·b_ref`（准备坐标系）。v1 用基底输入胞，对 6×6 输入 fcc 位就不是 (1/3, 2/3)。
  `shift_cart`（应该）：结果坐标系中的笛卡尔矢量（Å），先转回准备坐标系再用。
- **预设**（只在基底最外层原子面每个参考胞恰有一个原子时提供，如密排与 (100)、(110) 金属面；其余只有 Top，完整的位点菜单是 M6-S1）：

  | 参考网格（M1 `mesh_type`） | 预设 (u, v) |
  |---|---|
  | hexagonal（120° 基） | Top (0, 0)；Bridge (1/2, 0)；两个空位 (1/3, 2/3)、(2/3, 1/3)：次表层（M3 `find_layers(skip_adsorbates=True)` 自顶数第 2 层）有原子在其正下方（面内最小像 < 0.5 Å）→ "hcp hollow"，否则 "fcc hollow"；只有一个原子面时两者都叫 "hollow" |
  | square | Top；Bridge (1/2, 0)；Hollow (1/2, 1/2) |
  | rectangular | Top；Short bridge / Long bridge（沿较短 / 较长的参考矢量的 1/2）；Hollow (1/2, 1/2) |
  | centered rectangular、oblique | Top |

  例：Pt(111) ABC 堆垛：(2/3, 1/3) 或 (1/3, 2/3) 中次表层原子下方的那一个是 hcp；Ru(0001) ABAB 同一规则给出 hcp（在第 2 层原子上方）与 fcc（不在前两层任何原子上方）。
  选了位点名而基底没有这个位点 → `no 'hcp' site on the substrate surface; available: top, bridge, hollow`（E-SITE）。

#### 3.8.4 约束与界面的检查（领域 #13）

- 构建后，完全固定（`[F, F, F]`）且 z 位于 [z_max(S) − 3 Å, z_min(O) + 3 Å]（`interface_fixed_window`）内的原子按层计数：> 0 →
  W8 `N fixed atoms of 'X' are at the interface`（常见于把切出且固定了底层的金属膜当覆盖层，或 Flip substrate 之后）。
- 基底有固定原子且实际施加到基底的应变（w > 0 时的最大主应变）> 1e-4 → W9 `the fixed layers of 'X' are strained by -3.63%; they no longer have the bulk lattice constant`。

### 3.9 层间距

所有方法给出的都是**垂直间隙** d = 上层最低原子 z − 下层最高原子 z。

#### 3.9.1 接触规则（`vdw` 默认、`covalent`）

设 δ_ij = (z_max(下层) − z_i) + (z_j − z_min(上层)) ≥ 0，ρ_ij 为两原子面内最小像距离（公共胞 C 内，先约化再查 9 个像），T_ij = s·(r_i + r_j)（s = `interface_contact_scale` = 1.0），
距离² = ρ_ij² + (δ_ij + d)²。要求所有对 ≥ T_ij：

```
d = max(interface_distance_min, max over {(i, j): δ_ij < T_ij 且 ρ_ij < T_ij} of [ sqrt(T_ij² − ρ_ij²) − δ_ij ])
控制对 = 取到最大值的 (i, j)；差 ≤ 1e-9 Å 时取 (i, j) 字典序最小者（工程 #20）
```

- sqrt(T² − ρ²) 随 ρ 单调减，所以只需最近像（审查复核正确）。只需考虑 δ < max T 的原子；**N_下·N_上 > 1e6 时必须用二维格子分箱**（工程 #26）。
- 没有任何约束对（两层原子面内都相距 ≥ T，只有极稀疏的覆盖层才会这样）→ d = `interface_distance_min`（0.5 Å），并附备注 "the layers do not touch; set the distance yourself"。
- 同一个闭式解与 M5 K6"接触抬升"在法向上的特例相同；两模块各自实现（M5 的抬升带接近方向和逐位点系数），金标互相核对一组 top/hollow 用例。

#### 3.9.5 `bulk`（应该，M6-S11；领域 #11）

d_k = 该层 `info.surface.period / info.surface.layersPerPeriod`（M2 字段），只在 `layersPerPeriod == 1`（每周期一个原子面，如 fcc(111)、bcc(110)、hcp(0001) 的单元素面）时可用。
两层都可用 → d = ½(d_s + d_o)；只有一层可用 → d = 该层的 d_k；都不可用 → E-BULK。v1 的"最上两个原子面间距"对多面终止的氧化物错误（TiO2(110) 桥氧终止给 1.267 Å，周期 3.248 Å），
对弛豫后的金属顶层也会偏小 1–3%。

#### 3.9.6 最近接触与周期像

同一套近邻代码（含阳离子、吸附物，全部原子）给出两个最近接触：层间（下层全部原子 ↔ 上层全部原子，面内 9 个像）与**跨晶胞边界**（覆盖层上表面 ↔ 下一个周期像中的基底下表面，
c 方向一个像，工程 #1）。任一 < `interface_min_contact_ratio`（0.75）× (r_cov,i + r_cov,j) → 警告
W10 `closest contact between the layers is 0.85 Å (C–Ni)` / W11 `the top of the stack is 1.20 Å from the next periodic image (S–Au); increase the vacuum`。
真空为 0（U4 允许）时 W11 几乎一定出现。

### 3.10 应变报告

对每层 k，面内形变 G_k（该层准备后的坐标系中）：基底 G_s = V^{−w}，覆盖层 G_o = V^{1−w} R。结果坐标系转角为 −φ（§3.8.1 第 7 步）。

| 字段 | 定义 |
|---|---|
| `tensor` | Biot 应变 ε = S − I，S = 结果坐标系中的对称伸长：基底 `Rz V^{−w} Rzᵀ`，覆盖层 `Rz V^{1−w} Rzᵀ`；给出 [[εxx, εxy], [εxy, εyy]] |
| `principal` | S 的特征值减 1，[ε1, ε2]，ε1 ≤ ε2 |
| `angle` | ε2 主方向与 x 轴夹角（度，[0, 180)）；各向同性（\|ε2 − ε1\| < 1e-7）时为 0 |
| `areal` | det S − 1 |
| `greenLagrange` | E = ½(G_kᵀ G_k − I)，在该层自身坐标系中（与 pymatgen `Deformation.green_lagrange_strain` 同义，便于对照） |
| `maxShear` | 面内最大工程剪应变的一半 (ε2 − ε1)/2（v1 的 `vonMises` 删除：把 (ε1, ε2, 0) 当三维应变对自由的二维片层没有物理意义，领域 #20） |

- 列表与搜索判据用的是**失配**（mismatch，"全给覆盖层"口径：F 的主伸长减 1），列名写 "Mismatch"，`mismatch` 字段；选中行与 `info.surface.interface` 给出所选分配下
  每层的**实际应变**。例：graphene/Cu(111) 1×1，失配 +3.77%；`strain_to="substrate"` 时基底实际应变 −3.63%（= 1/1.0377 − 1），覆盖层 0。
- `both`：两层各分到对数意义上的一部分（w = 0.5 时各约一半，原型 +1.180% → +0.588%）。

### 3.12 等价安全算术规则（P1）

v1 原型用前 7 条做到 Python 与 JS 的类列表逐项相同 [R]；v2 增加 8–11 条。实现必须遵守，代码审查逐条核对：

1. **离散决定**（是否通过筛选、是否去重、排序先后、归类）只用 + − × ÷ 和 sqrt 的结果，并保持相同的运算顺序；或者与远大于舍入误差的容差比较。
2. `atan2`、`sin`、`cos`、`pow` 在 V8 与 CPython/glibc 之间可能差 1 ulp：只用于显示、扭转窗口（带容差）、超格取向的极角比较（差 > 1e-9° 才分）和构建坐标（坐标比较容差 ≥ 1e-6 Å）。
3. 取整：约化用 `round_ties_to_zero`；其余 `round` 只用于离整数 < 1e-6（覆盖层行）或 < 1e-2（格子转动）的数，两种语言结果相同。
4. 取模：两种语言都写 `mod(x, p) = x − p·floor(x/p)`，不用 Python 的 `%` 与 JS 的 `%`。整数除法用 floor 语义。
5. 排序：显式比较器 + 容差，不用浮点数四舍五入后的键（±θ 孪生类的最大应变只差 1e-16，不用容差比较时先后由舍入噪声决定 [R，v1]）。两种语言的数组排序都稳定。
6. 浮点数不直接做哈希键；分桶后查邻桶。
7. 输出的整数矩阵都经规范化（§3.6.2），与发现顺序无关。
8. 归类与代表的选择只用与基无关的全序（§3.6.1 的 cmp_same_F、cmp_rep）；任何实现（向量化、Worker、分片）都不得引入依赖遍历顺序的选择。测试用"打乱顺序"核对（§7.1）。
9. 格子转动阶数用 §3.3(e) 的无三角函数判据；转角的 cos/sin 用精确常数，不调用 `Math.cos(Math.PI/3)` 一类函数。
10. 进入名字的数用 `format_fixed(x, d)`：`s = floor(|x|·10^d + 0.5)`，再按整数拼出小数点（两种语言同一实现），不用 `toFixed` 或 `f"{x:.1f}"`（`(21.25).toFixed(1) = "21.3"`、`f"{21.25:.1f}" = "21.2"` [V]）。
    M1 的 Wood 标签角度目前用 `toFixed(1)`，交 M7 统一到同一函数。
11. 化学式用 M2 的 `reduced_formula`（M2 负责两种语言一致）；不用 `display_formula`（`project.py:192` 不约化）或 `get_formula`（含 C 时一律 Hill 序：四原子 SiC 得 `C2Si2`/`CSi`，`display_formula` 得 `Si2C2` [V]）。

#### 3.13.2 网页端的分片（工程 #12）

- 引擎与后处理写成可恢复的生成器 `function* matchSteps(sub, ovl, opts)`：ZSL 在覆盖层区段循环里每 256 次迭代检查一次 `performance.now()`，超过 `sliceMs`（默认 12 ms）就 `yield`；
  重合矢量引擎在枚举与组合两段循环里同样处理；后处理按块、块内每 16 个候选组检查一次；最后的排序与 Pareto 一次完成（1 万类 < 10 ms）。
- 驱动器 `matchMeshesAsync(..., {signal, onProgress, sliceMs})` 用 `setTimeout(0)`/`MessageChannel` 继续下一片；每次让出时检查 `AbortSignal`，取消时抛 `AbortError`。
- 进度 = 已完成工作量 / 估算工作量（ZSL 的 work 或 K̂），引擎占 70%、后处理 30%；只用于显示。
- 同步版 `matchMeshes` 直接把生成器跑完（Node 测试、公共同步 API）。Worker（M6-C4）是后续优化，必须保留主线程回退。

```
      X.info.surface.kind == "cleave" → M2 surface_label(X.info.surface)（M2 §3.13 名字的第一段：reduced_formula + miller_token，例 "Ni(111)"、"ZnO(10-10)"）
      X.info.prototype ∈ {graphene → "graphene", hbn → "hBN", mos2 → 化学式} → 该名
      否则 M2 reduced_formula(X 的组成)（例 "MoS2"）
W(X)：叠层 → ""（叠层的网格写在来源里）；否则 " " + mesh_token(matrixRef)，mesh_token 按 M2 §3.13：1×1 → 省略（W = ""）；对角 → p(m×n)；
      否则 M1 wood_label；wood_label 为 None → "[[s11,s12],[s21,s22]]"
twist_suffix：L_o == L_s 且 |θ| ≥ 0.05° → " " + format_fixed(|θ|, 1) + "° twist"；否则 ""
info.surface.interface.label = "{L_o}/{L_s}"
```

例：`graphene/Ni(111)`（1×1/1×1）、`graphene p(3×3)/Pt(111) (√7×√7)R19.1°`、`MoS2 p(4×4)/Au(111) (√19×√19)R23.4°`、`graphene p(10×10)/Ir(111) p(9×9)`、
`graphene (√7×√7)R19.1°/graphene (√7×√7)R19.1° 21.8° twist`、`hBN/graphene/Ni(111)`、`graphene …/Pt(111) p(6×6)`（带 CO 的 p(6×6) 基底）。
用户给 `name` 时用用户的。M2 未导出 `surface_label` 时，M6 在 `build/interface.*` 内按 M2 §3.13 的同一规则实现（§10）。

### 4.5 多帧、部分占位、文件格式

- 多帧（C11）：每个输入只用当前帧（Python：`frame` 参数，默认 0），结果单帧，W1。网页端在按钮旁提示 "Uses the current frame"。
- 部分占位（C12）：`occupancy` 照常复制，W2。
- POSCAR：不保存 `info`（04 报告 §4），注释行写结构名；SD 由 F0-D 修好的写出器输出；`interface_layer` 不进 POSCAR。
- extxyz：`interface_layer:I:1` 列；`pbc="T T T"`；`info.surface` 以 `_JSON` 写出（F0-D）。JSON：全部保留。

### 5.3 分区控制器、搜索与缓存（工程 #24）

- 分区状态（两层选择、参数、最近一次搜索结果、选中的 `key`、列表滚动位置、进行中的搜索、会话内的真空值）放在**模块级控制器**里；`render` 只读状态、**从不启动搜索**。
  Surface 面板按分区签名单独重绘（F0-A §3.17），但选区变化等事件引起的重绘也不能丢状态。
- 搜索只由输入事件（参数改变、Swap、Flip、选层）或输入结构的修订号 `rev` 变化触发；参数变化后 400 ms 防抖启动，上一轮被取消（`AbortController`）。
- 缓存键：`PreparedLayer` 用 (结构 id, `rev`, flip, primitive)；搜索结果用 (两层的准备键, 全部搜索参数)。大基底的原胞搜索不必每次重跑。
- 结果过期判定：任一层的 `rev` 与搜索时不同 → 结果作废，状态行 "The layers changed. Search again."，Create 不可用直到新搜索完成。
- 进度只显示在分区状态行（`aria-live="polite"`），带 [Stop]；**不调用 `app.startTask`**——它委托 `_busyStart`（`app.js:1269-1284`），会把 `app.busy` 置真，
  使 F0-A 的 `canEdit` 与导出都不可用（工程 #6），而本分区的搜索在每次改参数后自动运行。
- 参数变化后若之前选中的 `key` 仍在结果中则保持选中，否则选第 1 项。

### 5.4 预览与创建

- 选中一项即开 F0-A 的 P-swap 会话：`ses = app.beginStructureEdit('Build layers', { kind: 'structure', owner: 'surface.interface', commitLabel: 'Create', onEnd })`，
  `ses.preview(built)`；会话开始后第一次预览完成时调用一次 `viewer.fitView()`（P-swap 默认不取景，F0-A §3.6.3；界面结果常比当前结构大一个量级），之后不再自动取景。
- **真空未填时**：预览用只供显示的 `interface_preview_vacuum`（10 Å）建结构，预览条标签为 "Build layers — vacuum not set (shown with 10 Å)"，状态行写 "vacuum not set"；
  Create（分区里的和预览条上的）都不可用，tip "Enter the vacuum (total gap in Å; 0 for none)."（U4）。显示用的 10 Å 间隙大于 F0-D 的 5 Å 阈值，
  所以 U1 的显示切口落在真空里而不是层间隙里（工程 #2）。填了真空后预览用真实值重建。
- 预览期间 `app.structure` 不变、不写历史、不标记未保存、不进自动保存缩略图（P3，F0-A 保证）；离开分区、切换活动结构、撤销/重做或项目变化时 F0-A 自动结束会话。
- **Create**：若 120 ms 防抖未到或预览不是当前参数的结果，先用当前参数同步重建，再 `ses.commit({ addAsNew: true, name })`（F0-A：`addStructure(previewS, { replaceProject: false, label })`）；
  新结构成为活动结构；撤销标签 `Add <name>`；`app.toastUndo("Built MoS2 p(4×4)/Au(111) (√19×√19)R23.4° — 124 atoms", { entry })`（只撤销这一步）；
  `return_parts` 勾选时另加两个结构（同一历史条目中，一次撤销）。超过 `interface_confirm_atoms`（50 000）先确认 "This interface has 120,000 atoms. Create it?"。
- 预览条上的 Create、mod+Enter（F0-A `edit.applyPreview`）与分区里的 Create 必须是同一个动作并同时可用/不可用：需要 F0-A 的会话选项 `onApply`（预览条与 mod+Enter 调用它，
  而不是默认参数的 `commit()`）与 `canApply() → true | string`（字符串即禁用原因）。这是 v2 向 F0-A 新提的请求（§10.2），也是 **T7b 的前置依赖**：
  F0-A v2 中 `edit.applyPreview` 对 P-swap 会话调用 `commit()`，即 `replaceActiveStructure(预览结构)`——会把基底换成界面而不是新增结构，也绕过 U4 的真空检查；
  M2 的 Cleave（`commit({ addAsNew: true })`）有同样的问题。
- Cancel：结束会话，保留分区参数。"Stack another layer…"（M6-S3）：Create 后出现在分区底部；预填基底为新结构、Substrate cell = Keep the input cell。

```
crystallume build interface SUBSTRATE OVERLAYER --vacuum Å [--from FMT]
    [--list [--json]] [--pick N] [--variant K]
    [--max-strain PCT] [--max-area A2|auto] [--max-atoms N] [--twist DEG] [--twist-tol DEG] [--max-aspect R]

    [--no-constraints] [--keep-overlayer-tags] [--parts] [--name NAME] [-o OUT] [--format FMT]
```

- **构建时 `--vacuum` 必填、没有默认值**（U4）：未给 `--list` 而缺 `--vacuum` → `parser.error("--vacuum is required: the total gap in Å between the stack and its periodic image (0 for none)")`（退出码 2，与 argparse 的必填参数相同；不用 `required=True`，因为 `--list` 不构建、不需要真空）。
- `--list`：打印匹配表（rank、atoms、area、twist、mismatch、substrate、overlayer、Pareto 标记）到 stdout，不构建；加 `--json` 输出 §6.1 的 dict。
- `--pick N` 从 1 起（人类计数），默认 1。**单位**：CLI 的 `--max-strain` 用百分数（3 = 3%），Python/REST/JS 的 `max_strain` 用分数（0.03）；M1 的 `apply_strain` 也用百分数——
  各入口的单位写在帮助里，交 M7 统一（工程 #23）。
- `--from FMT` 同时作用于两个输入文件；两者格式不同时省略 `--from`，按扩展名判断。
- 矩阵用 `nargs=4`，向量 `nargs=2`，避免 `nargs="+"` 吞掉位置参数（04 报告 §2.5）。`--parts` 写出 `OUT` 之外的 `OUT.substrate.EXT`、`OUT.overlayer.EXT`。
- 例：`crystallume build interface Ni111.vasp graphene.json --distance covalent --shift-site fcc --vacuum 15 -o POSCAR`；
  `crystallume build interface gr.json gr.json --twist 1.05 --twist-tol 0.05 --max-strain 0 --max-area 20000 --distance 3.35 --vacuum 20 -o tblg.xyz`。

**`required: true`**）、`match`（≥ 0 整数）、`variant`、搜索参数与构建参数（同 REST 范围）；不合法时抛 F0-A 的 `invalid-params`，文案如

## 7. 测试

### 7.1 单元测试（两种语言各写：`tests/test_latticematch.py`、`tests/test_interface.py`、`tests/js/latticematch.test.mjs`、`tests/js/interface.test.mjs`）

**匹配核心**
- `reduce_basis_shortest`：60° 与 120° 六方基都停住且两种语言相同；det T = +1；随机基与暴力最短矢量比较；定向保持；|u′| ≤ |v′|。
- `annulus`：与暴力枚举（|i|, |j| ≤ 50）逐个相等，含边界半径。`hnf_matrices_2d(n)` 个数 = σ(n)；`hnf_2d` 对任意幺模左乘不变。
- `polar`/`stretches`/`sym_pow`：R 正交、det R = 1、U 对称正定、F = RU（1e-12）；伸长与 numpy SVD 一致；各向同性分支。
- `lattice_rotations`：精确六方/正方/矩形；晶格矢量取 3–6 位小数、2e-4 与 1e-3 畸变时 k 不变，5e-3 时 k = 2；**任何输入都不抛错**；`rot_v2.mjs` 的 180 个网格作两语言金标（领域 #9、工程 #11）。
- 变体：六方/六方各向同性 6 个、各向异性 18 个；矩形/六方 P = 60°；正方/六方 P = 30°。派生：graphene/Ni(111) 结果中不含 2×2/2×2；被扭转窗口过滤掉的类的派生也不出现。
- **遍历顺序无关**（工程 #8）：把 HNF 枚举、基底子格循环、覆盖层区段与环带枚举全部反过来，graphene/Ni(111)（默认与 700 Å²）、MoS2/Au(111)（e = 0.5%、1500 Å²）、
  重合矢量引擎 15° ± 15° 上的类列表（代表与变体矩阵）逐项相同。
- **两引擎等价**（工程 #7）：graphene/Ni(111) θ0 = 10.9° ± 0.5°、400 Å² 两引擎都是 16 类且都含 m/n = 73/79；`max_aspect=None`、200 Å² 都是 11 类（测试中把矢量对上限调高）；
  MoS2/Au(111) e = 0.5%、15° ± 15°、1200 Å² 都是 96 类；tBLG（21.8、13.2、9.4、7.3）与 MoS2/Au 对齐 1000 Å² 相同。
- **K̂ 与上限**（工程 #3）：e ≥ 1e-3 的 6 个用例估计与实际相差 ≤ 20%；graphene/Ni(111) 5°、3%、5000 Å² 与 50 000 Å² 不枚举直接 E-PAIRS（< 0.1 s）；枚举中超限立即停止。
- **Pareto 稳定**（领域 #9）：graphene/Ni(111) 默认参数，两层晶格矢量取 4、5、6 位小数时类数（561）与 Pareto 集合（8 类）与精确输入相同。Pareto 标记、排序（含 ±θ 孪生的稳定先后）、`key` 唯一。
- 手动模式：det ≤ 0、非整数、元素 > 1000、相差 > 50% 报错；Keep：`"input"` 对干净 Pt(111) p(3×3) 给 m = 9，对 2×2 的 graphene/Ni(111) 结果给 m = 4（领域 #6）。
- 解析检验：tBLG 公度角 cos θ = (3m² + 3m + 1/2)/(3m² + 3m + 1)、原子数 4(3m² + 3m + 1)：m = 1, 2, 3, 4, 31 分别为 21.787°/28、13.174°/76、9.430°/148、7.341°/244、1.050°/11908，应变 0。

## 附录 B：翻转与镜像的推导要点

斜方网格 L 的正定向约化基有 (u, v)（长度 a、b，逆时针夹角 γ）与 (v, −u)（b、a，180° − γ）；镜像 L′ 的正定向约化基为 (Mv, Mu)（b、a，γ）与 (Mu, −Mv)（a、b，180° − γ）。
两组相同当且仅当 a = b 或 γ = 90°。所以一般斜方网格的镜像不能经转动与原网格重合，翻转（从 +z 看相当于镜像网格）后必须重新匹配。
六方、正方、矩形、有心矩形网格满足条件：翻转后的网格与原网格最多差一个转动（a ∥ x 的六方、正方、矩形网格完全不变），匹配的失配集合不变、扭转角会平移；原子图案仍可能改变（如 MoS2 的三重轴）。

### 原型中自行发现并修改的问题

1. **共价规则下"排除阳离子"会出错**：Al 终止的刚玉 (0001) 上石墨烯被放在 Al 上方 0.55 Å；因此阳离子一律用 Shannon 半径（vdW 规则下两者在全部场景上相同）。
2. **Auto 面积必须受矢量对预算约束**：默认 3% 时 graphene/Cu(111) 对齐的 4 倍莫尔胞面积会超过上限；改为取预算内的最大面积并给出提示（§3.5.4）。
3. **v1 场景文字有误**：tBLG Target 1.05° ± 0.05° 按原子数排序时第 1 行是 ±1.085°（11 164 原子），1.050°（11 908 原子）在第 3 行（§3.15）。
4. **左手晶胞的顶面**：M1 `standard_frame` 对左手晶胞给出 c_z < 0，若不处理，M6 的"上表面"会与 F0-A/M5 的定义（+c 一侧）相反；准备时先做 b ← −b（§3.2.1 第 2 步）。
5. **类数变化**：`max_area` 改为只限基底后，默认场景的类数略增（graphene/Ni(111) 549 → 561 等），Pareto 集合不变；§3.15 与附录的数字全部按 v2 规则重算。
6. **后处理的代价**：组内选择与类的创建顺序只用与基无关的键，只需规范化每类的创建者，Python 后处理与 v1 相当（graphene/Ni(111) 1.68 s）。
7. 现有代码 `routes/analysis.py:35` 的 `CRYSTALLUME_MAX_PAIRS` 注释与 `Settings` 不符（§6.3、§10.6）。
8. **F0-A 的预览条与 mod+Enter 会用默认参数提交 P-swap 会话**（`replaceActiveStructure`），对“新增结构”类的会话（M6、M2 Cleave）是错的，也绕过 U4 的真空检查；v1 没有发现。v2 向 F0-A 请求 `onApply`/`canApply` 并列为 T7b 的前置依赖（§5.4、§10.2）。
