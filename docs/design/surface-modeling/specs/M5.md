## 0. 摘要：关键决定

| # | 决定 | 理由（证据） |
|---|---|---|
| K1 | **吸附物库只存一份**：`crystallume/web/data/adsorbates.json`（schema `crystallume.adsorbates/1`），52 个条目。每个模式直接存**局部坐标系下的笛卡尔坐标**，运行时不做内坐标换算；框架约定按 §3.9（v2：参考方向可由模式的 `reference` 字段给出）。读取用共用模块 `core/webdata.py`/`core/webdata.js`：**规格在本文 §4.2 定稿（简报 §3 要求由 M5 定），实现归 F0-D 第 0 波**（M2 第 1 波的 `oxidation_states.json` 也要用）。 | 两种语言零换算，坐标逐位一致；简报 §3；波次（E9）。 |
| K2 | **基底与表面坐标系一律走共用函数**：先用 M3 `find_adsorbates` 认出吸附物，再剔除"不与周期网络相连的有限片段"，得到基底；在**只含基底原子的轻量视图**上调用 F0-A `surface_normal`（及其 `cut`），法向可以沿任意晶轴；按整数像偏移展开。不再自写展开与真空判定，删去 E4。 | v1 的中位数平移在恰好一半原子跨边界时出 ±0.5 个 c、吸附物会吃掉真空（10 Å 真空两面各一个 CO 只剩 4.04 Å）、真空沿 a 时直接拒绝（违反 U1）（E1）。v2 原型四种情形都与理想 slab 完全相同（`checks_frame.py`）。 |
| K3 | **位点原子 `auto` v2**：顶层 ∪ "上半部（按基底高度的中位数）里欠配位且未被顶层覆盖的原子"。配位数只在**基底子图**上用 M3 的 smart 键图计算；参考配位数取**下半部**同元素的最大值，下半部没有的元素一律作为候选（只做覆盖判据）。去掉 v1 的 3 Å 全局深度窗。 | v1 的深度窗锚定在最高原子上，负载团簇或两层高岛会让真实表面整个消失（D1：Pt4/Pt(111) 台面 16 个原子全丢）；吸附物会改变配位数，放置后标签跟着变（E13）。v2：Pt4/Pt(111) 恢复 13 + 4 个位点原子（团簇正下方的 3 个台面原子被遮挡，§3.2.3），23 个场景 slab 的位点原子与 v1 完全相同（`m5run.py`）。 |
| K4 | **两步补全位点原子集合**：(a) 三角剖分前剔除被遮挡的位点原子（投影距离 < 0.3·d_nn 且更低）；(b) `auto` 再补上 `exposed` 原子集合里的**密堆微面三重位**（顶点全为金属、两两成键、近正三角形，横向 0.3 Å 去重）。 | (a) v1 的 1e-6 Å 重合判据只挡精确重合，自检还会因此失败报 E9（D12、E14）；(b) fcc(110) 的 (111) 微面准三重位是常见位点，`auto` 漏掉它，`exposed` 又丢掉长桥与 4 重位（D7）。原型：只有 fcc(110) 多出 fcc/hcp 各 2 个（每 1×1 胞），其余场景（含 bcc(111)、CeO2、MoS2）一个不加。 |
| K5 | **位点 = 周期性二维 Delaunay + 外接圆心合并**（Bowyer–Watson，两种语言逐行移植；不变）。自检的 V 取剖分顶点数。 | 无参数、适应任何表面；Python 与 JS 三角形逐个相同（v1 原型）。 |
| K6 | **fcc/hcp 只给"金属密堆三角形"**：三个顶点都是金属、两两成键、近正三角形；沿三角形法向第一个轴上原子与三个顶点都成键 → `hcp`，否则 `fcc`。其他三重位与 4 重以上空位写成 `hollow (X3)`，必要时加 ` over Y`、`shallow`/`deep` 前缀（§3.6）。 | bcc(111) 两种空位都叫 hcp、CeO2(111) 的"hcp"恰是体相延续位、刚玉出现两个 `hcp (O3) over Al`（D2）。v2：bcc(111) → `shallow`/`deep hollow (Fe3)`，CeO2 → `hollow (O3) over Ce`/`over O`，MoS2 → `hollow (S3) over Mo`（T_Mo）/`hollow (S3)`（H），刚玉 → `shallow`/`deep hollow (O3)`。 |
| K7 | **接近方向按类决定**：桥位用垂直于桥轴的方向，空位用顶点平面的法向，只有系综原子两两成键（真实微面）且类内平均倾角 > 5° 时才启用，类内所有位点一致。 | Pt(211) 8 个桥位中有 5 个沿全局法向只成一根键（2.020/3.464 Å），改为垂直于桥轴后两根都是 2.020 Å（D3，`checks_place.py`）；TiO2 的 `hollow (Ti2O2)` 不成键、倾 21° 却被当成微面，2° 阈值让等价位点各用各的方向（D11）。 |
| K8 | **等价性**：局部指纹（元素、d、Δh、ρ，半径 5 Å，容差 0.10 Å）不变；分类改为**按与原子下标无关的几何键排序后贪心**，加一个可证明不改变结果的标量预筛，类数上限 200（超过则按基础标签归并并给出 W13）。可选 `fingerprint_adsorbates`：已有吸附物进入指纹但不成为位点原子。 | 带容差的贪心依赖访问次序，弛豫结构上类数爆炸、复杂度近二次（E5）。v2：4 种原子顺序分组完全相同、预筛前后完全相同（`checks_class.py`）；共吸附时 fcc 分成 3 + 3 + 3、top 分成 1 + 6 + 2（D4）。 |
| K9 | **放置高度：接触抬升**（不变），但目标键长改为 `f × (r_A + r_M,eff)`：金属基底原子的有效半径取 slab 自身"金属–金属键长中位数的一半"，阳离子取"到阴离子键长的中位数减去阴离子共价半径"，其余用 Cordero。系数 `bondFactor` 按模式 × 位点类型，另有 `cation`、`covalent` 两个环境键；结合原子与 slab 原子都是电负性元素时（该原子自身的 top 位除外）用非键下限 `0.8·ΣR_Bondi`。T13 用 5 种金属、2 种氧化物校准。 | 只在 Pt(111) 上校准的 Cordero 半径在其他金属上有系统偏差：W −0.25、Mo −0.18、Ru −0.11 Å；N/Ru(0001) 2.06 → 1.96 Å，O/W(110) 2.28 → 2.03 Å；Ti5c 上 O 2.26 → 1.75 Å（D9）。O 放 TiO2 的 `bridge (O2)` 时 O–O 只有 1.78 Å（D10）。 |
| K10 | **放吸附物原位修改 slab**（U5/D2），一次撤销。第一次写 `adsorbate_id` 前先调用 M3 `promote_adsorbates`；新原子按 F0-D K14 **保持元素分块**（slab 已按元素分块时追加后做一次稳定的 `sort_by_species`），源映射交给 F0-A 的追踪器；`mark_edited(s, "atoms")`；记录写入 `info.surface.adsorbates`；名称只用 M2 的哨兵 `info.surface.name`。 | 不先 promote，导入的 CONTCAR 里已有的 CO 会在第一次放置后变成基底（E2）；追加在末尾会让 CONTCAR 序号与界面不一致、每次导出多一条说明（E3）；两套自动命名会互相打断（E19）。 |
| K11 | **上下表面对称操作**由 M5 实现（M2 本期不提供）：在表面坐标系 (e1, e2, n) 中求解，只用基底原子，参考原子取顶层最稀有元素、候选只取底层同元素原子，结果按基底摘要缓存。"Both sides" 降为"应该"。 | v1 假设法向沿 z、把吸附物也算进去，顶面放一个 CO 后 Both sides 永久禁用，1 万原子 4.5 s（E6、D8）。v2：转 90° 的 slab、顶面已有 CO 都得到反演；9600 原子 1.8 s（Python 原型，未向量化）。 |
| K12 | **覆盖度的默认分母是 1×1 表面胞**（每个 1×1 胞一个吸附物 = 1 ML），同时显示"每个位点原子"与"每个某元素原子"；1×1 网格取自 M2/M1 的来源信息，没有时用 M1 `find_translations` 在基底上求面内原胞。1/n 超胞在 1×1 网格上枚举、按面内点群去重（`M′ ≡ U·M·g`）、按（最短矢量、保留的点群操作数、有无 Wood 标签、次短矢量、夹角偏差）排序，只有当前晶胞的超格才能 Apply。 | TiO2(110) 上"每个桥氧一个 H"显示成 0.50 ML、p(2×2) 上输入 n = 3 得到 1/12 ML（D5、E7）；v1 的去重条件恒成立、排序把斜胞排在 p(2×2) 之前（E7、D13；`checks_cov.py` 复现并验证修正）。 |
| K13 | **共吸附**：新增 W5（吸附物之间的非键近接触，`d < 0.8·ΣR_Bondi`，氢键对放宽到 1.5 Å）；位点给出 `nearestAdsorbate`；"放到所有等价位点"和"填充"默认跳过已占用与会触发 W2/W5 的位点（`skip_blocked`）。 | CO 在顶位时把 O 放到全部 9 个 fcc 位，有 3 个 O 距 C 只有 1.71 Å，W2 一条都不报（D4）；v2 的 W5 报出这 3 个放置。 |
| K14 | **预览不开会话**：悬停和选中位点时的幽灵一律用 F0-A 的 `ghostLayer`；位点标记只在 Pick site 工具下可拾取（`pickIn: ['site-pick']`），该工具里单击选位点、双击放置。 | F0-A 的会话会冻结所有编辑与导出（选着吸附物时连 Delete、导出 POSCAR 都不能用），且 F0-A v2 已规定悬停幽灵不开会话（E4）。 |
| K15 | **批量生成**：每种不等价位点各生成一个新结构（`adsorption_structures`，P4 的"新结构"），并提供不等价表面原子上的替位与空位（应该）；弛豫后的位点归属 `assign_sites`。 | 高通量吸附能筛选的标准步骤（pymatgen `generate_adsorption_structures`）；CONTCAR 分析要看吸附物是否迁移（D6、D21）。 |
| K16 | **两种语言的 API 用同一组词、同样分三层**：`plan_adsorbates`（纯函数）→ `apply_placements`（原位）→ 便捷的 `add_adsorbate(s)`；键长参数叫 `bond_length`，`distance` 只保留 pymatgen 兼容的位点偏移含义。 | 简报 §3；P1 要能逐函数核对；`distance` 一词两义（E10）。 |
| K17 | **公开端点有工作量守卫**：`/build/adsorbate` 需要位点识别时先 `_guard_work`，云模式下未登录返回 401（只接受显式坐标的请求不受影响）；`/analysis/sites` 可以只返回类、限制位点数。 | 匿名用户可以反复提交接近 20 万原子的 slab（E8、EM3）。 |

## 3. 算法

记号：行向量晶胞 `cell`（C1），`cart = frac @ cell`；`k` 为真空轴，`(i, j) = (k+1, k+2) mod 3` 为面内两轴；`n` 为表面法向（`n·a_k > 0`，顶面 = +a_k 一侧，F0-A A-D16）；
`n_s` 为当前面的外法向（顶面 `n`、底面 `−n`）；`r_cov(X)` 为 Cordero 共价半径（F0-D 统一的表，未知元素 0.5 Å）；`R_B(X)` 为 Bondi 半径（F0-D K16 `bondi_radius`，缺失时 `adsorbate_vdw_fallback` = 2.0 Å）。
成键一律用 M3 的化学键图（`bond_graph`，判据 `bond_min < d < min(bond_max, bond_scale·(r_i + r_j))`，0.4 / 5.0 / 1.15，按周期像逐条计数，M3 K7），本模块不另设成键常量。
取整与格式化一律用 `q_d(x) = sign(x)·floor(|x|·10^d + 0.5)` 与基于它的 `format_decimal(x, d)`（§4.7，两种语言逐字相同，E16）。所有常量见 §4.7。

### 3.1 前提、基底与表面坐标系（E1）

```text
surface_setup(s, side, *, include_adsorbates=False, exclude=(), indices=None, frame=None):
  require s.cell                                                        # E1
  # 1. 吸附物与基底
  A0 = include_adsorbates ? ∅ : find_adsorbates(s).indices              # M3 §3.8：adsorbate_id → tags（含 OC20）→ 几何猜测
  若 method == "indices"：A0 ← A0 − indices                               # 用户指定的原子总是基底
  sub0 = 全部原子 − A0 − exclude
  G0 = bond_graph(view(s, sub0), metal_pairs="smart")                    # 基底子图（E13）
  loose = 若 G0 含面内无限延伸的连通块：原子数 ≤ |sub0|/2 的有限连通块（M3 的连通块与像偏移追踪），否则 ∅   # D1-3
  ads = A0 ∪ loose；sub = sub0 − loose；G = loose 为空 ? G0 : 在 sub 上重建
  loose 非空 → W14 "C37, O38 are not bonded to the surface and are treated as an adsorbate"（最多列 6 个原子）
  # 2. 法向与切口：F0-A surface_normal 作用在只含基底的视图上（吸附物不占真空，E1-2）
  sn = surface_normal(view(s, sub), frame=frame)                         # F0-A §3.14.2；view 带 info.surface.axis 提示
  sn 为 null 或 sn.surface 为假 → E3（文案 = F0-D vacuum_gap_hint(view(s, sub))，界面经 requireVacuumGap）
  k = sn.axis（任意轴，E1-3）；pbc[i] 与 pbc[j] 必须为真，否则 E2
  pbc[k] 为真：f = 全部原子（含吸附物）的分数坐标第 k 列；m_t = −floor(f_t − sn.cut.lo)（整数，F0-A §3.8.2 的 unwrapAlongGap）
  pbc[k] 为假：m = 0
  upos_t = r_t + m_t·a_k                                                 # 只用于计算，从不写回结构
  # 3. 该面的右手正交框架
  n_s = side == "top" ? sn.normal : −sn.normal；e1 = unit(a_i)；e2 = n_s × e1；F = [e1; e2; n_s]
  X_t = upos_t @ Fᵀ（框架坐标；第三分量 h_t 即沿 n_s 的高度）
  return {sub, ads, loose, G, k, (i, j), n_s, F, upos, m, X}
```

- `view(s, idx)`：只含 `symbols`、`positions`（所选帧）、`cell`、`pbc` 与 `info.surface.axis` 的轻量结构，不复制 props/info，O(N)。M5 所有几何都在这个视图与框架坐标中完成。
- 展开只按整数个 `a_k` 平移，是切口的纯函数；**没有中位数修正**（v1 的 `shift −= median(shift)` 在恰好一半原子跨边界时出 ±0.5，Python 的 `round` 与 JS 的 `Math.round` 再各给一个答案）。
  因为在框架坐标中计算，位点的 `point` 换回笛卡尔后（`P = X @ F`）可能比存储坐标差一个 `a_k`；这不影响任何结果（放置的新原子也在同一展开坐标中，§3.10.5）。
- **真空可以沿任意轴**：v1 的 E4（"真空沿 a，请重定向"）删除。`SiteSet` 报告 `axis` 与 `inPlaneAxes`，`frac` 与 `images` 的面内分量指这两根轴（§4.8）。
- 斜 c（c 不垂直于表面）、左手晶胞都没有问题：高度沿 `n_s`，`n` 由 F0-A 按 `n·a_k > 0` 统一。
- 帧：JS 用当前帧，Python 用 `frame`（默认 0）；多帧编辑的丢帧见 §4.6。
- 一致性：F0-A 的显示、M3 的层都用全部原子算切口，M5 用基底算。两者只在吸附物把真空挤到 5 Å 以下时不同（显示不切、M5 仍能工作）；§10 请 F0-D/F0-A 给 `gap_cut`/`surface_normal` 加 `exclude` 参数，
  显示传 `adsorbate_id > 0` 的原子，届时三者完全一致。
- 原型（`checks_frame.py`）：Pt(111) p(2×2) 4L 把晶胞边界放在第 2、3 层之间（8 个原子在 f > 0.5）、10 Å 真空两面各一个 CO（全部原子的最宽空隙 4.04 Å，v1 报 E3）、
  晶胞行循环置换使真空沿 a、绕 x 转 90° 使法向沿 −y、底面：五种情形的类表都与理想 slab 完全相同。

### 3.2 位点原子

#### 3.2.1 `auto`（默认，K3）

```text
h_t = X_t 的第三分量（t ∈ sub）
layer = cluster_heights(h, layer_tolerance)                     # M3 的一维单链聚类（§3.4 同一规则，0.3 Å），0 = 该面最外层
med = median{h_t : t ∈ sub}                                      # 偶数个时取中间两个的平均（numpy 规则）
CN_t = G 中 t 的边数（smart 规则，按像计数；只在基底子图上，E13）
CN_ref(el) = max{CN_t : el_t = el, h_t ≤ med}；el 在下半部没有原子 → 未定义（团簇、覆盖层、单原子合金的表面元素）
top = {t : layer_t = 0}
auto = top ∪ {t ∈ sub − top : h_t ≥ med
                               且（CN_ref(el_t) 未定义 或 CN_t ≤ (1 − site_undercoordination)·CN_ref(el_t)）
                               且 t 未被覆盖}
覆盖：t 在 G 中与 ≥ 3 个 top 原子相连（含像），这些邻居都比 t 高（Δh > 0），且它们相对 t 的面内方向角排序后最大间隙 < π
```

- 与 v1 的差别（D1）：去掉以最高原子为基准的 3 Å 深度窗（负载团簇、两层高岛会把整个支撑表面挤出窗口）；"上半部"用基底高度的**中位数**而不是极差中点（高团簇放在薄 slab 上时极差中点会高过台面）；
  `CN_ref` 只取下半部（只出现在表面的元素不再"永远不欠配位"）。
- 例：CeO2(111) 的表层 Ce 配位 7 < 8，但被三个顶层 O 包住 → 排除，得到经典位点；fcc(211) 台阶底原子（CN 10）只与 1 个顶层原子相连 → 保留；TiO2(110) 的 Ti5c 不与 O_br 相连 → 保留。
- 原型（`m5run.py`、`checks_frame.py`）：23 个场景 slab 的位点原子与 v1 完全相同；Pt4 四面体放在 Pt(111) p(4×4) 上：位点原子 = 台面 13 + 团簇 4（v1：只有团簇 4 个；团簇三个底角原子正下方的 3 个台面原子在 §3.2.3 被剔除）；
  表面上方 6 Å 的 CO 由 M3 的几何猜测认出（自由分子规则），其他原子已有 `adsorbate_id`、几何猜测不运行时由 §3.1 的有限片段规则认出，位点只来自 Pt。
- 负载在**异种**基底上的团簇（Pt4/TiO2）会被 M3 认作吸附物；需要团簇与周边位点时用 `include_adsorbates=True`：原型得到 6 个 O_br + 4 个 Ti5c + 4 个 Pt（另 2 个 Ti5c 与团簇成键、配位升高而不再欠配位）。
- 只在基底子图上算配位数的另一个好处：吸附物达到 1 ML 时 smart 规则也不会去掉顶层金属之间的键（M3 §3.7 所说的局限对位点识别不存在），放置前后位点标签不变（E13）。
- 已知局限（文档写明）：`auto` 依赖配位数，金属氢化物、碳化物、金属间化合物 + 吸附物等体系可能得到意外的位点原子——界面一键切换方法并显示位点原子，`Selected atoms` 兜底。

#### 3.2.2 其他方法

| 方法 | 级别 | 规则 | 适用 |
|---|---|---|---|
| `exposed` | M | 调用 M3 `surface_atoms(view(s, sub), side, probe=κ)`：所有基底原子看作半径 R = ½·中位最近邻距离的球，半径 κR（κ 默认 `SURFACE_DEFAULTS.surface_probe` = 0.70，M3 K5）的探针竖直落下，先碰到它则暴露 | 想要"几何上看得见的所有原子"时；与 Layers 分区的 Select surface atoms 一致 |
| `indices` | M | 用户给定（界面：选区）；这些原子不再算吸附物 | 特殊表面、重构、负载团簇的一部分 |
| `layers` | S | `layer < layers`（默认 1） | 平整面；与 ASE 的位点表一致 |
| `window` | S | `h ≥ max h − window`（默认 1.0 Å） | 兼容 pymatgen（0.9 Å） |

原型（`run_sites.py --all-methods`）：fcc(211) 上 `layers` 只得台阶边一排、`window` 少台阶底；TiO2(110) 上两者都只得 O_br。`exposed` 的期望值以 M3 的金标为准（M3 原型：Pt(110) 含槽底原子，TiO2(110) 含 O3c，CeO2(111) 含 Ce 与下层 O）。

#### 3.2.3 遮挡剔除（D12、E14）

```text
d_nn = median{ t 在 G 中最短的一条边长 : t ∈ sub }（没有边时 2.5 Å）
对位点原子两两（面内最小像；二维网格，格宽 = site_occlusion·d_nn）：
    投影距离 < site_occlusion (0.3)·d_nn，且 h_b > h_a（相等时下标大者算低）→ a 被遮挡
被遮挡的原子从位点原子中去掉；W4 "Pt12, Pt40 are covered by atoms directly above them and do not define sites"
```

- `auto` 与 `exposed` 正常不会产生遮挡；`layers`/`window`/`indices` 选到投影重合的原子时（例如 ABCA 堆积的 fcc(111) 取 4 层，第 1 层与第 4 层重合），v1 的 1e-6 Å 判据只挡精确重合，
  稍有弛豫就生成"竖直堆叠原子之间的长桥"这类垃圾位点（D12），精确重合时自检又因 V 计错而失败（E14）。
- 被遮挡的原子**不**作 top 位点（其正上方就是另一个原子，放不了吸附物；E14 建议的"只作 top 位点并入同一类"不采纳，见文末）。
- 原型（`checks_occl.py`）：Cu(100) 6L 取 3 层、Pt(111) 4L 取 4 层、Ru(0001) 取 3 层，精确与 0.01 Å 面内噪声各一次：都剔除 4 个原子，剖分自检通过，没有跨堆叠原子的桥。

#### 3.2.4 输出

`site_atoms`：排好序的原子下标；`site_atoms_info`：`{method, cn: {t: CN}, cnRef: {el: CN}, covered: [...], occluded: [...], loose: [...], layer: {t: layer}}`（供界面 "Site atoms" 一行与 `Select site atoms` 使用）。
位点原子为 0（例如全部被排除）→ E5。

### 3.3 周期性二维 Delaunay

#### 3.3.1 准备点集

```text
A = [[a_i·e1, a_i·e2], [a_j·e1, a_j·e2]]                         # 面内二维晶格（行，框架坐标）
(u, v, M) = gauss_reduce_2d(A0, A1, angle="obtuse")              # M1 §3.11.1：det M = +1，恰为半数时向零；钝角约定对位点没有影响
B = [u; v]；Bc = M @ [X 系中的 a_i; a_j]（同一组矢量的三维形式）
对每个位点原子 t：把 X_t 平移整数个 Bc 使其 B-分数坐标落在 [0, 1)（eps 1e-9）→ base_t
spacing = sqrt(area(B) / n_site)；margin = site_tiling_margin (4.0) × spacing
mf = margin / heights(B)
points：先所有 base_t（home 副本，按原子下标），再按 (p, q) 字典序（p, q ∈ [−⌈mf⌉, ⌈mf⌉]，跳过 (0, 0)）追加 base_t + p·Bc0 + q·Bc1，只保留 B-分数坐标在 [−mf, 1 + mf]² 内的副本
x = X 的第一分量，y = 第二分量
```

边距规则让大胞只多出约 30% 的点（1 万原子 slab：1600 个位点原子 → 约 2300 点），小胞自动包含完整 3×3（或更多）平铺。

#### 3.3.2 Bowyer–Watson（规范实现，不变）

两种语言**逐行同构**（v1 原型 `delaunay.py`/`delaunay.mjs`，已验证输出逐个三角形相同）：

- 谓词：`orient(a,b,c) = (bx−ax)(cy−ay) − (by−ay)(cx−ax)`；`incircle(a,b,c,d)` 用以 d 为原点的 3×3 行列式（运算顺序固定）。严格判定：`orient < −1e-12` 才算在边外；`incircle > 1e-9` 才算在圆内。
  Python 用内置 float 标量运算（不用 numpy 向量化）；JS 不得使用 `Math.fround`、不得重排表达式。
- 超级三角形：`(midx − 20s, midy − 20s)`、`(midx + 20s, midy − 20s)`、`(midx, midy + 20s)`，`s = max(span, 1)`；结束时去掉含超级顶点的三角形。
- 插入顺序：蛇形网格序（格子边长 `site_order_cell` = 3.0 Å，按 `(gy, gx if gy 偶 else −gx, 原下标)` 排序）。
- 定位：从上一个新建三角形出发的可见性行走；步数超过 `4·T + 10` 报内部错误。
- 空腔：从包含点的三角形出发 BFS（栈，后进先出），邻居外接圆严格包含新点则入腔；边界边按腔内三角形的顺序收集；新三角形 `(a, b, p)`。
- 输入点两两投影距离 ≥ `site_occlusion·d_nn`（§3.2.3 已保证）；仍有距离 < `position_tolerance` 的点 → 内部错误（不应发生）。

复杂度：期望 O(N log N)；边距筛选后的 p(40×40) 顶层（2401 个点）JS 34 ms、Python 267 ms（工程审查实测）。

#### 3.3.3 合并、归属与自检

```text
cc[t] = 二维外接圆心与半径 R[t]
对每条恰有两个三角形 t1、t2 的边 e：
    |cc[t1] − cc[t2]| < site_merge_ratio (0.2) × max(R[t1], R[t2]) → union(t1, t2)，e 记为"内部对角线"
多边形 = 并查集的组（按最小三角形号排序）
归属（home）：点的 B-分数坐标 f 满足 −1e-9 ≤ f < 1 − 1e-9（两分量）
  top：home 副本的顶点；bridge：非对角线边，中点 home；hollow：多边形，二维中心（组内外接圆心的平均）home
自检：V − E + F == 0（V = 剖分顶点数，即遮挡剔除后的位点原子数；E = home 非对角线边数；F = home 多边形数）
      且 Σ(home 多边形面积) 与 |det B| 相对误差 < 1e-6
失败 → margin 加倍重试（最多 2 次）→ 仍失败报 E9
```

- 相对合并判据让轻微畸变（弛豫后的 CONTCAR、随机 0.05 Å 扰动）的正方形仍合并成 4 重空位；bcc(110) 相邻准三重空位的"圆心距/半径"为 0.667、(111) 面相邻的 fcc/hcp 两三角形为 **1.000**（v1 误写为 ≈ 2.0，D22），都远离 0.2。
- 共圆的六个顶点（石墨烯、表面空位）合并成 6 重空位；对角线消失，所以不会出现跨空位的长"桥"。

### 3.4 位点生成

```text
nn_t = median(该位点原子所有非对角线 Delaunay 边的三维长度)
bridge e = (u, v) 保留：|P_u − P_v| ≤ site_bridge_ratio (1.5) × min(nn_u, nn_v)
hollow 保留：所有边界边满足上面的长度条件；单个三角形（未合并）时中心必须严格在三角形内（orient > 1e-6，即锐角三角形）
top：point = base_t；bridge：point = (P_u + P_v)/2，axis = P_v − P_u，length = |P_v − P_u|
hollow：point = 组内各三角形**三维外接圆心**的平均；fold k = 不同顶点数
每个位点：ensemble = 顶点原子下标（升序），images = 每个顶点相对其存储坐标的整数像（面内两分量来自平铺与 Bc → cell 的换算，第 k 分量来自 §3.1 的 m）
```

**密堆微面三重位**（D7，仅 `method == "auto"` 且 `site_microfacets` 为真）：

```text
ex = surface_atoms(view(s, sub), side, probe=κ)（同 §3.2.2 的 exposed；遮挡剔除照做）
ex ⊆ auto → 跳过（致密面没有新原子，零额外开销）
对 ex 做 §3.3 的剖分；取其中未合并的单个三角形三重位，要求：三个顶点都是金属、两两在 G 中相连、近正三角形（最长边 ≤ site_regular_ratio (1.1) × 最短边）
与 auto 的任何位点横向（框架 x、y）距离 ≥ site_microfacet_dedupe (0.3 Å) 的加入：kind = hollow, fold = 3, microfacet = true
```

- 只补"金属、两两成键、近正"的三重位，就是 (111)/(0001) 型的密堆微面；化合物表面（顶点含非金属）、bcc(111)（top/2nd/3rd 三层原子组成的三角形边长 2.49/2.49/2.87 Å，不规则）都不会多出位点。
  横向 0.3 Å 去重：微面三重位与短桥在 fcc(110) 上横向只差 0.49 Å，0.5 Å 会误并（D7）。
- 原型（`m5run.py`）：Pt(110) 1×1 多出 `fcc (Pt3)` ×2、`hcp (Pt3)` ×2（2×2 胞为 ×8、×8），接近方向倾 35.3°（(111) 微面）；(111)、(100)、(211)、Fe(110)、Fe(100)、Ru(0001)、Fe/W(111)、SrTiO3、ZnO、NaCl、CeO2、MoS2、TiO2 的类表不变。

**位点 `position`** = `point + distance·normal`（`distance` 默认 2.0 Å，pymatgen 兼容）；**标记位置** = `point + site_marker_height (1.0 Å)·normal`；
**`height`** = `(point − 该面最外位点原子)·n_s`（≤ 0；台阶下部的位点为负值）；**`frac`** = `point` 在 `(a_i, a_j)` 上的分数坐标，包裹到 [0, 1)（eps 1e-9，≥ 1 − 1e-9 视为 0）。

### 3.5 接近方向（按类决定，D3、D11）

```text
每个位点先算候选方向与倾角：
  top    ：n_s（top_normal = "local" 时：m = −Σ_j unit(r_j − r_t)，j 为 t 在 G 中的邻居；倾角 = ∠(m, n_s)）
  bridge ：û = unit(P_v − P_u)；n_b = unit(n_s − (n_s·û)û)（取与 n_s 同侧）；倾角 = asin(|n_s·û|)
  hollow ：n_loc = 顶点的最小二乘平面法向（3×3 协方差的最小特征向量，与 n_s 同侧；JS 用 Jacobi）；倾角 = ∠(n_loc, n_s)
  "系综成键"：bridge 两原子在 G 中相连；hollow 所有边界边在 G 中相连（微面三重位为三条边）
分类（§3.7）完成后，对每个类：
  类内全部位点的系综成键，且类内平均倾角 > site_local_normal_min_tilt (5°)
    → 该类每个位点用各自的候选方向作 normal；否则 → 该类全部用 n_s（平整面上与 n_s 逐位相同）
```

- 等价分类用的指纹只用 `n_s`（Δh 沿 `n_s`），与接近方向无关，所以"先分类、后定方向"没有循环依赖，同一类的位点总用同一种规则。
- 原型（`checks_place.py`，O 的目标距离 2.02 Å）：Pt(211) 的 `bridge CN 7·9`、`CN 9·10` 倾 16.8°，`CN 7·10` 倾 35.3°：沿全局法向放置时 Pt–O 为 2.675/2.020、2.020/3.464 Å，
  按类方向放置时两根都是 2.020 Å；台面三重位倾 19.5°、台阶 4 重位倾 35.3°（4 × 2.02 Å）；TiO2(110) 的 `hollow (Ti2O2)` 顶点不成键 → 全局法向；
  0.05 Å 随机起伏的 Pt(111) 上所有类的平均倾角 < 5° → 全局法向（v1 的 2° 逐位点阈值会让 18 个空位中的 2 个改用局部法向）。

### 3.6 子类型与标签修饰

**fcc/hcp（K6，D2）**——只对 3 重空位（含微面三重位）：

```text
条件 C：三个顶点都是金属（METALS），两两在 G 中相连，且 max(L) ≤ site_regular_ratio (1.1)·min(L)
n_t = 三顶点平面的法向（与 n_s 同侧）；c = point；rsub = site_subsurface_ratio (0.3)·mean(L)
轴上原子 = 以 c 为中心、半径 3·max(L) + 2 Å 内的基底原子（含面内像，不含 c 向像，除去三个顶点）中，
           depth = −(r_j − c)·n_t > 0.3 Å 且到轴的距离 < rsub 的、depth 最小者（并列取下标小者）
C 成立：轴上原子存在且在 G 中与三个顶点都相连 → "hcp"；否则 → "fcc"
C 不成立：无子类型；记 below = 轴上原子的元素、belowDepth = depth（没有轴上原子时都为 null）
k ≥ 4 重空位：沿该类的接近方向同样求轴上原子，记 below、belowDepth
```

- 为什么不用"第二层/第三层"判 hcp（D2 的建议）：台阶面的三重位顶点分属不同层，层号与微面不对齐；"轴上原子与三顶点都成键"沿三角形自身法向判定，对 (211) 台面同样成立（原型 `fcc CN 7·9·9` 等）。
  加上条件 C 以后，bcc(111)（顶点间距 4.06 Å，不成键）、CeO2/MoS2/刚玉（顶点非金属）都不再得到 fcc/hcp。

**标签修饰**（依次进行；"同名"指同一面、标签字符串相同的类）：

1. **over X**（无子类型的空位）：把基础标签相同的类分组——组内各类的 `below`（含 null）不全相同时，组内有 `below` 的类加 ` over X`；单独一类时，`below` 不是顶点元素才加。
   例：CeO2 两类 `hollow (O3)` 的 below 为 Ce 与 O → `hollow (O3) over Ce`、`hollow (O3) over O`；MoS2 → `hollow (S3) over Mo` 与 `hollow (S3)`；SrTiO3 TiO2 终止 → `hollow (O4) over Sr`；
   Fe(110) 的准三重位（下方 2.03 Å、横向偏 0.51 Å 处有第二层 Fe，落在 rsub = 0.79 Å 内）只有一类、且 Fe 是顶点元素 → `hollow (Fe3)`。
2. **桥长**：同名的桥若长度（`q_1`）恰有两个值 → 前缀 `short `/`long `；超过两个值 → `bridge 2.77 Å`（`format_decimal(length, 2)`）。
   **深浅**：同名的空位若都有 `below` 且 `belowDepth`（`q_1`）恰有两个值 → 前缀 `shallow `/`deep `（bcc(111) 的 SH/DH，刚玉的两种 O3 空位）。
3. **配位数**：仍同名且各类的顶点 CN 元组（升序）不全相同 → 每类加 ` CN 7·9`（中点 U+00B7）。CN 是 §3.2.1 的键图配位数（1.15·Σr_cov，在 bcc 上含第二近邻：Fe 体相 14，文档写明，D23）。
4. **序号与上下文**：仍同名 → 按 §3.7 的类序加 ` #1`、` #2`…；这些类另给 `context`：
   - 有已有吸附物且 `fingerprint_adsorbates` 为真：到最近吸附物原子的面内最小像距离（`2.0 Å from CO #1`）；
   - 否则：到该面"最稀有的 top 类"（成员最少，并列取类序在前者；它本身不参与）的最近位点的距离（`2.2 Å from top (Ce)`），只在最稀有 top 类的成员数小于最多者时给出；
   - 有 `context` 的同名组按距离升序编 `#n`（并列按类序）。D15 的"CN 与多数不同的原子、空位中心"判据不够确定，改用这条可复现的规则（文末说明）。

底面的类用同样的标签，界面在分组标题注明 `Bottom`；API 用 `side` 字段区分（标签本身不含面名，保证顶面与底面等价位点同名）。

原型的完整标签表见 §7.3。

### 3.7 等价性：指纹、分类、顺序、标签、颜色（K8，E5）

**指纹**（每个位点）：以 `point` 为中心、半径 `site_fingerprint_radius` (5.0 Å) 内所有基底原子（排除的原子与吸附物除外；`fingerprint_adsorbates` 为真时包括吸附物；含面内周期像，**不含** c 方向周期像），
每个原子记 `(element, d, Δh, ρ)`：`d` 为距离，`Δh = (r_j − point)·n_s`（不是局部法向），`ρ = sqrt(d² − Δh²)`。按 `(element, d)` 排序。

**匹配**（`fp_equal(F1, F2, tol)`，不变）：

```text
one_way(A, B):                       # A 中每个"核心"条目都要在 B 里找到不同的匹配
  for (e, d, dh, rho) in A，跳过 d > R − 2·tol 的条目（边界带可选）
     在 B 中同元素、d' ∈ [d − tol, d + tol] 的窗口里找第一个未用的条目，且 |dh − dh'| ≤ tol、|rho − rho'| ≤ tol；找不到 → False
equal = one_way(F1, F2) and one_way(F2, F1)
```

**分类**（固定次序 + 精确预筛 + 上限）：

```text
okey(st) = (side, kind 序 top < bridge < hollow, fold, subtype 序 fcc < hcp < none, composition, −q_2(height), q_5(frac_b), q_5(frac_a))
按 okey 稳定排序后逐个处理位点 st：
  bucket = 已有的、(side, kind, fold, subtype, composition) 与 st 相同的类（按建立顺序）
  对 bucket 中每个类 c（代表 = 第一个成员）：
     预筛：|s1(st) − s1(c)| > 3·tol → 跳过（s1 = 指纹中最小的 3 个 d 之和；最近的 3 个条目不都在核心区 d ≤ R − 2·tol 内时不预筛，slab 上不会发生）
     fp_equal(c, st) → st 归入 c，停止
  都不匹配：类数 < site_max_classes (200) → 新建类；否则 st 并入 bucket 的第一个类，记 capped（W13）
```

- 次序键只用几何量，与原子下标无关，两种语言同一顺序；结果因此不随原子顺序变化（E5：v1 按生成顺序贪心，0.2 Å 容差下 6 种原子顺序有 5 种分组不同）。
- 预筛只排除不可能匹配的对：若 `fp_equal(A, B)`，A 最近的 3 个条目在 B 中有互不相同、d 差 ≤ tol 的匹配（反之亦然），所以 B 的第 m 小距离 ≤ A 的第 m 小 + tol，`|s1(A) − s1(B)| ≤ 3·tol`。
  实现可以改用更强的必要条件"最小的 6 个核心距离逐项差 ≤ tol"（同一论证），结果不变（原型 `checks_prefilter.py`）。v1 的"C > 200 时哈希预分桶"删除。
- 类数上限：超过 200 时剩余位点按基础标签归并（所以界面最多 200 + 基础标签数个类），W13 `"{n} sites are inequivalent at 0.10 Å; the list stops at 200 classes. Raise the equivalence tolerance to group them."`，
  Sites 块显示按钮 `Try 0.3 Å`。
- 原型（`checks_class.py`，0.05 Å 随机扰动）：Pt(111) p(3×3) 在 0.1/0.2/0.3 Å 下 41/5/4 类，p(6×6) 6L 在 0.1/0.2 Å 下 158/11 类；4 种随机原子顺序的分组全部相同；预筛与不预筛完全相同。
  类数依赖随机数流（v1 写的 52/15/6 是另一条流），所以扰动结构作为固定的 JSON 夹具存档（§7.1）。

**组成字符串**：元素按 Pauling 电负性升序（相同按符号字母序），计数大于 1 时写数字：`Pt3`、`TiO`、`Ti2O2`、`Na2Cl2`、`Ce3O3`。电负性用 JS `core/elements.js` 的 `PAULING`，F0-D 把 Python 侧对齐到同一张表并补全 JS 缺的 Pm、Rn、Am–Lr（§10）；
表里仍没有的元素按 5.0。

**类的顺序**（决定 `class` 下标）：

```text
(side: top < bottom, kind: top < bridge < hollow, fold 升序, subtype: fcc < hcp < none, composition 字典序,
 −max(height) 的 q_2, length 的 q_2（bridge；其余为 0）, cn 元组, 成员中最小的 (q_5(frac_b), q_5(frac_a)))
```

**位点顺序**：先按类序，再按 `(q_5(frac_b), q_5(frac_a))`，再按 ensemble 下标元组。`index` 即该顺序的位置。

**标签示例**：

| 情形 | 标签 |
|---|---|
| top | `top (Pt)`、`top (Ti)` |
| bridge | `bridge (Pt2)`、`short bridge (Pt2)`、`long bridge (ZnO)`、`bridge 2.70 Å (Pt2)` |
| 金属密堆三重位 | `fcc (Pt3)`、`hcp (Pt3)`、`fcc (CuPt2)` |

**颜色**（界面用，API 也返回 `color`）：top `#2F80ED`、bridge `#27AE60`、fcc `#F2994A`、hcp `#EB5757`、4 重 `#9B51E0`、6 重 `#00A3A3`、其他空位 `#A0522D`；

### 3.8 已占用、邻近吸附物、位点归属

**吸附物分组与结合原子**（本节与 §3.11、§3.12 共用）：

```text
组 = 相同 adsorbate_id > 0 的原子；没有 id 的吸附物（§3.1 的 ads，包括 loose）按 G_all（全部原子的键图）在 ads 内的连通块分组（与 M3 promote_adsorbates 同一规则）
结合原子 binding_atoms(g)：
  有记录且组的组成与记录（库模式或 definition）相同 → 记录的结合原子按"元素 + 同元素内的名次"对应到组内原子（组内同元素原子按下标排序；K10 的插入与稳定排序保持同元素次序）
  否则 → 组内到任意基底原子距离最小的原子（并列取沿 n_s 更低者，再取下标小者）
所在面：结合原子的 h（§3.1，顶面框架）≥ 基底高度中位数 → top，否则 bottom
```

**已占用**：

```text
对该面每个位点：若某组的某个结合原子 b 满足 横向距离（垂直于 site.normal）< site_occupied_radius (1.0 Å) 且 0 < (r_b − point)·normal < 3.5 Å
  → occupied = true，occupant = 该组 id（多个时取横向最近者）
nearestAdsorbate = {id, distance}：位点 position（point + 2.0 Å·normal 处的探针点）到最近吸附物原子的距离（含面内像）；没有吸附物时为 null
```

"Place on all" 与 "Fill" 跳过已占用位点（`skip_occupied`），并跳过会与已有吸附物产生 W2/W5 的位点（`skip_blocked`，§3.12.1）；单个 Place 到已占用位点时警告 W12 但照常放置。
`nearestAdsorbate` 只用于显示（tooltip `2.3 Å from CO #1`）；是否"阻塞"取决于要放的吸附物，在规划时精确计算（§3.12.1）。

**位点归属**（`assign_sites`，D21、EM8）：

```text
对每个组 g：b = binding_atoms(g) 的第一个；side = 所在面
  在该面的位点集合（只用基底，吸附物不参与）里取 b 的面内投影最近的位点（面内最小像；并列取位点序在前者）
  返回 {id, side, binding, site: index, label, class, lateral: 横向偏移 Å, height: (r_b − point)·normal, moved}
  moved：组有记录且记录的 site.point 与 b 当前位置的横向偏移 > site_moved_threshold (0.5 Å)，或最近位点的类标签与记录不同
```

Placed adsorbates 列表与 CLI `sites --assign` 用它显示 `CO #1 · now on hcp (Pt3) (placed on fcc, moved 1.6 Å)`；用户用 M4 的移动工具拖过吸附物之后，记录的 `site`、`height` 已不成立，列表照此标出（EM8），M4 不需要改动。

### 3.9 吸附物局部框架

**库约定**（`kind`；库坐标必须满足，校验到 1e-4 Å，v2 按 E15 修正）：

| kind | 约定 |
|---|---|
| `mono` | 结合原子 `binding[0]` 在原点；+z 指离表面（非结合原子的 z 可以为负，如 CH4 的三脚朝下） |
| `bi` | 两个结合原子在 `(−L/2, 0, 0)` 与 `(+L/2, 0, 0)` |
| `flat` | 所有结合原子 z = 0，质心在原点；只有一个结合原子时，它在原点、分子平面的法向为 +z |

**参考方向**：每个模式可给 `reference: [x, y, 0]`（单位矢量，默认 `[1, 0, 0]`）；放置时 `rotation = 0` 让它对准位点框架的 e1（§3.10.1）。v1 要求"第一个离轴原子在 xz 平面且 x > 0"，
而库里 4 个模式按设计就不满足（`CO2/flat` 只有一个结合原子；`H2O/flat` 的 H 在 xy 平面；`NH2`、`CH2` 的 H–X–H 平面 ⟂ x，以便在桥位上垂直于桥轴，E15、D16），v2 把参考方向写成显式字段。
CO2 的 `flat` 模式改为 `mono`（C 在原点，分子轴沿 x），物理吸附系数不变。

**自定义吸附物的自动框架**（`adsorbate_from_structure`，两种语言同一规则；v1 原型 `frames.py`，不变）：

```text
P = 选中原子坐标（周期结构中的选区先按最小像拼成一整块：以第一个原子为参照逐个取最近像）
B = binding（默认：在 slab 上取离基底最近的选中原子；否则取第一个原子）；others = 其余
kind = 用户指定，或 len(B)==1 → mono，2 → bi，≥3 → flat
mono：o = P[B0]；c = mean(P[others]) − o
   |c| > 0.1 → up = unit(c)
   否则（结合原子在中心，如 CO2 的 C、CH4 的 C）：
       线形（协方差特征值升序，前两个都 < 1e-3 Å²）→ up ⟂ 分子轴（与分子轴最不平行的笛卡尔轴正交化）
       平面形（最小特征值 < 1e-3）→ up = 平面法向，符号使 (P[others0] − o) × (P[others1] − o) · up > 0
       否则 → up = unit(P[others0] − o)
   x = 第一个横向分量 > 1e-3 Å 的非结合原子方向（投影到 ⟂ up）；都没有 → 与 up 最不平行的笛卡尔轴正交化
bi：o = (P[B0] + P[B1])/2；x = unit(P[B1] − P[B0])；c = mean(P[others]) − o 去掉 x 分量
   |c| > 0.1 → up = unit(c)；否则平面形 → 平面法向（符号同上）；否则 → 与 x 最不平行的笛卡尔轴正交化
flat：o = mean(P[B])；up = P[B] 协方差的最小特征向量；有离开平面 > 0.1 Å 的非结合原子时使其平均在 +up 侧，否则按 (P[B1]−P[B0]) × (P[B2]−P[B0])；x = P[B0] − o 的面内方向
R = [x, y = up × x, up]（行）；local = (P − o) @ Rᵀ；reference = [1, 0, 0]
```

**保持现有取向**（`keep_orientation=True`）：框架 = 表面框架 (e1, e2, n_s)，原点 = 结合原子；`rotation = 0` 即保持原取向。选区在 slab 上时界面默认开；
Python/JS 的 `place_adsorbate`/`add_adsorbate` 收到 `Structure` 时**默认开**（ASE `add_adsorbate(..., mol_index=)` 的语义：分子不转动，结合原子放到位点，D19）；自动框架只在界面的 "From structure…" 默认使用。

### 3.10 放置

#### 3.10.1 位点框架与取向

```text
n_p = site.normal（§3.5，按类）
e1 = 参考方向投影到 ⟂ n_p：bridge 为桥轴 P_v − P_u（使 e1·â ≥ 0，≈0 时使 e1·b̂ ≥ 0；â、b̂ 为面内两轴的单位矢量）；top、hollow 为 a_i
e1 = unit(e1 − (e1·n_p) n_p)；e2 = n_p × e1
Q = local @ Rz(−φ_ref)ᵀ @ Ry(tilt)ᵀ @ Rz(rotation)ᵀ          # φ_ref = 模式 reference 的方位角；先把 reference 转到 +x，再把 +z 向 +x 倾斜，最后绕 z 转 φ
w_a = Q_a.x·e1 + Q_a.y·e2（横向）；s_a = Q_a.z（相对锚点沿 n_p 的高度）；锚点 = 局部原点
```

锚点横向位置 = 位点 `point` 在 ⟂ n_p 平面上的位置；按坐标放置（P1 的 x、y 或分数）时，锚点横向位置为该坐标，`n_p = n_s`，高度参考取该处最近的位点原子集合。

#### 3.10.2 有效半径（D9）

```text
env(j)（基底原子 j）：j 是非金属 → covalent；j 是金属且在 G 中至少与一个非金属（ANIONS 且不在 METALS）相连 → cation；否则 → metal
r_eff(el, env)，对每个出现的 (元素, 环境) 只算一次：
  metal   ：½·median{ d(j, x) : el_j = el, env(j) = metal, x 为 j 在 G 中的金属邻居 }
  cation  ：median{ d(j, x) − r_cov(x) : el_j = el, env(j) = cation, x 为 j 在 G 中的非金属邻居 }
  covalent：r_cov(el)
  没有可用的边，或 |r_eff − r_cov(el)| > 0.5 Å → r_cov(el)
```

- 金属半径跟随 slab 自身（应变、合金、晶格常数误差都自动反映），不需要数据表；只在基底子图上统计，吸附物不影响它。
- 原型（`checks_place.py`）：Pt 1.386（Cordero 1.36，+0.026）、Cu 1.278（−0.042）、Ag 1.446（−0.004）、Au 1.442（+0.082）、Ni 1.246、Pd 1.375、Rh 1.345（−0.075）、Ru 1.353（−0.107）、
  Fe 1.243（−0.077）、W 1.370（−0.250）、Mo 1.363（−0.177）；阳离子 Ti（TiO2）1.288（Cordero 1.60）、Ru（RuO2）1.323。

#### 3.10.3 目标距离

```text
T(a, j)（a 为吸附物原子，j 为基底原子，含面内像，不含 c 向像，不含其他吸附物与 exclude）：
  a 不是结合原子 → clash·(r_cov(a) + r_eff(j))，clash = adsorbate_clash_factor (0.75)
  a 是结合原子：
    bond 模式且 j 是位点系综原子（含其像）→ 用户的 bond_length（用户明确要求的键优先于下一条）
    a 与 j 都在 ELECTRONEG = {N, O, F, S, Cl, Se, Br, I} 中，且不是"top 位并且 j 就是该位点原子"
        → adsorbate_nonbonded_factor (0.8)·(R_B(a) + R_B(j))，这一对记为"非键"（D10）
    bond 模式（j 不是系综原子）→ 用户的 bond_length
    env(j) = cation 且模式的 pairBondLengths 有 el(j) → 该绝对值（T13 填写，§4.1）
    否则 → f·(r_cov(a) + r_eff(j))，f 按 §4.1 的 bondFactor 查：
        env(j) = covalent → bondFactor.covalent ?? 1.0         # 非金属基底：共价半径之和就是键长（O_br 上的 H：0.97 Å）
        env(j) = cation   → bondFactor.cation ?? 按位点类型的值
        env(j) = metal    → 按位点类型的值（top / bridge / hollow；4 重以上用 hollow）
        用户 bond_factor 覆盖 metal 与 cation 两种环境的值
```

非键下限的例外（该原子自身的 top 位）保留"在 O 上加 O 成过氧、在 S 上加 S 成二硫"这类有意的构型。原型（`checks_place.py`）：O 放 TiO2(110) 的 `bridge (O2)`、`hollow (Ti2O2)` 时 O–O 从 1.78、1.61 Å 变为 2.43 Å；
前者此时离最近的 Ti 超过 3 Å，W3 报"没成键"（这本来就不是 O 的合理位点）。

#### 3.10.4 接触抬升与三种高度模式

```text
auto 与 bond：
  H = −∞
  for 吸附物原子 a，for j（与锚点横向距离 < R_q = max_a |w_a| + 3.5 + 3.0 Å，二维网格查询）：
     D = T(a, j)；ρ² = |横向(r_j) − (锚点横向 + w_a)|²（垂直于 n_p）
     ρ² < D² → H = max(H, h_j + sqrt(D² − ρ²) − s_a)          # h_j = r_j·n_p（框架坐标）
  只抬不压：c 方向周期像与其他吸附物不参与抬升（它们在吸附物上方时会把它错误地抬过对方），只在 §3.11 的冲突检查中出现
  H = −∞（没有任何约束）→ H = point·n_p + adsorbate_fallback_height (1.0 Å)，W6
  取得最大值的约束来自非结合原子 → W7 "lifted so that H3 does not clash with Pt12"
  bond 模式下没有任何结合原子约束成立（所有 ρ ≥ bond_length）→ E12
height：H = point·n_p + h；不抬升，只做冲突检查
```

#### 3.10.5 最终坐标

`r_a = 锚点横向 + w_a + (H + s_a)·n_p`（框架坐标）→ 换回笛卡尔 `X @ F`；整块吸附物再平移一个面内晶格矢量，使锚点的面内分数坐标落在 [0, 1)（分子保持完整，不逐原子包裹；第 k 轴不包裹）。
`height` 字段 = `(锚点 − point)·n_p`。

**解析检查**（测试用）：单原子在完全平整、各顶点等高的 k 重空位上 `H − point·n = sqrt(D² − ρ²)`，ρ 为圆心到顶点距离。Pt(111)（a = 3.92 Å，r_eff 1.3859 Å）：O fcc D = 2.0459、ρ = 1.6004 → 1.2747 Å；
CO top D = 0.86·2.1459 = 1.8455 Å；Cu(100)（a = 3.615，r_eff 1.2781）O hollow D = 1.9381、ρ = 1.8075 → 0.6994 Å（T1 的测试用这些式子现算，不抄数字）。

### 3.11 冲突检查

放置后，对每个新原子 a 与所有已有原子 j（基底、其他吸附物、同一批之前放的吸附物；含面内与 c 方向周期像）：

| 规则 | 条件 | 警告文案（`warnings[]`） |
|---|---|---|
| W1 与 slab 碰撞 | j 属于基底且 `d < 0.75·(r_cov(a) + r_eff(j))`；"预期的键"（结合原子与有成键目标的 j）只在 `d < 0.5·(r_cov(a) + r_eff(j))` 时报 | `"{A}{i} is {d} Å from {X}{j} (clash below {t} Å)"` |
| W2 与吸附物成键 | j 属于另一个吸附物且 `d < bond_scale·(r_cov(a) + r_cov(j))`（M3 的成键判据） | `"{A}{i} is {d} Å from {X}{j} of {name} #{k} (they would be bonded below {t} Å)"` |
| W5 与吸附物非键近接触（新） | j 属于另一个吸附物、不满足 W2，且 `d < adsorbate_contact_factor (0.8)·(R_B(a) + R_B(j))`；氢键对（一方是 H、另一方是 N/O/F/Cl）的阈值改为 `adsorbate_hbond_min` = 1.5 Å | `"{A}{i} is {d} Å from {X}{j} of {name} #{k} (closer than {t} Å)"` |
| W3 结合原子没成键（改） | 对所有有成键目标（非"非键"对）的基底原子 j，`min_j d_j / T(a, j) > adsorbate_unbonded_ratio (1.3)` | `"{A}{i} is not bonded to the surface (nearest {X}{j} at {d} Å)"`，j 取比值最小者 |

- 数字一律 `format_decimal(x, 2)`；原子编号 1 起；`{A}{i}` 在吸附物内编号，`{X}{j}` 用结构中的全局编号。每次放置最多保留 `adsorbate_max_warnings` (10) 条，超出时最后一条为 `"… and 7 more"`。
- 原型（`checks_place.py`）：Pt(111) p(3×3) 的 top 位有 CO 时，把 O 放到 9 个 fcc 位：v1 的 W2 为 0 条，W5 在 3 个放置上报出 O···C 1.71 Å 与 O···O 2.36 Å；Pt(111) p(2×2) 12 个桥位都放 CO → 48 条 W2（相邻桥位 C–C 1.39 Å，v1 原型）。
- 氢键放宽避免 OH/H2O 网络里 1.6–1.9 Å 的正常氢键被误报（D4）。

#### 3.12.2 填到目标覆盖度（P12）

### 3.13 上下表面对称操作 `find_top_bottom_operation`（M5 实现；M2 本期不提供，K11）

```text
find_top_bottom_operation(structure, tolerance=0.1, *, include_adsorbates=False) → {rotation, translation, kind} | None
  在 §3.1 的顶面框架中工作（基底原子；include_adsorbates 时全部原子）
  A2 = 面内二维晶格（框架 x、y，Gauss 约化后）；G = A2 A2ᵀ
  ops2 = {M ∈ {−1,0,1}^{2×2} : |det M| = 1, ‖M G Mᵀ − G‖∞ < 1e-6·max(1, ‖G‖∞)}   # ≤ 12 个；次序：−I、I、其余按字典序
  layer = cluster_heights(h)；top = 最外层，bottom = 最内层
  ref = top 中"在全部基底里数目最少的元素"（并列按符号）里下标最小的原子
  for M in ops2：L = A2⁻¹ M A2（框架平面内的行向量映射 v' = v L）；R_f = [[L, 0], [0, −1]]（沿 n 取反）
      for j in bottom 中与 ref 同元素的原子（按下标）：t_f = X_j − X_ref @ R_f
          对每个基底原子 i：X_i @ R_f + t_f（面内包裹）在 tolerance 内有同元素原子（框架坐标的二维网格 + 高度分箱），第一个失配即放弃这个 j
          全部匹配 → R = Fᵀ R_f F，t = t_f @ F（换回笛卡尔，行向量约定 r' = r @ R + t）；返回
  kind = "inversion"（L = −I）| "mirror"（L = I）| "rotation"（其他）
```

- 在表面坐标系里求解，法向不在 z 上的导入 slab 同样成立；吸附物不参与，顶面已有 CO 不再让 Both sides 失效（E6、D8）。
- 结果按"基底摘要"缓存（§5.10），界面的 Both sides 可用状态直接读缓存。
- 原型（`checks_tb.py`）：Pt(111) 4L、绕 x 转 90°、顶面有 CO（只用基底）、SrTiO3 TiO2 7L、TiO2(110)、CeO2(111) → inversion；MoS2 → mirror；SrTiO3 6L → None；
  同一个顶面有 CO 的 slab 若用全部原子（v1 的行为）→ None。Pt(111) p(40×40) 6L（9600 原子）1.8 s（Python 原型逐原子循环；实现应向量化，预算 §7.5）。

### 3.14 覆盖度（K12，D5、E7）

#### 3.14.1 θ 的定义

```text
θ(side, per) = N_ads(side) / N_den(per)
  N_ads(side) = 该面的吸附物组数（§3.8 的所在面）
  per = "cell"（默认）：N_den = 当前晶胞含有的 1×1 表面胞数 N_cells（§3.14.2）
  per = "site-atom"   ：N_den = 当前方法得到的该面位点原子数
  per = 元素 X        ：N_den = 该面最外两层（§3.2.1 的 layer 0、1）与位点原子中 X 的原子数（CeO2 的 "per Ce" 因此可选）
单位显示 ML；记录与返回值注明所用定义
```

- 对单质密堆面三者相同；对化合物不同：TiO2(110) 1×1 有 2 个位点原子（O_br、Ti5c），"每个桥氧一个 H"按 1×1 胞是 1.00 ML、按位点原子是 0.50；SrTiO3 TiO2 终止每胞一个吸附物按 1×1 胞是 1.00 ML、按位点原子 0.33（D5）。
- 界面同时显示两种：`θ = 1.00 ML (per 1×1 cell) · 0.50 per site atom`。
- `side = "both"` 时两面分别计算、分别显示；Fill 只作用于所选的面（EM7）。

#### 3.14.2 1×1 表面胞

```text
来源依次为：
  1. user：API 的 cells=n（界面 Coverage › "1×1 cells" 数值框）——用户明确知道时
  2. info：info.surface.kind == "cleave"（M2 生成）：S = info.supercellMatrix 在 (i, j) 上的 2×2 块（不存在时 = I）；
           S 必须是"面内形式"（S 的 k 行、k 列除对角元外为 0，且 |S_kk| = 1），否则跳到 3
           N_cells = |det S|；1×1 网格 A1 = S⁻¹ · [a_i; a_j]（M2.md §4.2 与 M4 §3.10.4 同一规则）
  3. translations：M1 find_translations(view(s, sub), tolerance=coverage_translation_tolerance (0.3 Å，且 < h_min/4), axes=(i, j))
           N_cells = 平移群的阶；A1 = M1 primitive_cell(view(s, sub), axes=(i, j)) 结果晶胞的 i、j 两行（只在要列 1/n 超胞时才算）
  4. none：per = "cell" 不可用，退回 "site-atom"，I2 "The 1×1 cell could not be determined; coverage is per site atom."
θ 的显示注明来源：(per 1×1 cell, from the cleave record) / (… from in-plane translations) / (… as entered)
```

- 只认 M2 写的 `kind == "cleave"`：其他来源的 `info.supercellMatrix`（例如体相先做了 M1 超胞）是相对体相母胞的，不能当成 1×1 表面网格。
- 平移搜索在基底上做（吸附物不破坏平移对称）；容差取 0.3 Å 是为了弛豫过的 CONTCAR（吸附物下方的 Pt 起伏 0.1–0.2 Å）；平移群只有恒等元时，当前晶胞就被当作 1×1 胞——
  对弛豫后对称性被明显打破的结构这可能不对，界面在来源为 translations 且阶为 1、位点原子数 > 1 时提示 `Is this the 1×1 cell? Enter the number of 1×1 cells if not.`

#### 3.14.3 1/n 覆盖度的超胞建议（P13）

```text
coverage_supercells(slab, n, *, max_results=6)：
  需要 A1（§3.14.2 的来源 info 或 translations；来源 user 只给胞数、没有网格 → E23）
  候选 = M1 hnf_matrices_2d(n)（全部 [[i, j], [0, n/i]]，按 (i, j) 升序）
```

### 3.15 复杂度

| 步骤 | 复杂度 | 说明 |
|---|---|---|
| 吸附物识别、基底视图 | O(N + M) | M3 键图（CSR、周期格子）；视图 O(N) |
| 法向与切口 | O(N log N) | F0-A `surface_normal`（三轴排序，1 万原子约 3 ms JS） |
| 配位数、有效半径 | O(N·k) | 共用键图 |
| 遮挡剔除 | O(n_site·k) | 二维网格 |
| Delaunay | 期望 O(M log M)，M ≈ 1.3·n_site | 蛇形插入 + 行走定位；微面三重位只在 `exposed ⊄ auto` 时多做一次 |
| 指纹 | O(S·k_R)，S ≈ 6·n_site，k_R ≈ 30–60 | 三维网格（边长 = 指纹半径） |
| 分类 | O(S·w·k_R)，w 为预筛窗口内的代表数 | 类数上限 200 → 最坏 O(200·S·k_R) |
| 放置一次 | O(n_ads·k) | 横向圆柱查询 |
| 所有等价位点 / 填充 | O(n_cand·n_ads·k) / O(need·n_cand) | n_cand 为候选位点数 |
| 上下对称操作 | O(n_ops·n_bottom·N) 最坏，通常一次完整核对 | 第一个失配即剪枝；n_ops ≤ 12，n_bottom 为底层同元素原子数 |
| 1×1 胞（translations） | M1 §3.12（阶数预筛后 1 万原子 0.1 s 量级） | 按基底摘要缓存 |

`cation` 键按 TiO2、RuO2 的量级给出（§3.10.6）。T13 在至少 5 种金属（Pt、Ru、Cu、Ag、Fe 或 W）与 2 种氧化物（TiO2、RuO2 或 CeO2）的参考键长上校准，误差目标：金属 ≤ 0.1 Å，阳离子位 ≤ 0.15 Å；
校准不了的（RuO2 上的 CO）用 `pairBondLengths` 并在 R3 写明。生成的结构是弛豫的起点，用户可以改键长或高度。

**校验**（`test_adsorbate_library`，Python 与 JS 各一份，读同一文件）：

1. schema、顶层字段、类别引用、id 与别名唯一（大小写不敏感）；
2. 每个条目恰好一个默认模式；`positions` 形状 N×3；`binding` 下标合法；`reference` 为 xy 平面内的单位矢量（1e-6）；`initialMagmoms` 长度为 N；
3. 框架约定（§3.9 表）到 1e-4 Å；
4. 同一条目各模式的内部距离矩阵一致到 2e-3 Å（模式表里标为几何不同的除外：CO2 的 bent）；
5. `geometry` 中每个键长、键角与坐标一致（键长 2e-3 Å，键角 0.2°）；
6. 任意两原子距离 ≥ 0.7 Å；
7. `bondFactor` 的键只能是 `top`/`bridge`/`hollow`/`default`/`cation`/`covalent`，值在 (0, 3]；`pairBondLengths` 的每一项在 `source` 中出现该元素；
8. 文件被 `JSON.parse` 与 `json.loads` 读出相同的对象（Python `json.dumps(sort_keys=True)` 与 JS 规范化后的 `JSON.stringify` 比较）。

### 4.2 加载（共用数据模块：规格在此定稿，实现归 F0-D 第 0 波，K1、E9）

Python `crystallume/core/webdata.py`：

```python
import copy, json, re
from functools import lru_cache
from importlib import resources

_NAME = re.compile(r"^[a-z0-9_]+\.json$")

@lru_cache(maxsize=None)
def _load(name: str):
    if not _NAME.match(name):
        raise ValueError(f"invalid data file name {name!r}")
    text = resources.files("crystallume").joinpath("web", "data", name).read_text(encoding="utf-8")
    return json.loads(text)

def load_web_data(name: str):
    """Parsed crystallume/web/data/<name> (cached); returns a deep copy so callers cannot change the cache."""
    return copy.deepcopy(_load(name))
```

JavaScript `crystallume/web/js/core/webdata.js`：

```js
const BASE = new URL('../../data/', import.meta.url);
const NAME = /^[a-z0-9_]+\.json$/;
const pending = new Map(), loaded = new Map();
export function loadWebData(name) {
  if (!NAME.test(name)) return Promise.reject(new Error(`Invalid data file name "${name}"`));
  if (!pending.has(name)) pending.set(name, (async () => {
    const u = new URL(name, BASE);
    const text = u.protocol === 'file:'
      ? await (await import('node:fs/promises')).readFile(u, 'utf8')            // Node 测试
      : await (async () => { const r = await fetch(u, { cache: 'no-cache' });
          if (!r.ok) throw new Error(`HTTP ${r.status}`); return r.text(); })();
    const value = JSON.parse(text);
    loaded.set(name, value);
    return value;
  })().catch((e) => { pending.delete(name); throw new Error(`Could not load ${name}: ${e.message}`); }));
  return pending.get(name);
}
export const webData = (name) => loaded.get(name) ?? null;                     // 同步读取，未加载时为 null
export function setWebData(name, value) { loaded.set(name, value); pending.set(name, Promise.resolve(value)); } // 测试、插件
```

- **归属**：这个模块是第 0 波的地基（M2 第 1 波的 `oxidation_states.json` 要用它），所以由 F0-D 实现（§10，任务 F0-D-W，规模 S）；本模块只交付 `adsorbates.json` 与它的校验、加载包装。
  F0-D v2 已把 Bondi 半径并入元素数据（K16），M6 不再需要 `bondi_radii.json`，v1 的"M6 也用它"删除。
- 吸附物库在其上包一层：Python `adsorbate_library()` = `_validate_library(load_web_data("adsorbates.json"))`（校验失败抛 `RuntimeError`）；JS `loadAdsorbateLibrary()` = `loadWebData('adsorbates.json').then(validateLibrary)`、
  `adsorbateLibrary()` = 已校验的缓存或 null、`setAdsorbateLibrary(lib)` 用于测试与插件（同样经过校验，失败时抛出带字段路径的错误：`adsorbates[3].modes[0].binding: index 4 is out of range`）。
- 包数据已包含 `web/**/*`（`pyproject.toml:57-58`），无需改打包配置；服务器整目录提供前端（`server/app.py` `FrontendApp`，`no-cache` + ETag），静态构建 `scripts/build_artifact.py` 也整目录复制。

- **删除吸附物**：`keep` = adsorbate_id 不在 `ids` 中的原子 → `s._remap(keep)`；删除对应记录；`mark_edited(s, "atoms")`；改名。

- **部分删除**（EM6）：用户用通用 Delete 删掉吸附物的一部分原子时，剩下的原子保留原 id；记录保留；列表按实际原子显示化学式，组成与记录不同时注明 `(edited)`；名称后缀按实际原子（§4.5）；
  所有原子都没了的记录（孤儿）在下一次 M5 编辑时删除。
- **合并、粘贴（M4）**：M4 v2 已按"完整的源吸附物 g → g + max(目标 id)、不完整的 → 0"重编号并复制记录；复制来的记录 `site = null`、`bonds = []`，本模块的列表与重算接受这种记录。
  v1 记录里的 `firstAtom` 已删除（按块插入后它没有意义），M4 复制时也不再写它（§10）。
- **面内超胞（M1）**：M1 已按像重编号（v + q·V）；请 M1 同时复制记录（id 同样变换，`site.point` 加上该像的平移，`frac` 按新晶胞重算；§10）。

### 4.6 多帧、部分占位、派生信息

- 多帧（C11）：网页 `editActive(..., {singleFrame: true})`（F0-A A1）只保留当前帧并给出带 Undo 的 toast `Kept frame k of N and dropped the others.`；

### 5.3 位点标记与 Pick site 工具（F0-A v2 契约，K14、E4）

- **形状按类型**（色盲友好）：top = 球（半径 0.28 Å）；bridge = 沿桥轴的短棒（长 0.7 Å、半径 0.10 Å）；hollow = 在位点平面内的正 k 边形薄片（外接圆半径 0.32 Å，k = fold，k > 6 时画圆）；颜色按类（§3.7）。
- **位置**：`point + site_marker_height·normal`，由 F0-A 的 `drawnCopies(points, model, {repeat: true})` 按显示包裹（含 U1 切口）与显示超胞复制，`index` 数组把画出的副本映射回位点下标。底面标记画在 −n 一侧。
- **实现**：自定义 B 层叠加层 `viewer.overlays.add({id: 'adsorption-sites', owner: 'm5-sites', tier: 'top', export: 'marker', pickable: true, pickIn: ['site-pick'], pick, onModel, beforeRender})`，
  每个类一个 `InstancedMesh`（`render/sitemarkers.js`）；先用 F0-A 的 `markerLayer` 交付球形版本，再换成形状版本。
- **Select 工具下**：标记只显示、**不可拾取**——点击表面原子照常选原子（F0-A A-D8/D11）；位点经类列表加 ◀▶ 选择。
- **Pick site 工具**（`render/tools/sitepick.js`，`tools.register({id: 'site-pick', title: 'Pick adsorption site', icon: 'target', toolbar: false, selects: false, cursor: 'crosshair', touch: 'claim', when, whyNot, hint, mouse, handler})`，
  handler 是工厂函数 `(app, viewer, opts) → {claims: () => false, hover, click, cancel, keydown}`）：Placement 块的 `Pick site` 开关或命令 `tool.sitePick` 进入；
  悬停标记 → 幽灵 + 提示（C 层 DOM：`fcc (Pt3) · site 2 of 4 · C–Pt 2.10 Å for CO`）；**单击 = 选位点**（`click` 返回 true）；Shift+单击 = 加入/移出多选位点集（Place 时每个位点各放一个）；
  **双击 = 直接放置**（`overlaydblclick`，一步撤销）；右键 = 标记菜单（`overlaycontext`：`Place CO here`、`Select site atoms`、`Copy site position`）；触屏轻触 = 选位点、双击 = 放置、长按为可选（F0-A C2）；
  Esc 回到 Select。按 F0-A §3.13.4 的契约，单击不放置（v1 的"单击即放"与 F0-A 冲突）。
- **状态**：悬停 ×1.5；选中位点加白色描边环；已占用位点 40% 不透明度；隐藏的类不画。
- **何时显示**：Adsorbates 分区展开且有结果时；面板关闭或切换结构时隐藏（结果按结构缓存，§5.10）。命令 `sites.toggle`（Shift+S，M3 已让出）在面板关闭时单独开关。
- **导出**：`export: 'marker'`：PNG 默认不含，导出菜单勾选 "Include markers (sites, fixed atoms)"（偏好 `exportMarkers`）时包含；缩略图与 glTF 永不含。
- **性能**：拾取对**画出的副本**做解析射线–球求交；副本总数 > 100 000（如 1 万个位点在 3×3 显示超胞里）时只拾取 (0, 0) 像的副本（E22-6）。

### 5.4 Adsorbate 块

- **搜索框**：placeholder `Search adsorbates (CO, OH, formate…)`，匹配 id、formula、name、aliases、tags（不区分大小写，空格分词取交集）；结果按类别顺序再按库顺序；Enter 选中第一项。
- **类别 chips**：`All` `Atoms` `Molecules` `O/H` `N` `C1` `C2` `Hydrocarbons` `S` `Mine`；单选；记忆在面板状态。
- **列表项**：`CO  Carbon monoxide`，次要文字为默认模式标签；键盘上下移动、Enter 选中。
- **Element…**：出现元素输入框（现有 `elementInput`），任何元素都可作为单原子吸附物；`Binding` 隐藏。
- **Use selection**：用选区创建自定义吸附物（L7）；出现 `Binding atom` 下拉（`1 · C`、`2 · O`…）、`Pick in view` 按钮（下一次点击原子即设为结合原子，Esc 取消）、
  `Keep current orientation` 开关（选区在 slab 上时默认开）、`Save to my adsorbates…`（名称输入用 `promptDialog`）。
- **From structure…**：菜单列出项目中其他结构（名称 + 化学式 + 原子数；> 200 原子的条目禁用并提示 `Too large for an adsorbate (max 200 atoms)`）；默认用自动框架。
- **Mine**：导入 JSON 时按 schema 校验（失败：`This file is not a Crystallume adsorbate list: <field path>: <reason>`），超过 50 条或单条超过 200 原子时拒绝并说明；名称一律按纯文本渲染（`textContent`），不解释 HTML（EM5）。
- **Binding**（模式）下拉：模式标签；下方提示 `Usually on top, bridge or hollow sites`（来自 `sites`）与条目的 `note`。
- 库加载失败时整块显示错误一行 + `Retry`，`Element…` 与 `Use selection` 仍可用。

**幽灵预览（不开会话，K14）**：吸附物按当前参数放在悬停的标记上（Pick site 工具下），否则放在选中的位点（可多个）上；用 F0-A 的 `ghostLayer({id: 'm5-ghost', structure, opacity: 0.45})`，
`ghost` 是只含新原子、带 slab 晶胞与 pbc 的结构；参数改变、悬停改变时在下一帧更新（只重算这些吸附物，单个 ≤ 2 ms）；Both sides 打开时幽灵同时含镜像。

预览不进历史、不标记未保存（P3）。

### 5.6 Coverage 块与 Placed adsorbates 列表

- `θ = 0.25 ML (per 1×1 cell) · 0.25 per site atom`；下拉 `per 1×1 cell` / `per site atom` / `per Pt` / `per O`…（列出该面最外两层的元素）。Both 时两行（Top、Bottom）。
- `1×1 cells`：数值框，显示 §3.14.2 得到的胞数，来源写在 tip（`From the cleave record`、`From in-plane translations`）；用户改它即来源 user；来源为 translations 且胞数为 1、位点原子数 > 1 时旁边显示 `Is this the 1×1 cell?`。
- `Fill to θ`（0.01–1 ML，步长 0.01）、`Min. separation`（0–20 Å）、`Fill`：用当前吸附物、当前模式和**选中位点的类**；没有选中类时禁用（tip `Choose a site class first.`）。
- `Cells for 1/n coverage`：n（2–16）→ 最多 6 行 `(√3×√3)R30° · 4.80 Å apart [Apply]`；`applicable` 为假的行灰显，`Apply` 禁用，tip 为 `why`；Apply 调用 M1 的原位超胞（一个撤销步 `Make (√3×√3)R30° supercell`），
  然后自动重算位点；已有吸附物时 Apply 前确认（`confirmDialog`："The adsorbates will be repeated too."）。1×1 胞未知时整行显示 E23 的界面文案。
- Placed adsorbates：每行 `CO #1 · fcc (Pt3) · top`（`#k` 为 adsorbate_id），按钮 `Select`、`Remove`；位点归属（§3.8）显示 `now on hcp (Pt3) (placed on fcc, moved 1.6 Å)`；组成与记录不同时 `(edited)`；
  没有记录的组按化学式显示为 `CO #3`（custom，M4 的请求）；悬停行在视图里高亮该吸附物（F0-A `setHighlight('adsorbate-hover', …)`）。底部 `Select all`、`Remove all`（确认）、`Mark selection as adsorbate`。

M4 的移动工具吸附目标：`crystallume.tools.get('move').registerSnapTargets((structure) → [{position, label}])`（M4 v2 的名字，E18）：注册当前位点结果的 `position` 与类标签，拖动吸附物时可吸附到位点。

### 5.9 触屏、无障碍、错误提示

- 触屏：Pick site 工具下轻触标记 = 选位点；双击 = 放置；长按为可选（F0-A C2），所有标记菜单项都能经类列表的 `⋯` 与 Placement 块的 `⋯` 完成。没有悬停，幽灵只跟随选中位点。
- 无障碍：类列表 `role=listbox`，每项 `aria-label="fcc (Pt3), 4 sites"`；◀▶ 有 `aria-label="Previous site"`/`"Next site"`；选中位点、计算出的高度、放置结果写进 `role=status` 的提示行（礼貌播报）；
  所有数值框有 `aria-label`；标记本身不可聚焦，但每个功能都可通过面板完成（选类 → ◀▶ → Place）。
- 错误：面板内 `p.err-text role=alert` 显示 §3.16 的界面文案；命令执行失败用错误 toast。

### 5.10 应用状态、缓存与失效（E12、EM1）

- **缓存**：`app.surfaceSites`：`WeakMap<Structure, LRU(4) of {key, params, result}>`。`key` = **基底摘要**（基底原子的下标、符号、当前帧坐标，以及晶胞、pbc）+ 解析后的参数哈希；
  吸附物的增删不改变基底摘要（K14 插入不移动基底原子的下标时），所以放置后结果保留，只重算 `occupied`、`nearestAdsorbate`、`context` 与 Coverage（O(位点数)）。
- **M5 自己的编辑**：用 `EditResult.map` 重映射位点结果的 `ensemble` 与基底摘要中的下标（例如 SrTiO3 上放 Ti 使 O 的下标后移），不重算。
- **其他编辑**（删原子、移动、改晶胞、换帧、撤销/重做恢复出不同的结构）：基底摘要变了即失效——≤ 3000 原子自动重算；更大时标记为过时（列表变灰、按钮 `Refresh`、标记隐藏）。撤销一次放置得到的结构与放置前的基底摘要相同，直接复用缓存。
- **选中的位点**：结果保留时按下标保留；失效时清空，Placement 块回到 `Choose a site…`。
- **上下对称操作、1×1 胞**：同样按基底摘要缓存；Both sides 的可用状态与 θ 的分母读缓存。
- 新事件：app 的 `sites`（载荷 `{side, counts, classes: n}`），加入 `api/public.js` 的 `EVENTS` 表；标记交互用 F0-A 的 `overlayhover`、`overlayclick`、`overlaydblclick`、`overlaycontext`（载荷 `{layer: 'adsorption-sites', index, item, x, y, mode}`，`item` 为位点对象）。

## 6. API

两种语言用同一组词（简报 §3：Python snake_case ↔ JS camelCase），同样分三层：**规划**（纯函数，返回放置）→ **应用**（原位修改）→ **便捷函数**（K16，E10）。所有新参数都是关键字参数（04 报告 §2.1）；

```python
    name: str | None = Field(None, max_length=80)
    keepOrientation: bool = False

class AdsorbRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")
    structure: StructureModel
    adsorbate: str | CustomAdsorbateModel
    mode: str | None = None
    site: str | int | None = None
    position: list[float] | None = Field(None, min_length=2, max_length=2)
    frac: list[float] | None = Field(None, min_length=2, max_length=2)
    side: Side = "top"
    all: bool = False                      # all equivalent sites of `site`'s class
    each: bool = False                     # one new structure per class (D6); response "structures"
    classes: list[str | int] | None = Field(None, max_length=200)
    coverage: float | None = Field(None, gt=0, le=1)
    per: str = "cell"                      # "cell" | "site-atom" | element symbol
    cells: int | None = Field(None, ge=1, le=100_000)
    count: int | None = Field(None, ge=1, le=100_000)
    minSeparation: float | None = Field(None, ge=0, le=50)
    skipOccupied: bool = True
    skipBlocked: bool = True
    bothSides: bool = False
    mirrorExisting: bool = False
    height: float | None = Field(None, ge=-2, le=10)
    bondLength: float | None = Field(None, ge=0.5, le=5)
    bondFactor: float | None = Field(None, gt=0, le=3)
    rotation: float = Field(0.0, ge=-3600, le=3600)
    tilt: float = Field(0.0, ge=0, le=180)
    clash: float | None = Field(None, ge=0.3, le=1.0)
    sites: SiteParams | None = None        # site-finder parameters used to resolve `site`
```

（`Vec3 = Annotated[list[float], Field(min_length=3, max_length=3)]`；新模型用 `extra="forbid"`，拼错字段返回 422——本模块的选择，M7 统一。）

**服务器行为**（E8、EM3）：

1. `to_structure()`；**需要位点识别**（`site` 是标签、关键字或下标；`all`、`each`、`coverage`、`count`；`bothSides` 需要对称操作）时：
   云模式且未登录 → 401（与 `/analysis/*` 同一守卫 `_signed_in_on_cloud`）；然后 `_guard_work(s, radius=5.0, settings)`（`routes/analysis.py:41`），再检查位点数 ≤ `site_max_count`。
   只给 `position`/`frac` 的请求不做位点识别，与其他 `/build/*` 一样公开。
2. 估算原子数：单个结构 `N + n_places·n_ads·(2 if bothSides)`（`all`/`coverage` 时 `n_places` 取该类位点数或目标数）；`each` 时为各类结构之和；超过 `_limit(settings)` → 400（E15）。
3. 科学代码的 `ValueError`/`TypeError` → 400（04 报告 §3.1）；`AdsorbateWarning` 收集进 `warnings`，不写 stderr。
4. `/analysis/sites` 的响应超过 `maxSites` 个位点时截断并给出 W10；`detail: "classes"` 不返回逐位点数组（1 万原子 slab 的完整响应约 3–4 MB）。

### 6.5 CLI（`crystallume/cli.py`，M7 统一前的提议；E23）

```
crystallume sites SLAB [--format FMT] [--side top|bottom|both] [--method auto|exposed|layers|window]
                       [--layers N] [--window Å] [--probe K] [--kind K]... [--tolerance Å]
                       [--distinguish-adsorbates] [--assign] [--all] [--json] [--plugins DIR]
crystallume adsorb SLAB ADSORBATE [--format FMT] [--mode MODE]
                       (--site SITE [--index K] | --position X Y | --frac U V | --each-class [--class LABEL]...)
                       [--all | --coverage THETA [--per cell|site-atom|EL] [--min-separation Å] | --count N]
                       [--side top|bottom] [--both-sides] [--height Å | --bond-length Å] [--bond-factor F]
                       [--rotation DEG] [--tilt DEG] [--method …] [--no-skip-blocked]
                       [-o OUT | -o DIR/] [--to FMT] [--plugins DIR]
crystallume adsorb SLAB (--substitute EL | --vacancy) [--class LABEL]... -o DIR/ [--to FMT]     # S
crystallume adsorb --list [--category C] [--json]
```

- 输入格式用 `--format`（与 `info`、`analyze` 一致），输出格式用 `--to` 或由 `-o` 的扩展名推断（与 `convert` 一致）；插件目录用 `with_plugins` 的 `--plugins DIR`；不再有 `-p`（与 `-p/--param` 冲突，`cli.py:459`）。
- `sites` 默认打印表格到 stdout，一类一行：`class  label  kind  count  example(frac u, v)  height`；`--all` 每个位点一行；`--assign` 追加吸附物的位点归属；`--json` 输出 `crystallume.sites/1`。
- `adsorb` 的 `ADSORBATE` 为库 id/别名或元素符号；`--site` 接受类标签（需引号）、ASE 关键字或类下标；`--index K` 选该类第 K 个位点（1 起，默认 1）。
  `--each-class -o DIR/`：每类写一个文件 `DIR/NN-<slug(label)>.<ext>`（扩展名按 `--to`，默认 `vasp`）与 `DIR/index.json`（`[{file, class, label, site, formula, warnings}]`）。
- 写出用现有 `_write_or_print`；警告以 `crystallume: warning: …` 打到 stderr（F0-D 的约定）。多值参数一律 `nargs=2`/`nargs=3` 或可重复的单值参数，不用 `nargs="+"`（04 报告 §2.5 的陷阱）。
- 示例：`crystallume adsorb slab.vasp CO --site "fcc (Pt3)" -o slab_co.vasp`、`crystallume adsorb slab.vasp O --site hollow --coverage 0.5 -o c2x2.vasp`、
  `crystallume adsorb slab.vasp CO --each-class -o screening/`、`crystallume sites CONTCAR --side both --assign`。

### 8.3 需要用户知道的取舍（按上表实施；若有不同意见，改动都很局部）

- 与 v1 原型相比，氧化物与 bcc(111) 上的位点标签变了（不再出现 `hcp (O3) over Ce`、`fcc (S3)`）；fcc(110) 多出 (111) 微面的 fcc/hcp 三重位。
- 覆盖度默认按 1×1 表面胞计算，在化合物表面与 v1 的"按表面原子"不同；两者都显示。
- 键长：Pt(111) 上与 v1 相差 ≤ 0.03 Å；W、Mo、Ru 等金属上缩短 0.1–0.25 Å（更接近文献）；Ti5c 上 O 从 2.26 缩到 1.75 Å。
- 异种元素的负载团簇默认算吸附物（位点只在支撑面上）；要团簇上的位点时勾 "Include adsorbates as site atoms" 或用选区。
- Pick site 工具里单击选位点、双击放置（F0-A 的统一交互），不再"单击即放"。
