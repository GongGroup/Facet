## 3. 规则与核对方法

### 3.1 命名规则（全仓库；新代码必须遵守，旧名字不改）

1. **两种语言同词**：Python snake_case，JS 同一组词的 camelCase；常量两边同名大写；`SURFACE_DEFAULTS` 的键按"下划线后字母大写"机械互转（L-F0-11）。同一概念只有一个名字，账本"已解决的冲突"里的旧名不作别名保留（ledger-features §0.3）。
2. **ASE 名字沿用 ASE 的语义**，不只是名字：`make_supercell(structure, P)`（原子按像优先排列，与 ASE 缺省 `order="cell-major"` 相同）、`Structure.set_cell(cell, scale_atoms=False)`、`surface`、`add_adsorbate(slab, adsorbate, height, position)`（位置参数与 ASE 相同，原位修改）、`add_vacuum`、`niggli_reduce`（**原位**，N-16）、`Structure.rotate(a, v, center=(0, 0, 0), rotate_cell=False)`、`translate`、`set_distance`/`set_angle`/`set_dihedral`/`rotate_dihedral`、`get_*`、`wrap`、`center(vacuum=)`（每侧，旧接口）。偏离 ASE 之处只有三条，全部写进 `docs/PLUGINS.md` §8.6：新函数的 `vacuum` 是总间隙且必填（U4）；`surface()` 的结果 `pbc = [T, T, T]`（U2）且 `layers` 是关键字参数、缺省 4；`niggli_reduce` 返回结构本身以便链式调用（ASE 返回 `None`）。
3. **返回值**：原位修改返回 `self`/`this`；派生返回新对象；纯函数不改输入。例外只有 `add_atom`/`addAtom` 返回新原子的下标（JS 现有约定，L-M4-02）。
4. **下划线**：Python 名字以 `_` 开头表示"供构建器与其他模块使用，脚本不要调用"（`_remap`、`_set_source`、`_adopt`）；JS 没有这个约定（`remap`、`setSource`、`_adopt`），两份文档都标为 internal。这是简报 C2 的写法，不算不一致。
5. **旧的不对称对保留**（`append`/`addAtom`、`delete`/`deleteAtoms`、`copy`/`clone`、`from_dict`/`fromJSON`、`to_dict`/`toJSON`、`read_xyz`/`readXYZ`、`write_extxyz`/`writeXYZ`），新代码不再造新的不对称对；M4 的 `add_atom` ↔ `addAtom` 补上了一对。
6. **JS 模块级构建器保留现有的 `build` 前缀**（`buildCrystal`、`buildSurface`），Python 没有（`crystal`、`surface`）；公共 API `facet.build.<名字>` 与 Python `facet.build.<名字>` 相同（`build.surface` ↔ `build.surface`、`build.makeSupercell` ↔ `build.make_supercell`、`build.makeInterface` ↔ `build.make_interface`）。
7. **`window.facet` 的命名空间按"做什么"划分**（K1）：

   | 命名空间 | 成员做什么 | 参数约定 |
   |---|---|---|
   | `build.*` | 返回新结构或目录数据，**不进项目、不改活动结构**（与现有 `build.crystal`、`build.molecules()` 相同） | 第一个参数可以是可省的输入结构（`build.surface(bulk?, params)`，按 `instanceof Structure` 判断） |
   | `analysis.*` | 返回数据，不改任何东西 | `(s = app.structure, opts)`：结构在前且可省；其他必需输入放进 `opts`（所以是 `sitePoint(s, { atoms })`、`movingGroup(s, { atoms })`）。唯一例外是顶层的 `matchQuery(query, s?)`（M3 E22） |
   | `edit.*` | 改活动结构，一次调用一步撤销（经 `editActive`/`replaceActiveStructure`，L-F0-53） | 下标缺省为选区；不改结构的成员只有 `copy()` 与 `clipboard()`，它们不入历史 |
   | `surface.*` | Surface 面板的应用动作：把结果加入项目（可撤销）、开关标记 | 与对应命令同参数 |
   | `lattice.*` | 只接受晶胞、矩阵、指数，不接受结构 | 纯函数 |
   | 顶层 `select*` | 改应用的选区并返回新选区 | 纯查询放在 `web/js/core/selection.js`（与 Python 同名、返回下标）与 `facet.matchQuery` |

8. **命令 ID** 为 `<区域>.<动词或名词>`（camelCase：`surface.setVacuum`、`cell.bakeRepeat`）；标题句首大写，打开表单的命令以 `…` 结尾；MS 的名字只放 `aliases`（菜单路径放 `ms`，只显示）；类别取 `CATEGORY_ORDER`（F0-A 加了 `Cell`、`Surface`）。
9. **REST**：路径段是名词（`/build/surface`、`/analysis/layers`）；请求体字段 camelCase；模型名 `<名词>Request` / `<名词>Response`（同一名词在 `/build` 与 `/analysis` 下都有时，`/analysis` 一侧加区分词，如 `VacuumGapRequest`，N-18）；新模型 `extra="forbid"`。
10. **客户端**：K3。
11. **CLI**：子命令与选项 kebab-case；输入输出选项按 ledger-features §0.3（写结构的命令 `--from` 输入格式、`-o` 输出、`--format` 输出格式；只读命令 `--format` 输入格式、`--json`；帧一律 `--index N`）；**同一个选项名在所有命令里含义相同**（N-23）；容差一律 `--<领域>-tol`（`--layer-tol`、`--translation-tol`、`--twist-tol`、`--site-tol`）；帮助里写单位。
12. **拼写**：标识符、CLI 选项、JSON 键用美式（`center`、`color`，与现有代码相同）；界面文字与文档正文用英式（`Centre slab`、`Colours`，与现有界面、README 相同）；显示给用户的枚举值随界面（`centred-rectangular`，L-M1-05）。
13. **Python 包的属性遮蔽**：`facet.build` 导出与子模块同名的函数（现有 `build.crystal`，新增 `build.surface`、`build.adsorbate`），包属性是函数而不是子模块。文档与代码一律写 `from facet.build.adsorbate import adsorbate_suffix` 或用 `facet.build` 重新导出的名字，**不写** `facet.build.adsorbate.adsorbate_suffix`（属性访问拿到的是函数，会 `AttributeError`）。M6 的子模块 `build.interface` 与函数 `make_interface` 不同名，不受影响。
14. **错误文案**：核心函数的 `ValueError`/JS `Error` 两种语言逐字相同、小写开头、无句末句号；界面显示时首字母大写加句号；REST 的 `detail` 就是核心文案；CLI 打印 `facet: error: <文案>`（F0 账本 §0.3）。
15. **进入名字、标签与文案的数字**一律经 L-M1-15 的 `round_half_up`/`format_decimal`/`format_sig3`/`format_angle`。

### 3.2 返回类型规则（K2）

一个参数不得改变返回对象的种类。需要不同结果时提供第二个函数或方法（先例：`contiguous_shifts` 代替 `make_contiguous(return_shifts=True)`，`export_structure_with_warnings` 代替 `export_structure(with_warnings=True)`，`transform_detailed`）。
唯一例外：`details=True` 把列表或元组结果换成字典，字典里含原结果与诊断信息（`find_adsorbates`、`surface_atoms`、`site_atoms` 已这样做；文档写明 `details=True` 时原结果在哪个键）。
REST 响应是 JSON 对象，只增减键（例如 `structures` 代替 `structure`、附加 `parts`），不视为违反。

### 3.5 `normalize_symbol`（K8，E-37 交 M7）

两种语言同一规则（`core/elements.py:75`、`web/js/core/elements.js:138`），金标 `tests/data/elements/normalize.json`（≥ 40 个记号）：

```text
None/null → "X"
整数或纯数字串 → 原子序数对应的符号，不存在 → "X"
取第一个字母串：去掉 "_" "/" "." ":" 之后的部分（Fe_pv、Fe/pv），再去掉非字母（Fe3+、O2-、Ca1 → Fe、O、Ca）
字母串恰为 D 或 T（大小写不限，D1、t2 同此；Ta、Tb 等两字母元素不受影响）→ "H"，并记读取备注
前两个字母按"首字母大写、次字母小写"是元素 → 它（CA → Ca、CL1 → Cl、CAL → Ca）
否则首字母是元素 → 它（OW → O、Hw1 → H、OXT → O）
否则 → "X"，并记读取备注
备注（读取器经 add_warning 写入，同一文件合并为一条）：species 'D' was read as H; 'Xq' was read as X (unknown element)
```

变化：Python 原来保留 `D`、`T` 与未知记号，现在给 H/X 并记备注；JS 原来对 `CAL` 这类三字母全大写记号取单字母（`C`），现在取两字母（`Ca`）。界面的元素输入（M4 `parse_element`）不受影响（它对未知符号报错）。M7-T6（第 5 波）。

### 3.6 JS PDB 写出的取向（E-27 交 M7）

`web/js/io/pdb.js:95-108` 写坐标前先把晶胞与坐标转到 PDB 要求的标准取向（a ∥ x，b 在 xy 平面），与 Python `io/pdb.py:172` 相同；金标对一个倾斜的三斜晶胞核对两种语言的 `CRYST1` 与坐标（P6）。M7-T7（第 5 波）。

### 6.7 CLI

**通用约定**（ledger-features §0.3，本节只补 M7 的统一项，§6.8 N-23…N-28）：
- 写结构的命令：`--from FMT`（输入格式）、`-o/--output OUT`（**可省**，省略时 Extended XYZ 写到 stdout，与现有 `build` 组相同，N-26）、`--format FMT`（输出格式）。只读命令：`--format FMT`（输入格式）、`--json`。

### 6.10 单位、真空与各入口的缺省值

| 主题 | 规则 |
|---|---|
| 长度、角度、坐标 | Å；度；分数坐标无量纲；晶胞的行是晶格矢量，`cart = frac @ cell`（C1） |
| 真空 | 名为 `vacuum` 的参数（Python、JS、REST、命令、CLI 的 `--vacuum`）= slab 或叠层与其周期像之间沿法向的**总间隙**，必填、无缺省、界面从不预填（U4，ledger-features §1.5）。例外只有两个旧接口：`Structure.center(vacuum=)` 与 `build.crystal(…, vacuum=)`/`build crystal --vacuum`（**每侧**，后者给值时发 `DeprecationWarning`，负责人决定 L-02）。M5 `Adsorbate.to_structure(vacuum=)` 是装箱：各晶胞矢量方向上周期像之间的总间隙 |
| 0 Å 真空 | 切面 = 体相堆垛（`stacking: "bulk"`）；界面 = 超晶格；已有结构的 `set_vacuum(0)` → E12d（负责人决定 L-13） |
| 应变 | 名字带 `percent` 的参数、CLI 与界面用百分数；`max_strain` 是分数（N-22） |
| 探针 | `probe` 是相对原子半径的比例（不是 Å），0.3–1.5（N-21） |
| 帧 | Python `frame=None` → 第 0 帧；JS 缺省当前帧；CLI `--index` 缺省 −1（最后一帧）；改变晶格或原子集合的操作只作用于一帧并丢弃其余帧（C11） |
| 层号 | Python 数组 0 = 最底层（`index`）、`from_top` 0 = 顶层；界面、CLI、查询 JSON 与 `tags` 用"顶层 = 1" |
| 约束 | `selective_dynamics` 的 True = 沿晶格矢量 a/b/c **可动**（C3）；`axes`、`fix_axes`、CLI `--axes` 列出的是**被固定**的方向（`"abc"` 的子集或可精确换算的 `"z"`、`"xy"`） |
| 吸附物与层分析的缺省 | `find_layers`、`facet.analysis.layers`、JS `findLayers`：`skip_adsorbates=False`；Layers 分区、`fix_layers`、`select_layers`、REST `/analysis/layers`、`Client.find_layers`、CLI `layers`：跳过吸附物（`--include-adsorbates` 关闭）（N-33） |
| 层容差 | `tolerance=None` → `info.surface.layerTolerance` → `SURFACE_DEFAULTS.layer_tolerance`（0.3 Å）（R-F07） |
| 其他缺省（U4） | 4 层（`slab_layers`）、六方表面网格 120°、slab 居中（`slab_position = "center"`） |

### 7.6 默认运行的时间预算

- **发布时 `pytest -q`（不含 `slow`，有 Node）在开发容器里 ≤ 60 s**，其中经桥运行的 JS 部分（`test_js_unit.py`、`test_js_parity.py`、`run_js` 调用）≤ 20 s。现状：169 个测试约 7.7 s（`progress.md`）。

§8.1 的两段关键原文（各模块照抄，不改说法）：

```markdown
**Vacuum** is always the total gap, in Å, between the slab (or the stack) and its periodic image along the
surface normal. It has no default: every function, command and form that takes `vacuum` needs a value, and
0 is allowed when cleaving (the slab continues the bulk stacking) and when building an interface (a
superlattice), but not for the vacuum of an existing structure: cleave with 0 instead. Two older calls are different: `Structure.center(vacuum=)` and `build.crystal(..., vacuum=)`
add that much vacuum on *each* side, as in ASE's `surface()`.

**Constraints** are stored as `selective_dynamics`: three booleans per atom, `True` meaning free to move
along cell vector a, b or c, as in VASP. A structure without this property has every atom free. The `axes`
of `fix`, `fix_layers` and `--axes` list the directions to *fix*: `"abc"` for all three, `"c"`, or `"z"` and
`"xy"` when the cell makes them exact (a and b in the xy plane, c along z).
```

§8.6 列出的差别（原文要点）：`surface()` 的 `vacuum` 是总间隙且必填、结果三维周期、`layers` 缺省 4；`add_adsorbate()` 与 ASE 一样原位修改并接受 `height`、`position` 位置参数，另有 `site=`；`niggli_reduce()` 原位修改并返回结构；`tags` 1 = 顶层（与 ASE `surface()` 每个周期块一个号不同，M3 D16）；Extended XYZ 的 `move_mask` 与 ASE 的 `FixAtoms`/`FixCartesian` 互通，部分约束经 ASE 写 POSCAR 会丢失（导出警告 W6）；pymatgen 的位点 `distance` 只指位点偏移，键长参数叫 `bond_length`。

# Changelog

## 0.4.0 — <date>

Build surface models — slabs, constraints, adsorbates and interfaces — in the app, from Python, over the
REST API and on the command line.

### New
- **Surface panel** (Shift+5) with five sections, each with a live preview:
  - **Cleave**: cut a slab from a crystal along (h k l) or (h k i l), pick a termination, set the thickness

  - **Layers**: see the atomic layers of any slab, select or fix the bottom, middle or top layers, fix

  - **Interface**: match two lattices, choose how the strain is shared, set the distance, shift and twist,

  re-orient, shift origin and wrap.

  structures.

  atoms with Atom Selection queries by element, layer, height or coordination.
- Look along the surface normal (N), at the bottom surface (Shift+N), or along any [u v w] or (h k l).
- Search commands by their Materials Studio names, such as Cleave Surface or Build Layers.
- Exports warn when the format cannot keep constraints, frames, occupancy or the cell.
- Python: `build.surface`, `build.make_supercell`, `build.add_adsorbate`, `build.make_interface`,
  `analysis.find_layers`, `analysis.adsorption_sites` and new `Structure` methods such as `set_vacuum`,
  `fix_layers`, `rotate` and `set_distance` (see docs/PLUGINS.md §8).
- REST: `/build/surface`, `/build/vacuum`, `/build/transform`, `/build/adsorbate`, `/build/adsorbates`,
  `/build/interface`, `/analysis/terminations`, `/analysis/layers`, `/analysis/sites`,
  `/analysis/interface` and `/analysis/vacuum`, each with a `Client` method.
- Command line: `build surface`, `build interface`, `transform`, `terminations`, `layers`, `sites`,
  `adsorb` and `edit` (`vacuum`, `flip`, `center-slab`, `fix`, `free`, `translate`, `rotate`,
  `set-distance`, `set-angle`, `set-dihedral`, `add-atom`, `merge`, `delete`).

### Changed
- `vacuum` in every new function, command and form is the total gap between a slab and its periodic image,
  and has no default.
- `build.crystal(..., vacuum=)` and `facet build crystal --vacuum` still add vacuum on each side, and
  now say so; the Python call gives a DeprecationWarning.
- Extended XYZ files store constraints as ASE's `move_mask` instead of `selective_dynamics:L:3` (both are
  still read).
- Dihedral angles in the web app have the IUPAC sign, as in Python.
- Built crystals have the same name in the app and in Python, such as `Cu fcc`; supercell names read
  `Cu fcc 2×2×2`.
- Built-in prototypes use the same default lattice constants in the app and in Python.
- `Structure.delete` raises IndexError for an atom index out of range instead of wrapping around.
- Editing atoms or the cell removes the space group and calculated results such as energies, with a note.
- New atoms get default values for per-atom properties (free, tag 0) instead of empty ones.
- Unknown elements have a covalent radius of 0.5 Å in Python (was 1.5 Å), as in the app.
- D and T are read as H, and unknown element symbols as X, with a note.

### Fixed
- The web app's POSCAR reader dropped Selective dynamics, and its writer never wrote it.
- Python read `.TRUE.` in Selective dynamics as fixed.
- Duplicated structures shared per-atom properties with the original in the web app.
- `get_distance(mic=True)` and other minimum-image distances were wrong in strongly skewed cells.
- Slabs that cross the cell boundary are drawn in one piece, and the bottom layer is no longer drawn again
  above the vacuum.
- Smart bonds no longer hide every metal–metal bond when a molecule sits on a metal surface.
- Undo in a notice undid the latest change instead of its own.
- PDB files written by the web app use the standard orientation, as Python's do.

### For plugin authors
- Panels, selection actions, atom info rows and view tools can be added with `registerPanelSection`,
  `registerSelectionAction`, `registerAtomInfo` and `tools.register`.
- Commands can declare `params`, `aliases` and `estimate`; parameters are checked for plugins and
  embedding pages.
- New events: `preview`, `visibility`, `overlayhover`, `overlayclick`, `overlaydblclick` and
  `overlaycontext`.
- `app.undoStack` and `app.redoStack` are deprecated; use `app.history`.

### Server
- In cloud mode, `/build/*` requests that run a search (sites, lattice matching, cleaving a crystal of more
  than 2 000 atoms) need a signed-in user.
- New settings `FACET_MAX_INTERFACE_WORK` and `FACET_MAX_INTERFACE_VECTOR_PAIRS`.
- `/io/export` returns `warnings` and `notes`; `/formats` lists what each writer can store.

### Upgrading from 0.3
- Projects from 0.3.1 open unchanged; saved measurements are converted when the project opens.
- Scripts that read `selective_dynamics` columns from Extended XYZ files written by 0.4 should read
  `move_mask` (or use `facet.read`).
- When serving a static copy or an artifact, publish the new `data/` folder with `js/`, `css/` and
  `vendor/`.
